# 301. Introspection of reuse and threads

Status: accepted
Where: 13
Note: the user asked for introspection of memos and parallelism

Introspection of reuse and threads: each query table counts what a run does with its memos (`Event`,
`Db::tally`, `--memos`/`VUN_MEMOS=1`); `vun-par` counts calls spread, alone and nested, helpers
asked and lent, wall and busy time (`Usage`, with `--timings`), and `VUN_THREADS` sets its threads;
waiting on a claim is timed apart; a saved key reached through reads gets its slot by position and
is read when first needed
