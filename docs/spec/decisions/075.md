# 75. Type syntax is complete in evaluation

Status: accepted
Where: 02, appendix B
Note: on the agent's recommendation

Type syntax is complete in evaluation: `[N]T` arrays, `[T]` slices (an array value holding one type,
mirroring tuples of types), `?T` and `*T` through the table `type_prefixes`; array literals have the
join of their items, `[v; n]` repeats, and an integer index gives the item of an array or slice,
through a borrow
