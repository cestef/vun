# 475. `install.sh` runs nothing it has not checked

Status: accepted
Where: 12

`install.sh` runs nothing it has not checked: with each release the workflow publishes `SHA256SUMS`
of the archives and `SHA256SUMS.sig`, its raw Ed25519 signature from the same `RELEASE_KEY`
(decision 368); the script holds the release key (`VUN_INSTALL_KEY` names a mirror's, as the base64
of its DER; a test holds it equal to `key.pub`), checks the signature with `openssl pkeyutl -verify
-rawin`, the archive against the checksums with `sha256sum` or `shasum`, and only then unpacks it
and lets it run `vun toolchain update`. The first toolchain is therefore the project's, not the
connection's
