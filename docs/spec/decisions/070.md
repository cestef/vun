# 70. Visibility levels

Status: accepted
Where: 01
Note: the user chose the levels and the spelling

Visibility levels: a name starting with `_` is restricted to a scope, its declaring namespace unless
`#[visible(.within(ns))]`, `#[visible(.package)]` or `#[visible(.workspace)]` widens it;
`lang.scope` declares `Scope` and its values, and `.name` with a provided type expected looks in the
namespace declaring the type; files and directories take their parent's scope; `names.visibility`
for a misplaced attribute
