# 269. The language server, `vun util lsp`

Status: accepted
Where: 12, 13

The language server, `vun util lsp` (`vun-lsp`), is a shell over one driver session and its query
engine: an open document's text, saved or not, is read as a new version of its file (`FileId`) at
each change, and results of earlier versions are placed in the latest through `vun_origin::Resolve`;
it publishes the diagnostics `vun check` reports, per document version, answers definition and hover
from resolution, sema and the types `vun debug types` prints, applies the changes that arrived
during a check together before the next, and declares its methods in one table from which its
capabilities derive, its messages typed structs over `vun-data` (no `lsp-types`)
