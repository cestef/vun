# 153. The C backend writes strict C99

Status: accepted
Where: 13
Note: the user's choice

The C backend writes strict C99: no header, its own `uN`/`iN` from the target's C model
(`lang.target.C`), every width and alignment it relies on checked with `sizeof`; unsigned
arithmetic, signed operations through `iN`; typed memory access with `-fno-strict-aliasing`; atomics
only through the builtins the target's C compiler profile declares (`lang.target.Atomics`); typed
own names spelled in one place, stepping aside for link symbols; data defined in pointer order,
cycles declared first; what C99 lacks refused; the target's C compiler (`lang.target.CCompiler`)
compiles, and drives GNU ld for hosted targets
