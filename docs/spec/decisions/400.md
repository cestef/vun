# 400. An array has the impls of the slice of its items

Status: accepted
Where: 2

An array has the impls of the slice of its items (`Witnesses::tiers`: its own, then the slice's), so
an impl for the slice serves arrays and `lang.mem.Array` is targeted only to differ: `Eq` (one
length) and `Sequence.len` (`n`). A name an array impl declares, or an interface it implements,
shadows the slice's. The array twins of `Format`, `Debug`, `Json`, `Hash`, `Concat` and the search
methods are removed
