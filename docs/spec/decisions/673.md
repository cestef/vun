# 673. `#[link.library(name)]` is read by every hosted linker

Status: accepted
Where: 07, 13

`#[link.library(name)]` is read by every hosted linker (decision 254 done): the link plan lists the
libraries the imports name (`LinkPlan::libraries`, from `lir::Unit::libraries`), and the GNU driver,
`ld64.lld` and `lld-link` link each after the objects (`-lname`, `name.lib`). A package states what
it links on its imports; the machine's tools file keeps sysroots and flags, not what a program needs
