# 95. Kinds

Status: accepted
Where: 05

Kinds (query `Kinds`): a type is linear when `#[kind.linear]` marks it (on its literal or its
declaration), when a part is linear, or when it is a frame; borrows are copy as kinds, their
exclusivity being the borrow rules'. Reading a whole linear place moves it; matching or
destructuring by value consumes the value, whose parts carry what it held (`Role::Unpacked`); a
return with a linear place still held is `place.linear_leak`, a discarded linear result included. A
method's receiver is passed as its first parameter asks: a borrow in its mode, or the value
