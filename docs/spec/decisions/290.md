# 290. LIR is lowered per function

Status: accepted
Where: 13
Note: the user asked for LIR per function

LIR is lowered per function (`FunctionLir`): a function's LIR, tidied, names functions, link
symbols, data and trap sites by positions in its own tables (`Refs`), placed in the unit when the
program is assembled (`Assembly`: exports resolve link symbols, constants deduplicated after their
site ids are written, sites numbered in function order, a site's id held in data, never an
immediate); `Cx::get_all` computes many keys of a query over threads and reads them as the caller's
reads; simplify's second phase (`inline_small`) runs on the assembled unit
