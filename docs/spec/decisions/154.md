# 154. Targets are named `targets.<system>.<cpu>`

Status: accepted
Where: 13
Note: the user's choice

Targets are named `targets.<system>.<cpu>` (`linux.x86_64`, `bare.cortex_m4f`); architecture, CPU,
system and ABI are fields of `lang.target.Spec`, never parts of a name; a `Spec` holds the target's
C model (`lang.target.C`); `--target` names one, else `targets.hosts` gives the running machine's
(named as Rust's `std::env::consts`); the target is a query input with no default, so nothing
assumes a width
