# 663. A tuple position is a `u32`

Status: accepted

A tuple position is a `u32` (`syntax.tuple_index_too_large` past it, reported where the HIR is
lowered, which takes the diagnostics context of the stages before it); a native frame, and the stack
arguments of a call, are at most 1 GiB (`Missing::Frame`), which keeps every displacement of an
access in 32 bits with room for the words a function reserves besides; the declaration number of an
origin is a `u32`.
