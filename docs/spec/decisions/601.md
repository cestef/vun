# 601. `--measure instructions` counts the instructions a process retires in user mode

Status: accepted
Where: 11

`--measure instructions` counts the instructions a process retires in user mode under `perf stat -e
instructions:u` (a program's samples are one process per benchmark, its count over the iterations
its loop ran: start and batch overhead are counted in, a constant a baseline cancels). Where it
cannot (not Linux, a target run through an emulator, no `perf`, no counter or no permission) the run
is timed and says why with a typed `Unavailable` reason (the record `bench_fallback`); an
interpreter's operation count (spec 11) waits for the interpreter mode, a Cortex-M's DWT cycle
counter for the board runner
