# 680. The binder binds a C enum as an integer alias and a constant per value, which

Status: accepted
Where: 05, 07

The binder binds a C enum as an integer alias and a constant per value, which stays sound whatever C
holds in it; a request lists the enums, by their bound names (`vun_binder::Request::closed`,
`--closed`), that are Vun enums naming their tags (decision 679): `#[layout.tag]` of the enum's
integer, a variant per value (`GTK_ALIGN_FILL` is `fill`, the shared prefix dropped), and a constant
of the enum's type for a name that repeats a value; an enum whose names make no variants stays an
integer. A `#[layout.c]` struct accepts such an enum as a field, being the integer it is stored in
