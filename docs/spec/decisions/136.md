# 136. A package's plan

Status: accepted
Where: 03, 12
Note: the user chose Any and append

A package's plan: `std.build.plan($build)` lends `build` a `Build` without steps and returns its
`Action`s (`dep(Needed)`, `program(Any)`, `flash(Flashed)`, `test_on(Tested)`, `lints(Any)`),
recorded by `lang.meta.append` into a `&static [Action]`; records whose types each call infers are
kept as `lang.meta.Any` (a compile-time value with its type, `lang.meta.any(T, x)`); the driver
takes the declaration to run from the requirements of `std.build.Package`, runs the plan when
checking a package's `build.vun` (`plan.missing_build`, `plan.stopped`, or the trap) and prints it
with `vun debug plan`, a value printed as a literal (a namespace as its path, `Literal::Path`)
