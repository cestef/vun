# 84. Reflection descriptors are ordinary `lang.meta` structs named by each

Status: accepted
Where: 03
Note: on the agent's recommendation

Reflection descriptors are ordinary `lang.meta` structs named by each primitive's declared result
type (`fields: ($T: type) -> &[Field]`), filled by field name; `lang.meta.Field` holds `name` and
`type` for now (`attrs` added by 352; `offset` waits for layout); `name_of(T)` is the name
diagnostics show; `std.meta` spreads them
