`#[test.ignore("why")]` is a call of `std.testing.test.ignore`, giving a `std.testing.Ignored` the
runner reads with `std.meta.attr`: the test is not run and is reported as `ignored` with its reason,
and counted in the totals. `vun test` gives the program one pipe for its standard output and error,
so the lines a test writes, its trap's backtrace included, are reported with it. A run-time check
(bounds, narrowing, shift, division) names its site with the message its `Reason` gives at compile
time, so an index trap says what it is. Editors list a file's tests by calling `std.meta.collect(ns,
std.testing.test)` through the query engine (`vun_sema::testing::Tests`, each collected member
resolved to its declaration), and the language server offers a lens over each running `vun.test`,
which builds the tests' program and runs that test, its report written beside the document; `vun
test` and the server share the running and reporting (`vun_driver::testing::Run`). No `origin` is
added to `lang.meta.Decl`: the declaration a member names gives it. What a run reports comes back to
the server's loop as an event; how each test ended is kept until its document changes, titles its
lens and shows a trap as an error where it fired
