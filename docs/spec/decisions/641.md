# 641. `lang.bounds.last(T, b)`

Status: accepted
Where: 04, 06

`lang.bounds.last(T, b)` (the greatest item of bounds with an end, trapping for `a..`) and
`lang.bounds.before(T, b, x)` (the item before, or `x` at the least) read bounds from their end;
`rev` on `lang.Bounds($T)` (`std.iter`) is written over them, so `(3..8).rev()` counts 7 down to 3.
Bounds of one integer type convert to bounds of another in compiled code (a range literal's narrow
item type passes where `Bounds(usize)` is taken). `Vec.drain(range)` takes a `Bounds(usize)` where
it took `from, to`
