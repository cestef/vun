# 671. Durability is per group of inputs

Status: accepted
Where: 13
Note: the user asked for the best redesign of the verify step: 28 000 memos restored, 710 durable

Durability is per group of inputs. A query names the group of each input key (`Query::group`: a
package's description and files, the target, the checks, the trace each their own); the database
keeps the fingerprint of the shared inputs of each group as inputs are set; a memo records the
groups of all the inputs it read through (`Groups`, interned and pooled) and is saved with the
fingerprint of their inputs when it last held (`Under`), holding at once while that is the same.
This replaces decision 302's fingerprint per level, which folded over every input set and so
mismatched on a primed toolchain whenever the project published other packages or set options
priming left unset; a memo is its own when it reads an input of the database's own, as before
