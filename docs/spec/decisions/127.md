# 127. `std.iter` adapters

Status: accepted
Where: 06

`std.iter` adapters (`enumerate`, `map`, `filter`, `take`, `count`) are coroutine functions in
`#[impl(lang.Coroutine)] iter_methods`, each consuming the frame; a frame has its impls' methods
besides its interface's requirements; slices and arrays have `enumerate` yielding `(usize, &T)`
