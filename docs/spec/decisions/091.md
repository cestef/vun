# 91. `e?` goes through the table `early_return`

Status: accepted
Where: 01, 02, appendix B
Note: the user chose `never` arguments and `&mut Self`

`e?` goes through the table `early_return` (`lang.ops.Try.branch`, variants `go` and `stop`);
`lang.Branch(V, S)` names the result, and `lang.ops` holds the impls for `Option` (`Stop :=
Option(never)`) and `Result` (`Stop := Result(never, E)`); a type made with an empty enum in place
of arguments is accepted where the same constructor is expected (`NominalKind::Empty`), and joins
take the accepting type. Closures call through `lang.ops.Call` with `call: (self: &mut Self, args:
Params) -> R`: a closure has the type `TyKind::Closure` (its literal, instance, captures and
signature), its body is typed with the enclosing body, and its MIR takes the captures before the
parameters
