# 88. MIR places carry projections

Status: accepted
Where: 13

MIR places carry projections (`.*`, fields, items at an index held in a local), used for every read,
write and borrow of a part, so there is one way to reach a part; `.` and indexing dereference once
per borrow the typed body shows; `&mode place` is `Rvalue::Ref`; at compile time a shared borrow
reads as the value, parts are written by rebuilding the value, and `&mut` waits for a memory model;
an index past the end is a compile-time trap
