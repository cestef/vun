# 481. `std` gains `std.rand`

Status: accepted
Where: 12

`std` gains `std.rand` (`Rng`: `next` and the defaults `below`, `flip`, `fill`, `shuffle`;
`SplitMix64`, `Xoshiro256`, `Pcg32`, seeded and not for secrets, so no operating system entropy
yet), `std.seq.sort` (in place and with no allocator: `sort`, `sort_by`, `is_sorted`,
`binary_search`, `swap`, `reverse` on every slice; insertion sort below 16 items, heap sort above,
so not stable), `std.codec` (`Base`: hex, base32, base64 and base64url as one table of group size,
alphabet, padding and case; `varint`: LEB128 and zigzag) and the checksums `std.hash.crc32` and
`std.hash.adler32`, which are `Hasher`s. The property tests draw from `std.rand.SplitMix64` rather
than a copy
