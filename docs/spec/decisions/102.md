# 102. `#[impl(T)]` without an interface

Status: accepted
Where: 02
Note: the user accepted the review's proposals

`#[impl(T)]` without an interface: its argument is the target (a type or a type constructor), the
struct's declarations join `T`'s method lookup after its namespace, nothing is checked against
requirements, and no witness pair is registered (`ImplDecl::contract` is `None`), so the orphan rule
does not apply; a name declared by two impls a file sees, or by an impl and the type itself, is
`impl.collision` where it is looked up. `std.result` uses one for `map_err`
