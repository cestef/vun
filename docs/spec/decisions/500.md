# 500. A run the server starts can be given input

Status: accepted
Where: 13

A run the server starts can be given input: `vun.input` shows `.vun/views/<file>.input` (an empty
file where there is none) and the lens beside each run lens opens it; `vun.run` gives the program
that file as its standard input when it exists. The protocol has no way to prompt for text, so the
input is a file the editor edits, kept between runs like the output of one
