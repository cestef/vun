Components are a noun of their own, `vun component list\|add\|remove`, not a group of `toolchain`
(replacing decision 168's `toolchain component`). `list` merges what a toolchain has, built in,
loaded or installed, with what its release builds and the toolchain lacks
(`vun_driver::install::Component`, `Has`; `Kind` and `Id` give a piece of a release a typed name,
`backend-cranelift`, `link-lld`), from the manifest kept when the toolchain was installed, so naming
a component needs no network and a name is checked before anything is fetched
(`toolchain.no_component`, closest name suggested; a bare name is taken when one component has it).
`remove` refuses a component another installed one needs (`toolchain.required`). `toolchain show`
keeps the toolchain's facts and counts its components; `toolchain default <version>` makes an
installed toolchain the default. A fetch that fails names the address it was for
