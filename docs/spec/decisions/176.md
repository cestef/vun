# 176. The query engine

Status: accepted
Where: 13

The query engine: memos in slots of per-query tables (a key's slot made when first asked for), memos
swapped atomically and read without locks, reads recorded as (table, slot, fingerprint) once each in
first-read order, interface fingerprints of 128 bits from two fixed-seed foldhash passes instead of
BLAKE3 (package content hashes stay BLAKE3), one thread computing each memo while others wait, with
a wait-chain check that computes locally rather than deadlock; sessions share a database per package
(`Shared`, one target per database); interners and concurrent tables lock-free (`vun_par::Map`)
