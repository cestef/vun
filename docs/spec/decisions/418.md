# 418. `windows.x86.msvc` is a target

Status: accepted
Where: 08, 13

`windows.x86.msvc` is a target: 32-bit x86 PE built through the C backend with clang for
`i686-pc-windows-msvc`, linked by `lld-link` against `kernel32` and `ntdll`, which defines what the
C compiler calls for (`_aulldiv` and the other 64-bit divisions, `_chkstk`, the copies and fills),
so its runtime defines none of them and needs no 32-bit assembler. `kernel32`'s imports are
`stdcall`; `lang.target.Spec.accepts` lists the conventions of other architectures a target's C
compiler takes for its own, which x86-64 Windows does for the four of x86, so code calling the
system is written once. Its `register_bits` is 64, the width its C compiler computes and reaches
atomically, as wasm32's with 32-bit addresses (decision 299), so no atomic of 64 bits is
`lang.mem.soft`'s. A DLL names its exports undecorated whatever the convention (`lld-link` strips
the decoration), and the handles a 32-bit system returns are whole file numbers
