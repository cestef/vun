# 253. A wasm backend of the toolchain's own

Status: accepted
Where: 13

A wasm backend of the toolchain's own (`vun-backend-wasm`, spec 13, section 8.4): relocatable
objects in the tool conventions' format, linked by `wasm-ld`; modules and instructions as typed data
with a verifier running the specification's validation; structured control by Ramsey's algorithm;
slots below `__stack_pointer`; clang's wasm32 C convention
