# 227. Simplification runs callees first, so a function inlined has its own small

Status: accepted
Where: 13

Simplification runs callees first, so a function inlined has its own small callees inlined already;
a truncation of a sum, difference, product or bitwise operation read nowhere else is computed at the
narrow width (`Function::narrow`); absorbing constants fold (`x * 0`, `x & 0`, `x \| ~0`) as
identities do, `x & ~0` among them; unreached blocks are emptied and instructions that do nothing
but define an unread value are swept (`Function::sweep`). A 50-million-step `u64` LCG loop runs
natively in 380 ms instead of 487
