# 477. `std.fmt.println` is `print` and a line break

Status: accepted
Where: 03, 05

`std.fmt.println` is `print` and a line break; both write the pieces of one `std.fmt.write`, which
takes the arguments as a tuple. `std.mem.copy($T, to: &mut [T], from: &[T])` copies slices of one
length (a difference is `lang.panic.fail`) over `lang.mem.copy`
