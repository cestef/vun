# 386. Simulations run

Status: accepted
Where: 11

Simulations run (spec 11, section 4): a test whose one parameter is `&mut std.testing.Sim`
(`std.testing.takes`, which benchmarks use too) runs through the property runner, its `attempt`
giving the simulation the case's `Choices` by borrow, so the choices taken survive a trap and a
failing schedule is shrunk and replayed as a property's case is; it writes no argument lines.
`s.run(&clock, tasks, limit)` resumes one ready task of a tuple of `std.task.Async` borrows at a
time, chosen by a choice, and when none is ready moves the `Clock` (atomics, borrowed by the tasks
as the simulation runs them) to the earliest time a task sleeps until, waking every task, and ends
`.done`, `.stalled` or `.timed_out`. `vun sim --seeds N` is dropped: `--cases` and `--seed` do it.
Shrinking (`std.testing.property.shrink`) now keeps a case only when it is smaller than the best
(`Failing.smaller`: fewer choices, or as many and a smaller one first where they differ); a case
already minimal was counted shrunk on every try, up to `tries`
