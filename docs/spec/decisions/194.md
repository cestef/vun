# 194. Or-patterns that bind

Status: accepted
Where: 01, 13

Or-patterns that bind: every alternative binds the same names with the same types (spec 01, section
6), paired by `Hir::joined`; the resolver reports a name bound by some alternatives only and the
typer one bound with different types, both as `binding.unequal_alternatives`; MIR binds every
alternative into the locals of the first's binders, which names after the pattern resolve to
