# 264. What a program is built as is `std.build.Output`

Status: accepted
Where: 08, 12, 13

What a program is built as is `std.build.Output` (`executable`, `shared`, `static`), a field of a
plan's `Options` and `vun build --library`; a library has no runtime and no entry symbol, and is
named as its object format names libraries (`libcalc.so`, `calc.wasm`); linkers declare the outputs
they make (`LinkerInfo.outputs`), and a build takes the target's linker where it makes the output,
else the first adapter that does for the format: the target's archiver
(`lang.target.CCompiler.archiver`, `ar`) for a static library. A shared library's C sources compile
with `-fPIC`, and an ELF object the native backend writes names its own definitions through their
sections, so a library binds to itself (the user's plan)
