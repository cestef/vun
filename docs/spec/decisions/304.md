# 304. Layered memo files

Status: accepted
Where: 13
Note: saving copied every key of the shared entry into the project file: ~137 ms per build of a new project

Layered memo files: a project's saved memos are layered over the shared file of the libraries' memos
they were loaded with, named by the hash of its body; the stream, the pools, the queries' positions
and each query's keys continue that file's, the project file holding the keys it lacks and the memos
of its keys computed again; shared files are kept by hash, a week each but the newest; a memo
computed again equal to the one loaded is not new (`Novelty`)
