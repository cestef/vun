# 493. `std.fmt.json` writes a float as a JSON number of its shortest digits

Status: accepted
Where: 11, 12

`std.fmt.json` writes a float as a JSON number of its shortest digits (`std.fmt.float`), and `null`
for a NaN and an infinity, which JSON has no number for; it wrote a string of the exact hexadecimal
form (decision 363), which no other reader takes. `cargo xtask runtimes` runs the standard library's
tests on each target the machine runs: the runtimes are code of their own, and the machine's tools
file says which it can run (decision on `vun/tools.vun`, spec 12 section 6)
