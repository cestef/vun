# 316. Structured data is read and written through typed values

Status: accepted
Where: 13

Structured data is read and written through typed values (the crate first named `vun-json`, now
`vun-data`, 320): its `ToData` and `FromData`, derived by `vun-data-derive` (a struct of named
fields is an object, an absent option left out, `#[data(flatten)]` merged; one unnamed field is
itself; an enum of unit variants a string or, `#[data(number)]`, its discriminant;
`#[data(untagged)]` its variant's value; names cased by `#[data(case = camel)]`); reading fails with
a `Mismatch` naming what was expected where. The workspace's derives share `vun-derive-core` (items
read from their tokens with their helper attributes, tokens built tree by tree);
`#[derive(Variants)]` gives an enum of unit variants its `ALL`
