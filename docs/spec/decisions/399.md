# 399. A local is a binder a body binds

Status: accepted
Where: 1

A local is a binder a body binds: not a member of a namespace, whether declared in it or selected by
a spread (`Hir::is_local`). A name a spread selects, as `holes` in `..std.fmt.places.{ holes }`, is
a member, so `$` forms may read it
