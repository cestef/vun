# 130. `#[layout.c]` struct

Status: accepted
Where: 05

`#[layout.c]` struct: the default layout (C's on every target described), and each field of a type C
reads the same way: full-width integers, `bool`, `f32`, `f64`, `*T`, `?*T`, `#[abi.c]` functions and
`?` of them, arrays of these, `#[layout.c]` structs; at least one field (`layout.not_c`)
