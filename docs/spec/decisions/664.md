# 664. `vun debug profile` measures the compiler and the programs it builds with the

Status: accepted

`vun debug profile` measures the compiler and the programs it builds with the workloads declared in
`vun-profile` (`check-*`, `build-*` over corpus programs, `run-*` over `corpus/bench`). Instructions
are counted under callgrind with one thread, which repeats where wall time does not, and attributed
to crates and functions with the cost of a function's callees only where it is outside a call cycle;
time is sampled from `--timings` and ranked by stage and query with its spread. Results are
snapshots under `.vun/profile/<name>.json` that a later run is compared with by the `Comparison` of
the benches.
