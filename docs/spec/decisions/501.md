# 501. `lang.arch.wasm32` declares the atomic instructions of the threads proposal

Status: accepted
Where: 07, 13

`lang.arch.wasm32` declares the atomic instructions of the threads proposal (prefix `0xfe`:
`memory_atomic_notify`, `memory_atomic_wait32` and `64`, `atomic_fence`, atomic loads, stores, and
the read-modify-write forms `add`, `sub`, `and`, `or`, `xor`, `xchg` and `cmpxchg` at each width),
each needing the new feature `atomics`, which `wasi.wasm32.p1` declares. They are table data only:
the encoder already writes a prefix, a code and memory operands
