# 658. Commands show progress

Status: proposed
Where: 12
Note: the user asked for progress and verbosity in every command; chose multi-bar and levels

Commands show progress. `-v`/`--verbose` is global (`-v` a status line per file, `-vv` and more the
compiler's log); on a terminal `vun-term`'s `Progress` draws a bar per task on standard error (the
stage line fed by `vun_trace::Live`, counted bars for files, tests, chunks and download bytes) that
the streams take off the screen around every write and never draw inside a line; none is drawn off a
terminal, for `--format json`, `--quiet` or while logging
