# 507. `lang.arch.wasm32` declares the 236 vector instructions of the SIMD proposal

Status: accepted

`lang.arch.wasm32` declares the 236 vector instructions of the SIMD proposal (prefix `0xfd`, in the
`simd_*` files, taken from the operator list of `wasmparser`), each needing the new feature
`simd128`, which `wasi.wasm32.p1` declares. A vector is a stack position of the new class and type
`v128` (`ValType::V128` in the object format and the verifier); no Vun type is held as one, so a
block cannot bind one to a local, and a LIR constant of one is `Missing::Vector`. A lane is an
unsigned 8-bit immediate and `v128_const` takes two 64-bit ones. | 07, 13
