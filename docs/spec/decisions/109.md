# 109. `unsafe` is a single marker

Status: accepted
Where: 07
Note: the user chose one generic marker

`unsafe` is a single marker: `unsafe x` means `x` is used only where someone vouched for it; an
expression is vouched for where written, a function or function type at each call (its body gets no
permission). Function types carry markers (the table `markers` maps `unsafe` to
`lang.safety.unsafe`) as a third argument of `lang.Fn`, in the slot meant for every spec 07 section
4 property; a function lacking a marker is accepted where one with it is expected. The typer counts
enclosing `unsafe` expressions and reports calls through marked types, raw `.*`, top-level `mut`
accesses and `Cell` members (`typeck/safety.rs`)
