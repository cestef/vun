# 149. Typed, never spelled

Status: accepted
Where: 13, appendix B

Typed, never spelled: a borrow mode is a row of the table `borrows` (`Borrow`) from HIR
(`ExprKind::Borrow`) to MIR (`Rvalue::Ref`), words naming no row being `syntax.unknown_borrow`;
tables name `lang` members by path (`"lang.Step.yielded"`), generated as handles, which exist for
the members of type constructors and interface requirements; a table's `interface` is the parent of
its `function`; rows of several fields are named structs
