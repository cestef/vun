# 336. `$if` tests a pattern as `if` does

Status: accepted
Where: 03

`$if` tests a pattern as `if` does (the owner's choice): its binders are compile-time, the selected
branch is a step of its own (`Step { at: pat, index: 0 }`) typed and built with them bound, among
statements and as a value (`Selected::Tested`); `Env::tested` decides every staged condition
