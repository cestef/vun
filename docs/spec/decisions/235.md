# 235. `std.sync.Shared(T)` is reached only by value under a `&Critical`

Status: accepted
Where: 07
Note: the user's choice

`std.sync.Shared(T)` is reached only by value under a `&Critical`: `get` (a copy), `set`, `replace`
and `update`. It used to lend `&mut T`, which two calls or two nested sections could hold at once,
aliasing in safe code
