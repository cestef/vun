# 479. An annotation that is neither a type nor an interface

Status: accepted
Where: 02

An annotation that is neither a type nor an interface (nor a requirement not provided yet) is
`types.mismatch`, "expected a type": a struct literal of `Pair { .. }` for `Pair := ($T: type) ->
type` reported nothing and ended in `backend.unlowered`. `[_]u8` is written where an initializer
gives its length; elsewhere, `&static [_]u8` included, it is `types.hole_length`, and the library
writes `&static [u8]`
