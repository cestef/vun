# 150. LIR

Status: accepted
Where: 13

LIR (`vun-lir`): scalar SSA values with block parameters, aggregates in memory, typed ids for
functions, data and imports, link symbols only on exports and imports; Vun's convention passes
values in memory by address (`AbiType::Memory`), the C convention as records; traps call
`lang.panic.trap` with a site of the unit's message table; a verifier (dominance, types, targets)
and a text format
