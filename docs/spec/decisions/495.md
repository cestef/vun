# 495. `#[comptime.deferred]`

Status: accepted
Where: 03

`#[comptime.deferred]` (`lang.comptime.deferred`) on a function with `Code(T)` parameters makes the
code it splices run with the program: the MIR builder never evaluates the splice at compile time
(spec 03, section 4). `std.testing.assert` is marked, because a constant condition (a hash of a
literal, a float parsed from a literal) was evaluated by the compiler's interpreter and folded away:
the test then checked the interpreter, not the target's code, and every `assert` of the standard
library ran about 80 000 compile-time calls (a cold `vun test lib/std` fell from 25 s to 9 s on
`am3` with it and the fixes of the evaluator, the register allocator and slot promotion). Branches
and switches on a value recomputed where used now declare the scratch register they take
(`term_needs`)
