# 480. Scalable vectors, first as a library over the target's width

Status: accepted
Where: 04, 13

Scalable vectors, first as a library over the target's width: `lang.target.Spec.vector_bits`
(default 0, 128 on x86-64 and arm64) gives `std.simd.Scalable(T)` its lane count,
`std.simd.lane_count(T)` (one where there are no vector registers); `V.cover(left)`,
`V.load_partial(xs, fill)` and `V.store_partial(v, to)` cover a sequence of any length without a
scalar tail, and code using them assumes no width, so it runs as the same program on every target (1
lane on `linux.arm`, 4 of `f32` on x86-64 and arm64). Rather than a `lang.simd.Scalable` primitive
now (decision 44): no backend emits vector instructions, so a sizeless type would have nothing to
