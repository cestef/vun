# 303. Inlining per function

Status: accepted
Where: 13
Note: a new project spent ~350 ms inlining the libraries' functions again

Inlining per function: simplifying's second phase is a query per function (`InlinedLir`, keyed by
`Inlining`: the piece and the program's `Unchecked` functions in a canonical order), reading its
callees' inlined LIR, placing them in its own tables through the placement the unit's assembly uses
(`Places`), inlining and tidying; a library function's is shared like its LIR; trap sites are placed
once per site
