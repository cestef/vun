# 561. `BTreeMap` gives its keys in a range

Status: accepted

`BTreeMap` gives its keys in a range (`range(lower, upper)`, `lower` inclusive, `upper` exclusive),
greatest first (`entries_rev`), and taken away in order (`drain`), and `get_or_insert` gives the
value of a key, put there when it had none. The walks are methods of `Pool`, which holds the path of
nodes above the one visited.
