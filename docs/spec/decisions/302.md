# 302. Durability

Status: accepted
Where: 13
Note: the user asked for architectural gains; `--memos` showed 14.4k library memos verified for a small program

Durability: `Sharing` is `Own`, `Chosen` (the target, the checks) or `Shared` (a library's sources);
a memo's level is the least of its reads', and it is saved with the fingerprint of the inputs of its
level or more shared when it last held (`SavedMemo::under`), holding at once while that fingerprint
is the same; an input not set stays out of every fingerprint; verifying ahead claims each memo for
one thread (`Found`)
