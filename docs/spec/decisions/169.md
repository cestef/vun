# 169. Integers wider than a backend computes with are legalized in LIR

Status: accepted
Where: 13

Integers wider than a backend computes with are legalized in LIR (`Unit::legalize`,
`BackendCaps::int_bits`) into pairs of halves before the backend runs: arithmetic, comparisons,
shifts, memory, control flow and calls over halves, a wide result a record of halves, division
through a helper function the pass adds; both the C and the baseline backend compute 64-bit wide and
so run 128-bit integers. The C backend places a stack slot aligned past every C type in a larger
array, rounded up at entry
