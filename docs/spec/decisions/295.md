# 295. A local declared with a value existing at compile time only

Status: accepted
Where: 03

A local declared with a value existing at compile time only (`Exists` false for its type: a
namespace, a type, a name), immutable and bound whole, is known at compile time as a `$` local is:
the typer stages it `Compile` and the evaluator reads its declaration (`Env::declared`), so `arith
:= lang.float.soft.arith; arith.add(..)` and `T := u8; x: T = 7` work in run-time bodies
