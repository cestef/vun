# 97. Borrow rules on MIR

Status: accepted
Where: 05

Borrow rules on MIR (query `BorrowChecks`): each `&mode place` is a loan held by the locals its
value flows into, a scoped value (query `Kinds` now gives duplication and region: borrow types and
anything holding one are scoped, raw pointers free, frames free until their parameters are read)
holding the loans of what it is built from, so a call's scoped result is tied to all its arguments'
loans. A loan lives while a local holding it is live; an access to an overlapping place while it
lives is `borrow.conflict` when the loan or the access is exclusive (the table `borrows` gains the
column `access`; a write is exclusive, a read shared); distinct fields, positions and payload items
are disjoint, run-time indices are not. A loan of a place not reached through `.*` in the result at
a return is `borrow.escape`. Writing a place does not conflict with loans reached through a `.*`
inside it (reassigning a borrow). A receiver is borrowed after the arguments are evaluated (decision
101)
