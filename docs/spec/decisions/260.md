# 260. Compile-time work in a body splits into expansions

Status: accepted
Where: 03, 04

Compile-time work in a body splits into expansions (`$if`, `$for` generating code), run while typing
since types depend on them, and evaluations (a `$e` typing does not need, such as `$assert`), run
once the body is typed with its types (`typeck::Reported`), so a code value evaluates at its site
with the site's types and no evaluation reads a body still being typed. An evaluation that surely
runs and uses a form not evaluated yet is `comptime.unsupported`. Where a float type is expected,
the typer gives it to the operands of the operator giving it, as evaluation does
