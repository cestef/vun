# 90. A top-level declaration

Status: accepted
Where: 08, 13

A top-level declaration `name: T = _;` outside `lang` has a value: its link symbol
(`Value::Linked`), which MIR calls and passes like any function value and which compile-time
evaluation cannot run; `[v; n]` evaluates at compile time and is `Rvalue::Repeat` in MIR
