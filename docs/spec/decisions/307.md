# 307. Kernel targets link `-static -nostdlib` and name the C compiler's helper

Status: accepted
Where: 08, 13
Note: the user asked to replace the hacks linking 32-bit Arm

Kernel targets link `-static -nostdlib` and name the C compiler's helper library after their objects
(`lang.target.CCompiler.libraries`, `-l gcc`): no C library, start files or unwinder (`libgcc_eh`),
which programs without unwinding never call; on 32-bit Arm `std.os.linux.kernel` exports the EABI's
division-by-zero hooks (`__aeabi_idiv0`, `__aeabi_ldiv0`) as traps, which GCC's Linux `libgcc`
otherwise answers through the C library's `raise`
