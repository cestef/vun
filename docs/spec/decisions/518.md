# 518. `std.Dyn(I)`

Status: accepted
Where: 02, 03
Amended by: 646

`std.Dyn(I)` (`std.dyn`) is dynamic dispatch as a library: a table struct with a field per function
requirement of `I(Dyn(I))`, the types they have for `Dyn(I)` itself, and a pointer to the target;
each requirement is a method of `Dyn(I)` (a `&mut` or shared borrow receiver, written by `$if` on
the receiver's type) calling the table's function with the target read back as the receiver, and
each member of `I` with a value (a default method, `Error := ...`) is a member of `Dyn(I)` as
`I(Dyn(I))` has it, so defaults call through the table; `Dyn(I).of(T, p)` is `unsafe` and the `Dyn`
does not own its target; a requirement taking `Self` by value or `$` parameters has no entry, and a
type requirement (`Error: type = _`) names no type for every target, so an interface used with `Dyn`
gives such types a value; the table is held by value (one word per requirement) rather than behind a
static pointer, which would need `function_cast` at compile time
