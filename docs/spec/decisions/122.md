# 122. A top-level binding reached as a place is its program-long storage

Status: accepted
Where: 01, 02, 13

A top-level binding reached as a place is its program-long storage (MIR `Role::Static`), whose
borrows never escape; `.name(args)` where a type is expected calls the type's member `name` when it
is no variant, at compile time too; a name bound to a member of a `struct` literal written inside a
compile-time call means that member of the type the call made (`G` in a method of `M(u8)` is
`M(u8).G`)
