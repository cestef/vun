# 315. `std.fmt.print($W, w, $format, ..args)` takes its arguments as a pack

Status: accepted
Where: 03, 08
Note: the user's request

`std.fmt.print($W, w, $format, ..args)` takes its arguments as a pack (285), one per `{}`, instead
of a tuple literal: `print(w, "{} and {}\n", a, b)`, `print(w, "plain\n")`
