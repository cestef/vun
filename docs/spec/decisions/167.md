# 167. Floats

Status: accepted
Where: 04, 13

Floats: a float literal has the float type expected of it; compile-time floats
(`vun_sema::float::Binary`) are exact values rounded once to nearest even per format, `f16`
included, NaN payloads unspecified; lowering maps `lang.float` to LIR (`!=` as `==` negated, since
LIR's float comparisons are ordered; negation flips the sign bit; `total_order` compares the bits as
signed keys), `lang.int.compare` and `total_order` write a `lang.Ordering`; the baseline holds
floats as bits in general registers and computes through SSE, passing them per System V classes
