# 661. Help pages list an option set by its detail

Status: accepted
Where: 12, 13

Help pages list an option set by its detail (`OptionSet.detail`): the compile options a command
takes are the usual ones (`--target`, `--lint`, `--release`, `--diagnostics`) on every page, the
run-time check options (`--checks`, `--cover`, `--trace`) and the profiling ones (`--timings`,
`--timeline`, `--memos`) on the long page only. A session whose target is not chosen keeps no
queries, since everything reading the target was computed without one
