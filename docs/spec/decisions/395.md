# 395. `vun fmt` breaks what runs past a width, 110 columns unless asked another

Status: accepted
Where: 13
Note: the user's approval

`vun fmt` breaks what runs past a width, 110 columns unless asked another (`vun_fmt::WIDTH`, the
width of `rustfmt.toml`; `--width`): the outermost group on the line holding the first column past
it, one entry a line (a group holding only one group that closes with it breaks that one), else the
line is continued before an infix operator; it takes paths as the other commands do, a file, a
directory or a package, the package around the current directory with none. The fix allowing a lint
puts its attribute on a line of its own above the declaration, at its indent
