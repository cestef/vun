# 318. The language server's messages are typed

Status: accepted
Where: 13

The language server's messages are typed (`vun-lsp-protocol`: each value a struct or enum over
`vun-data`, each method a type naming its parameters and result); a row of the server's table is a
method's type, whose handler reads and writes it (`Answers<R>`, `Hears<N>`). Documents change by
edits (incremental sync); positions count UTF-8, else UTF-32, else UTF-16. Besides diagnostics,
hover and definition it answers the outline (declarations from the syntax tree, a struct's fields,
an enum's variants and namespace), folds (delimiter pairs, raw string and comment runs), formatting
(one edit of what `vun fmt` changes) and semantic tokens (lexical classes from the grammar's tables,
names by what they resolve to, a declaration by the value sema computes)
