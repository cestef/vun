# 329. Board peripherals are tokens `Peripherals` holds, made by an `unsafe` claim

Status: accepted
Where: 08

Board peripherals are tokens `Peripherals` holds, made by an `unsafe` claim; registers are
`std.hw.Reg` fields of a `#[layout.c]` struct borrowed at the device's address by `std.hw.at`. A
timer's wait is `Event.wait` on the event its interrupt handler fires. A function exported by a
declaration naming it (`trap := config.trap`) is exported under that declaration's symbol. Bare
targets link the compiler's helpers (`libgcc`)
