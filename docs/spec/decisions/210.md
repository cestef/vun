# 210. A run-time binding holding a slice `[T]` by value is reported by the typer as

Status: accepted
Where: 02

A run-time binding holding a slice `[T]` by value is reported by the typer as `types.slice_value`,
with a fix inserting the borrow, instead of reaching lowering as `backend.unlowered` (the slice has
no layout); the rule restates spec 02's "reached through a borrow" for bindings
