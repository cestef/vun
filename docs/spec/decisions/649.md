# 649. A lint sees the types typing finds

Status: accepted

A lint sees the types typing finds. The walker types each function literal it reaches as an
instantiation binding no parameter (`Typed`, the memo checking shares), and a local's facts come
from that body: `lang.lint.Local.mutable` and `.pinned` (its type holds one integer).
`std.lints.suspicious.pinned` reports a mutable pinned local (`mut n := 0` traps at `n += 1`). A
generic function's locals whose type depends on a parameter have no type there and are not judged.
