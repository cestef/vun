# 71. Conditions are data

Status: accepted
Where: 01, appendix B
Note: on the agent's recommendation

Conditions are data: the table `forms` of `lang.syntax.desugar` names the condition type
(`lang.bool`) and the value on which a condition holds (`lang.bool.true`); the other value of the
condition type is falsity; an `if` with `else` has the join of its branch types (integer hull, else
equal types); the desugaring tables move from `grammar.vun` to `desugar.vun`
