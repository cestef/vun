# 402. A method that is another witness's, as `Debug` of an integer is `Format`'s, is

Status: accepted
Where: 2

A method that is another witness's, as `Debug` of an integer is `Format`'s, is an alias of it:
`debug := lang.meta.witness(std.fmt.Format, Int(r)).format;`, which needs no form of its own. An
interface declaration is a literal `interface(...)`, never a call computing one: finding the
witnesses of a type evaluates the interfaces its impls name, and `Derives` the value of each
`#[lang.derive]` one, so a constructor whose typing consults witnesses makes a cycle of memos, which
verifying a stored build ahead explores exponentially (a hang, not an error). The five interfaces of
one method writing a value to a writer are five declarations for that reason
