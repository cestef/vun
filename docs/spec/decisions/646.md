# 646. `std.Dyn(I)` checks the requirements of `I` when its table is built and reports

Status: accepted
Where: 02

`std.Dyn(I)` checks the requirements of `I` when its table is built and reports one that is no
function or whose first parameter is no borrow of `Self` (`comptime.reported`), instead of leaving
it without an entry; `std.dyn.OwnedDyn(I)` owns its target in memory from an allocator and runs the
`finish` it was made with on the target when it ends (decision 518 kept the `Dyn` non-owning). The
table stays held by value: a constant of function pointers cannot be borrowed as `&static`, and
`function_cast` is not known when compiling (decision 520)
