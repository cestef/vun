Status: accepted
Where: 13

Every editor's queries are written general patterns first, the last matching pattern winning (Helix
too, since 25.07), and a type written in a field `type` (`param`, `returns`, `typed_binding`,
`field`, `typed_lit`), a name or the last of a path, is captured as a type; a place of `editors.vun`
names several kinds (`.kinds`), as a binding does. The C sources a tool compiles for the parser
follow from the grammar (`Grammar::sources`: `scanner.c` only with external tokens). The language
server shows the type of an expression outside any function from its declaration's typing, leads a
member of a type's namespace (declared or spread) to its declaration, and names the toolchain's
library by its real path
