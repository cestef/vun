# 356. Every command taking a root file takes a path instead, optional

Status: accepted
Where: 12
Note: the owner asked for it

Every command taking a root file takes a path instead, optional: a file, a directory (a namespace)
or a package's directory, and with none the package around the current directory (its nearest
`build.vun`), as cargo finds `Cargo.toml`; names filtering what runs come after it.
`vun_driver::subject::Subject` is what a path names (`Loose`, `Package { dir, within }`,
`Workspace`), `Session::subject` and `files` resolve it: `check` and `fix` cover every file named, a
package's with its plan; `build` carries out a package's plan; `run` runs the program the plan
builds when there is one (`plan.nothing_to_run`, `plan.ambiguous_run`); `test`, `bench` and `doc`
take a package's root namespace; a directory outside any package is `package.no_project`
