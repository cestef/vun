# 133. Rust names declarations of `lang` and `std` through generated handles

Status: accepted
Where: 13
Note: the user's request

Rust names declarations of `lang` and `std` through generated handles (`vun_items::Item`, one per
public declaration and namespace, spelled as the declaration: `vun_items::lang::int::unsigned`),
never by strings: `Env::item`/`site` take them, tables' `item` and `interface` columns are them,
each primitive has its `item()`; generated Vun source is built with `vun_syntax::make` and one
printer
