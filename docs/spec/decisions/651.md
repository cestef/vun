# 651. Tail calls reach every backend but Cranelift and QBE

Status: accepted
Amended by: 653

Tail calls reach every backend but Cranelift and QBE: Thumb pops the link register and branches,
wasm releases the frame and `return_call`s, C needs `lang.target.TailCalls` (`none` by default,
`musttail` for the stock gcc and clang descriptions, so an old compiler that would ignore the
attribute is never assumed). A tail call in a coroutine function is `flow.tail_position`. Stack
bounds count a tail-call cycle as the largest frame among its functions (`StackUse`)
