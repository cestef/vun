# 334. Compile-time evaluation while a body is typed reads everything typing found so

Status: accepted
Where: 03

Compile-time evaluation while a body is typed reads everything typing found so far, shared
(`Arc<Found>`, written through `Arc::make_mut`) rather than copied; an annotation or `$` argument
that evaluates only once typed is typed then, in one place (`Typer::known_value`); a call leaving
`$` arguments out does not evaluate before typing infers them, rather than passing its arguments to
the wrong parameters; a call whose value exists at compile time only is known then (`TypeOf(x)` of a
run-time `x`)
