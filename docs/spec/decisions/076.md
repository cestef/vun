# 76. An impl's `T` may be a type constructor

Status: accepted
Where: 01, 02
Note: the user chose impls for methods of built-in types; the rest, including the spelling of constructor impls, on the agent's recommendation

An impl's `T` may be a type constructor (`lang.Int`, or a function returning a type): the impl
covers every type it makes, and its value is a function of the constructor's arguments giving each
witness (`#[impl(Narrow(Int))]` on `($r: Range) -> type { struct { ... } }`); methods of built-in
types come from such impls in `std`, one mechanism for every type. A file sees the impls of its
package and of its transitive dependencies. Method lookup is the type's namespace, then its
witnesses, then the defaults of their interfaces
