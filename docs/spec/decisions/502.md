# 502. A backend that writes no block of inline assembly in the function holding it

Status: accepted
Where: 13
Amended by: 508

A backend that writes no block of inline assembly in the function holding it (`Feature::InlineAsm`:
native, C and wasm have it) gets each block outlined before it reads the unit
(`vun_lir_passes::Outline`), so Cranelift hands the assist only the blocks and not every function
that holds one. A block naming a register (`Block::names_registers`) keeps its function whole, as do
naked functions, functions bound by `#[stack.max]` and functions of nothing but asm. Measured on the
backend tests: the runtime's functions are the asm, so almost nothing moved (one function in 5,400),
and the pass matters for code mixing asm with other code. `Feature::CAbi` states what it is: a
backend without it refuses a record by value, and no driver pass lowers it
