# 118. No bespoke formats in the ecosystem

Status: accepted
Where: 12
Note: the user's request

No bespoke formats in the ecosystem: the lockfile is a Vun literal file, `lock.vun` beside
`build.vun` (declarations `version`, `deps` with one sorted entry per line: `.name`, `.version`,
`.id` as `.foreign` or `.{ .id, .major }`, `.hash`, `.via`; and `replace`), read by the literal
reader and written by its printer, no source namespace; packages are published as `.tar.zst` (`pkg
pack` writes `<name>-<version>.tar.zst`, indexes serve `<version>.tar.zst`), `.ovpkg` dropped; file
names derive from the source extension. Supersedes the formats of 51, 53, 54, 55 and 60
