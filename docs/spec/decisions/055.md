# 55. Minimal version selection runs over the packages present

Status: accepted
Where: 12
Note: its format superseded by 118

Minimal version selection runs over the packages present; every dependency resolves to the version
selected for its identity; `vun.lock` records every required version (`dep name version id/major
hash [via dependent]`, the id in 16 hex digits), the selected one being the largest, written by `vun
pkg fetch` and `add`; the edition is 2026
