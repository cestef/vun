# 81. `&e` is typed through the table `borrows`

Status: accepted
Where: 01, 04
Note: on the agent's recommendation

`&e` is typed through the table `borrows` (a borrow of a type is a type), `unsafe e` and `#[attrs]
e` have the type of `e` (attributes on an expression are data, read where they act), struct patterns
bind fields by name or position, and each branch of an `if` or `match` is checked against the
expected type where it is written; `corpus/accept/syntax/patterns.vun` had two genuine overflows
(`u32` squared times 3 in `u64`, a signed area), now `circle(u16)` and `.to(u64)`
