# 206. `vun-object` writes Mach-O 64-bit objects

Status: accepted
Where: 13

`vun-object` writes Mach-O 64-bit objects (`Format::MachO`, chosen by the target's `object_format`)
for arm64: one unnamed segment, `LC_BUILD_VERSION` for macOS 11, symbols as C names with Mach-O's
underscore ordered locals, defined, undefined, `ARM64_RELOC_*` with addends in place for words and
in `ARM64_RELOC_ADDEND` for instruction fields, DWARF in `__DWARF` (section offsets unrelocated, as
Mach-O objects keep them); the native backend refuses a format it does not write for the machine
(`Missing::Format`). Apple's AAPCS64 already holds for registers (`x18` is never allocated, narrow
arguments are extended by the caller); linking is left
