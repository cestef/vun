# 101. Two-phase receivers

Status: accepted
Where: 01, 05
Note: the user accepted the review's proposals

Two-phase receivers: in `a.f(b)`, the place `a` (with its indices and the hops `.` takes) is
computed before the arguments, and the borrow the first parameter asks for is taken after them, so
`v.push(v.len())` does not conflict; a receiver taken by value is read first. A borrowed receiver
reborrows through `.*` rather than borrowing the local holding a borrow
