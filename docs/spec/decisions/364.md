# 364. A toolchain is a directory holding `bin/vun` and its library in `lib/`

Status: accepted
Where: 12
Note: the user chose the layout and the variable

A toolchain is a directory holding `bin/vun` and its library in `lib/` (`lang`, `std`, `targets`,
`boards`, the explanation pages), so a release archive runs wherever it is unpacked, as the
launcher's cache will: `vun` reads the library `VUN_LIBRARY` names, else `lib/` beside its `bin/`
when it holds every default dependency (`DEFAULT_DEPS`, each `build.vun`), else the checkout it was
built from (`vun_driver::packages::Library`, `Found::{Named, Installed, Checkout}`, logged under
`vun_driver=debug`); the explanation pages are read from the session's library, which was the
checkout's always
