# 352. Attributes are reflected

Status: accepted
Where: 03
Note: the owner asked for `std.meta.attr` whole

Attributes are reflected: `lang.meta.Field` and `lang.meta.Variant` hold `attrs: &[lang.meta.Any]`,
the values of the attributes written on them (a variant's, dropped by lowering before, are kept in
the HIR), evaluated where the type was built; `lang.meta.value(T, a) -> ?T` gives what an `Any`
holds when it is a `T`; `std.meta.attrs`, `attr(d, A) -> ?A` and `has(d, A)` (a marker type or a
value of it) take the descriptor as `$d`, attributes being compile-time data
