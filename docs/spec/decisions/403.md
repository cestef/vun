# 403. A function literal that is the value of a declaration annotated with a function

Status: accepted
Where: 2

A function literal that is the value of a declaration annotated with a function type takes, from
that type, the type of each run-time parameter it writes without one, at its position, and its
result when it writes none; a parameter past the type's is untyped, and a literal of fewer
parameters is a mismatch with the annotation (`Env::signature`, read by `literal_signature` and by
typing the body, so calls, compile-time evaluation and lowering agree): `add: (a: u16, b: u16) ->
u16 = (a, b) { ... }`. A literal elsewhere, such as an argument, still types its parameters where
they are written; taking them from the parameter it is passed for is open, as is taking an impl
member's from its interface
