# 681. The binder reads the attributes written on a type, units being parsed with

Status: accepted
Where: 07

The binder reads the attributes written on a type, units being parsed with
`CXTranslationUnit_IncludeAttributedTypes`: a pointer `_Nonnull` binds as `*T`, any other as `?*T`
(`Type::is_nonnull`). Nullability that only an `__attribute__((nonnull))` on a function or a comment
says is not read, and binds nullable
