# 517. A compile-time call costs memory by nesting level

Status: accepted
Where: 03, 13

A compile-time call costs memory by nesting level: each level keeps its arguments, locals, result
and memos, and the frames of the Rust calls one level goes through (about 12 KB a level in the dev
profile, measured by recursion through an annotation). A function and a code value are shared
(`Func` and `Code` hold an `Arc` of their parts and dereference to them), so a `Value` is 72 bytes
where it was 120 and a level costs about 8 KB (heap 3.5 KB: memo reads, the keys of the call's
memos, locals; stack 4.8 KB over the nine frames of a level, from 6.6 KB); `vun-sema-ty` tests that
a value stays within 80 bytes. The step budget is unchanged
