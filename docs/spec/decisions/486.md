# 486. An operand passed as asked that is a temporary is stored as the type expected

Status: accepted
Where: 02

An operand passed as asked that is a temporary is stored as the type expected of it, or, where a
slice is expected, as an array of that slice's items (`Typer::stored`), as a borrow of a temporary
is (482): `v.items() == [10, 20]` compares `u32` items, not the 1-byte ones of the literal's own
range
