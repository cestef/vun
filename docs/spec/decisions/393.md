# 393. An interface marked `#[derive(f)]`

Status: accepted
Where: 02
Note: the user's approval

An interface marked `#[derive(f)]` (`lang.derive`) gives a struct or an enum with no impl of it the
witness `f(T)`, when every field and variant payload of it has the interface too (`Witnesses`, with
the query `Derives` finding the marks): `lang.ops.Eq` is marked with `derive_eq`, which moves from
`std.cmp` to `lang.ops`, and `std.hash.Hash` with `derive_hash`, so `==` and hashing of structs and
enums need no hand-written impl. `std.hash` holds `Hasher`, `Hash`, the `Fnv` hasher and impls for
integers, `bool`, slices and arrays; `Format` gains `bool`
