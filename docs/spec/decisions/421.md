# 421. The command line sets lint levels

Status: accepted
Where: 10, 12

The command line sets lint levels: `--lint lint=level`, repeatable, overrides the build (spec 10,
section 4). A name is a lint's or a group's binding path; it is resolved against the lints and
groups the packages the command names see (`CheckedLints`), a name matching none is `lint.unknown`
with a did-you-mean, and a level that is none of `lang.lint.Level`'s is `cli.invalid_value`. The
levels are the query input `LintLevelsOf` (`vun_sema::lint::LintLevels`), scoped to those packages,
so the command line configures the code the command names, never the libraries it reaches; a pair
naming the lint wins over one naming its group, the last written wins, the command line wins over
the build, and `forbid` from any source is final
