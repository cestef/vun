# 168. Commands are organized as jj's

Status: accepted
Where: 12, 13
Note: the user's choice

Commands are organized as jj's: verbs at the root, nouns as groups of verbs, `util` for infrequent
commands (`lsp`, `completion`), `debug` for compiler development (every representation with origins,
`compare` across backends); `toolchain` holds `components`. `BackendInfo.readiness` says whether a
backend generates code; `Session::run_each` builds and runs through each one that does. Lowering
names an unhandled primitive (`Why::Primitive`), and MIR building, lowering and both backends trace
per function and statement (`VUN_LOG`)
