# 439. The RP2350 board's default trap records the trap site in the watchdog scratch

Status: accepted
Where: 08
Amended by: 449

The RP2350 board's default trap records the trap site in the watchdog scratch registers and reboots
into BOOTSEL as a fault does (`rp2350.fault.trap`; `Config.trap` defaults to it, `rp2350.halt` stays
for a probe); `fault.take` returns a `Stop`, a fault or a trap
