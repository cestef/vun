# 178. Origins are equal and hashed by their anchored identity

Status: accepted
Where: 10, 13

Origins are equal and hashed by their anchored identity; two entities lowered from one piece of
syntax get origins of their own (the further ones derived with `Via::Again(n)`), which the HIR
verifier checks; syntax nodes (`ExprRef`, `DeclRef`) order by their place in their file; the tables
handles index (`SourceFiles`, `OriginTable`) are the process's, as interners are, since interned
values hold handles; a file is the same entry only for the same key, shown path and text;
diagnostics sort by source position
