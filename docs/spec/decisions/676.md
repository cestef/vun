# 676. A runtime exports the heap and the environment as it does the library loader

Status: accepted
Where: 08
Amended by: 683

A runtime exports the heap and the environment as it does the library loader (decision of
`std.os.library`): `std.os.heap` (`take`, `give`; `Heap` is an `Allocator` over them) and
`std.os.env` (`get`; `System.env`), each with an `unsupported` export set for a runtime lacking
them. The C library's runtime provides them over `malloc`, `free` and `getenv`; the kernel, WASI and
Windows runtimes refuse every allocation and set no variable until they are given an allocator and
an environment of their own
