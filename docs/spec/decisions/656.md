# 656. `witnesses` finds the impls and derived interfaces that cover a type

Status: accepted
Where: 02, 13
Note: found profiling the compiler fuzzer: 40% fewer compile-time calls per program, a fifth less memory

`witnesses` finds the impls and derived interfaces that cover a type (`Candidate`), and each one's
witness is made when asked for (`resolved`), so asking which interface a type has, or an operator's
function, makes the witnesses of the impls asked about, not of all (about 25 for an integer type);
method lookup by name still makes them all. A derive is a candidate once every part of the type has
the interface
