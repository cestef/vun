# 162. `stack.max` is checked when the program is built

Status: accepted
Where: 07, 13
Note: the user's choice for imports

`stack.max` is checked when the program is built (`stack.exceeded`, `stack.unbounded`,
`stack.unreported`): worst-case stack use over the unit's call graph (`vun_lir::analysis::StackUse`)
from reported frames; recursion and calls through an address are unbounded; an import states its
stack use with `#[stack.max(n)]` on its `= _` declaration, trusted as its signature is, and one
without is unbounded. `stack.depth(k)` is not implemented yet
