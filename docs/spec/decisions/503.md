# 503. The Cranelift backend lowers C records by value itself, from `vun_abi::Passing`

Status: accepted

The Cranelift backend lowers C records by value itself, from `vun_abi::Passing` (parts in registers
as scalars and multiple returns, struct arguments on x86_64, copies by address on arm64, struct
return), and refuses a signature whose placement Cranelift's own rules would not reproduce
(`Missing::Placement`); the shared LIR pass for it was dropped since LIR has no multiple results or
by-value memory arguments.
