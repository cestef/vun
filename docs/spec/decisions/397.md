# 397. A place has the type typing found for its expression

Status: accepted
Where: 1
Note: the user's approval

A place has the type typing found for its expression. A run of items reached through a borrow,
`xs[a..b]`, is typed as a borrow of the run, so it is a value, held like any other: `.`, indexing,
`.*` and `&` of it follow from that type, and a borrow in a type is one dereference wherever it is
looked through. A run of an array by value is typed as the slice it is, which is storage that `&`
borrows. Compile-time method dispatch on an array value takes the type typing found, not the type of
its items in common, so a method's `T` is the declared one
