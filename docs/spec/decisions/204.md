# 204. The native backend writes DWARF 4 line tables

Status: accepted
Where: 10, 13

The native backend writes DWARF 4 line tables (`vun-dwarf`: `.debug_abbrev`, a one-unit
`.debug_info`, `.debug_line` with standard opcodes, addresses and section offsets as relocations;
`vun-object` gains debug sections, section symbols and 32-bit absolute relocations) from marks the
framework now always records, the prologue marked with the function's origin; in every profile, as
the C backend writes `#line` in every profile
