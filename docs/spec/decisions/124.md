# 124. `std.fmt`

Status: accepted
Where: 03, 08

`std.fmt`: `Writer` (spec 02's), `Format`, and `print($W, w, $format, args)`, which splits the
format string at `{}` at compile time (`holes`, `pieces`) and unrolls with `$for` and `$if`, writing
each argument by its `Format` impl (integers in decimal, byte arrays and slices as they are);
`std.os.Stream` implements `Writer`
