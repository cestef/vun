# 489. Fixes found building 488

Status: accepted
Where: 02, 06, 13

Fixes found building 488: a conversion of a float to its own format emits no cast and only
canonicalizes a NaN (it was malformed LIR); a call that binds `$` arguments has the signature of its
instantiation, and a frame made in a generic function records the instantiation its literal was
written in, not its own, so a coroutine function with `$` parameters (`filter`, `map`, `repeat`)
runs in compiled code; `.*` of a value that is not a borrow, a pointer or a type with a `deref` is
`types.not_dereferenceable` (it left the form untyped and failed in lowering); `vun-lower` logs a
callee the program does not hold (`vun_lower::assemble=debug`)
