# 222. Builds keep what they make by content

Status: accepted
Where: 13

Builds keep what they make by content: the build directory is keyed by the artifacts, the C compiler
and the profile, objects are made under a part name and renamed whole and are not made again, and a
link stamp (`.vun/objects/linked/<hash of linker, target and plan>`, holding the hash of the output
written) skips a link whose output is unchanged; a repeat native build of `hello.vun` takes 17 ms
instead of 33, a repeat C build no longer recompiles
