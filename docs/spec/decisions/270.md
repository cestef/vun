# 270. HTML is typed

Status: accepted
Where: 12

HTML is typed (`vun-html`, after `press`): elements compose at run time with their child as a type
parameter and text escaping itself, and `template!` has the Rust compiler bake a document into one
string with its holes, sized from the document and its hole count in the type, each hole escaped for
where it is. `vun doc` writes a page per namespace and JSON from the CST (`vun-doc`), doc comments
rendered from Markdown with code spans naming a declaration linked by path or relative to where they
are written (the user's plan)
