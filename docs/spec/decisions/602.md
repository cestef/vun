# 602. Baselines

Status: accepted
Where: 11

Baselines (spec 11, section 5): `--save` keeps a run's statistics in `.vun/bench/<name>.json` of the
package (`--baseline <name>`, `base` by default, written as data by `ToData`, benchmarks a run does
not measure again are kept), and any run reads the baseline it names, if there is one, and shows
each median's change. A change is a regression when it is past `--fail-over p%` and past the larger
spread of the two runs, so noise alone never fails a run; the run fails only when `--fail-over` is
given. A baseline of another measure is not compared with. `Percent` (`vun-term`) is the value of
`--fail-over` (`Values::Percent`)
