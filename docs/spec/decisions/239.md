# 239. `lang.target.current` is the chosen target as a compile-time value

Status: accepted
Where: 13
Note: the user's choice

`lang.target.current: Spec = _` is the chosen target as a compile-time value, the value of its
declaration (the query `Chosen` gives the `Spec` read and that value; a machine's toolchain file
changes only the tools, which it does not say). An address is 16, 32 or 64 bits; `usize_max` derives
from the width
