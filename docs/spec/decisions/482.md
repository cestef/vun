# 482. A temporary is stored as the type the context expects of it whenever a borrow

Status: accepted
Where: 02

A temporary is stored as the type the context expects of it whenever a borrow reaches it: `&[1, 2,
300]` where a slice of `u32` is expected is an array of `u32` (`TyKind::stored_as`), and an operand
passed as asked that is a temporary, `xs == [1, 2, 300]`, is stored as the parameter's type
(`Typer::stored`); a borrow written as an operand passes its parameter's borrow as its expectation.
A place of narrower items borrowed as a slice of items of another size is `types.mismatch`
(`Typer::reinterprets`) instead of a compiler stop on malformed LIR, as comparing an `i32` array
with a literal compared 1-byte items to 4-byte ones. Rather than converting at the borrow: a borrow
has no storage of its own to convert into
