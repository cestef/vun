# 141. Values and members

Status: accepted
Where: 01, 02, 03, 07

Values and members: every compile-time value has a type (`type` for a type, `[n]T` for an array, `T`
the join of its items, `never` none); a `$` parameter has its value's type where its annotation
accepts it, else the annotation; `.{}` is `()` for the typer as for the evaluator; a member missing
from a type without a namespace of its own (integers, tuples, arrays, borrows, primitives) is
`types.no_member`, a value declaring its members (a type, an interface, a namespace, or a function
making one) staying unknown when not known; a requirement of `I(T)` is the member of that name `T`'s
witness declares, so defaults such as `Writer.write_all` type with `Error`; a type's impls are also
looked up in the file declaring it; a witness that is a type is used as it is (`#[impl(Cx)]`); `&e`
of a temporary holds the value as the expected pointee type where it accepts it (`&7` as `&u8`); the
`Cell` rule of `safety.requires_unsafe` is gone, `Cell` being reached only through `unsafe`
functions (`std.mem` `get`/`set`); `lang.meta.same(A, B)`; `Format` for slices and arrays of any
item (`[a, b]`, bytes as they are); `int_ord`; slices' and arrays' `ptr`
