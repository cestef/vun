# 83. `$for` and `$if` in type bodies are expanded when the members are read

Status: accepted
Where: 03
Note: on the agent's recommendation

`$for` and `$if` in type bodies are expanded when the members are read: each step binds the `$for`
binder (`Staging`), and what it generates keeps its bindings (members, and function values, whose
bodies see them); `$(e)` names are strings known at compile time; a `$` local that is never assigned
has the value of its declaration in the call evaluated in (`$Regs := struct { ... }` names its own
struct)
