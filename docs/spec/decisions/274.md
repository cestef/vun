# 274. A `$` form that surely runs is an error when it cannot be computed where it is

Status: accepted
Where: 03, 10

A `$` form that surely runs is an error when it cannot be computed where it is written:
`comptime.runtime` when it reads a local or parameter bound without `$` (even one holding a
constant), `comptime.unsupported` when it uses statements (so a `mut $` local) or an exclusive
borrow outside a compile-time call, which only the evaluator runs. A `$` form inside another is part
of it and never runs on its own. A diagnostic found in a generic body and again in instantiations
reaching it, equal apart from how it was reached, is reported once, reached the shortest way
