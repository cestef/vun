# 330. macOS links through lld's Mach-O flavor

Status: accepted
Where: 12, 13

macOS links through lld's Mach-O flavor (`ld64.lld`), which reads every fact from the target: its
architecture, its system and the oldest release it runs on (`lang.target.Version`,
`Spec.os_version`), its C compiler's libraries (`System`) and its sysroot. `lang.target.CCompiler`
gains `sysroot`, the directory of the target system's headers and libraries a machine's toolchain
file names (`--sysroot`, `-syslibroot`), and `version_flag`, the option telling the C compiler the
release. The macOS SDK on the owner's hosts is assembled from Zig's MIT-licensed stubs, Apple's
being licensed for Apple hardware only
