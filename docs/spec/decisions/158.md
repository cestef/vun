# 158. A coroutine function's frame type is `lang.meta.Frame(f)`

Status: accepted
Where: 03, 06
Note: the user's choice

A coroutine function's frame type is `lang.meta.Frame(f)` (`$F` inferred from `f`), the result of
its signature, trapping for a function that does not suspend; no function value has a member `Frame`
(`f.Frame` stays the name diagnostics show). `lang.meta.TypeOf` is `lang` source, `($T: type, $e:
Code(T)) -> type { T }`, taking any expression unevaluated (previously declared over `Code(type)`
and never implemented). A quoted argument infers `$` parameters as code of its type, and
compile-time calls take the `$` arguments typing inferred
