# 317. URLs are typed values

Status: accepted
Where: 12

URLs are typed values (`vun-uri`): RFC 3986 references kept as written with typed components (hosts
as registered names, IPv4, IPv6 or `IPvFuture`), `Uri` requiring a scheme and `Reference` not,
resolution (section 5.2), normalization (section 6), a builder escaping each component, and file
URIs (RFC 8089) both ways. A manifest's `.urls` and `.index` are URLs, checked when read
(`manifest.invalid_field`): a file mirror is `file:///...` with its path escaped; schemes are read
through `vun-fetch`'s table by name; redirects resolve by section 5.2; index paths are built by
segment
