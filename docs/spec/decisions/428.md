Status: accepted

A 32-bit Arm object keeps its relocations naming the symbols and holds the addend in the field each
fills (`Machine::implicit_addends`, `Fixup::addend` for a Thumb branch's): the Arm ABI's linkers
read it from there, and GNU ld ignored the addend of the entry, so a `bl` to a function in the same
object landed in another. `bind_locally` leaves such an object alone, a shared library's own symbols
then reaching through the symbol table
