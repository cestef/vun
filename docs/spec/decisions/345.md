# 345. An impl whose witness is made for a use, by a type constructor or for the

Status: accepted
Where: 02
Note: the owner's choice, over checking once with an abstract parameter per `_`

An impl whose witness is made for a use, by a type constructor or for the values of its `_`, is
checked against its interface's requirements where it is used: a method found through such a
witness, an operator's function or a call through `lang.ops.Call` reports each requirement the
witness made there does not meet at the use, the impl labeled; an impl whose witness is a type is
checked where it is declared, as before
