# 251. What a C library lays out its own way is a row per system

Status: accepted
Where: 08

What a C library lays out its own way is a row per system (`std.os.libc.System`: the `errno`
function, the signal set's word type and count, `pthread_sigmask`'s `how` values), declared by the
system's module (`std.os.linux.c`, `std.os.macos.c`); `std.os.libc` uses the row whose `os` is
`lang.target.current.os`, and a target with no row fails at compile time
