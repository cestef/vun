# 339. `std.lints.naming.case`

Status: accepted
Where: 10

`std.lints.naming.case` (deny) names types, interfaces and functions giving one `PascalCase`, and
everything else `snake_case`, where a struct of declarations alone, none a method receiving the
struct itself, and a function giving one (witnesses, derives), is a namespace (the owner's choice,
as is the receiver rule); what a binding is comes from its value and its literal, a primitive's from
its annotation; `lowercase_types` lists the exempt built-ins, and an integer type named by its width
(`u24`: a letter of `width_prefixes`, then digits) is exempt too (the owner's choice). A declaration
annotated `type` binds a type; one whose value does not evaluate is not linted. `vun tool bind`
names bindings in the same cases, through `vun_syntax::case::Case`, which the generators share.
Borrows of arrays or slices join as a borrow of a slice in any order (decision 116 made associative)
