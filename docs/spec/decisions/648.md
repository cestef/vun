named if any; the runner reads it as `std.testing.Options.filter`. A record of lists in the
grammar's sources is a kind when marked `#[syntax.kind]`, not when its name is `PascalCase`. SARIF
stays written by `Renderer::finish` alone (513): a run is one document and the tool's data is known
at its end, so no begin call is added. `for x in slice_borrow` iterates a `&[T]` through the
`Iterate` impl of `Slice`; `std.mem.copy(T, &out to, from)` is `types.mismatch`
