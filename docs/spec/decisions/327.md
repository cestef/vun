# 327. An exported value that is not a function is data of the program

Status: accepted
Where: 08, 13

An exported value that is not a function is data of the program (`vun_mir::ExportedDatum`): reached
from the root file's bindings and the members of the struct types they evaluate to, it reaches the
functions and link symbols it holds, and is lowered as exported data in its `#[link.section]`,
encoded on its own and placed as a function's data is; one with no value at compile time is
`comptime.export`, labeled where evaluation stopped
