# 337. Library reports point inside literals through code

Status: accepted
Where: 10

Library reports point inside literals through code: `lang.meta.within(T, c, bytes)` derives an
origin (`Via::Part`, written source) for the bytes of the string literal the code `c` writes, the
lexer locating each byte (`lexer::located`); `std.fmt.parse` reads a format once into pieces or a
typed `fmt.Error` (`Problem`, the bytes it covers), which `print` reports; an instantiation's report
moves to the call only when placed inside the callee's code
