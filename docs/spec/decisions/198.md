# 198. Cycles among queries

Status: accepted
Where: 13

Cycles among queries: a value computed from a cycle value (the `cycle` rule's value for a query
still being computed), directly or through what it read, is provisional and not memoized; only the
query reached again keeps its memo, so which query of a cycle is asked for first no longer changes
the others' values (the kinds of a recursive type's parts were computed from the placeholder and
kept). Verifying a memo whose reads reach it again recomputes it (`Why::Cycle`) instead of recursing
forever; a memo computed equal to the one it replaces, fingerprint and reads, changes nothing saved
