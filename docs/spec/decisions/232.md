# 232. Comparison operators are `lang.ops.PartialOrd`

Status: accepted
Where: 02, appendix B
Note: the user's choice

Comparison operators are `lang.ops.PartialOrd` (`lt`, `le` required, `gt`, `ge` provided); `Ord` is
a total order requiring only `cmp`, and `lang.ops.by_cmp(T)` is the `PartialOrd` witness following
it. Floats implement only `PartialOrd`, by IEEE comparisons; `totalOrder` is
`lang.float.total_order`. So `a < b` and `cmp` never disagree, and each interface has one meaning
