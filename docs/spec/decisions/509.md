# 509. `lang.arch.wasm32.call_indirect(f)`

Status: accepted
Where: 07

`lang.arch.wasm32.call_indirect(f)` (`Control::CallIndirect`) calls through the linker's table: the
form pops the `i32` index itself, sema and the verifier pop the parameters of `f`'s type under it
and push its result as for `call`, and the backend writes the type index of `f`'s function and the
table, both relocated. `f` is a signature, never called; a function value held as its address is the
index
