# 229. Jump threading also goes through a block switching or branching on a parameter

Status: accepted
Where: 13

Jump threading also goes through a block switching or branching on a parameter whose parameters
later blocks read, by demoting them to slots that promotion rebuilds; a block entered by one edge of
a branch or switch reads what the edge implies (`Function::reuse`); commutative constants fold on
either side, a comparison masked by a constant folds; a parameter passed one value is that value; a
block of constants read elsewhere is no longer jumped over (it broke dominance once values were
shared). A `for` over a range compiles to a one-block loop: the LCG loop runs in 103 ms (C `-O2`:
116)
