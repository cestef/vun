# 281. Operations of the system beyond writing reach it through link symbols each

Status: accepted
Where: 08

Operations of the system beyond writing reach it through link symbols each runtime exports, declared
once in `std.os` and wrapped by `System` methods (the user's choice); clocks first:
`std.time.{Duration, Instant, Clock}`, `System.now(clock)` and `System.pause(span)` through
`std.os.symbols.{now, pause}` (kernel: `clock_gettime`, `clock_nanosleep`; C library:
`clock_gettime`, `nanosleep`, clock numbers per system row `std.os.Clocks`; WASI: `clock_time_get`,
`poll_oneoff`), a pause interrupted by a signal resumed with what is left
