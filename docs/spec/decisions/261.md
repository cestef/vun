# 261. A float literal that nothing gives a float type is an `f64`

Status: accepted
Where: 03, 04
Note: the user's choice, the float default

A float literal that nothing gives a float type is an `f64` (`Format::DEFAULT`), at compile time and
at run time alike, as an integer literal types from itself: `nan := 0.0 / 0.0` is an `f64`.
Compile-time evaluation runs `match` (`Env::matching`: the first arm whose pattern takes the value
and whose guard holds), and a `$` argument is evaluated as a value of its parameter's type (`.empty`
for `$s: Shape` is the variant)
