Status: accepted

The options of commands take their values from, in order, the command line, the environment, the
package's plan and the toolchain: `b.commands(.{ .fmt = .{ .width = 100 } })` records them
(`std.build.Action.commands`, `Action::Commands`), and `Program::defaults` fills the options a
command naming a path leaves out (`Args::defaulted`), by command and option name, any option of any
such command; `plan.unknown_setting` names a section or field that is none. `vun fmt` takes
`--width`
