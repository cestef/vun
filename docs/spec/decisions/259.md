# 259. A field is not a method

Status: accepted
Where: 01

A field is not a method: `a.f(b)` with `f` a field of the type of `a` calls the value the field
holds with `b` alone. Function values, `$` parameters included, are ordinary compile-time values in
fields, arrays and results, so a runtime is chosen from a table of rows (`Runtime { os, start }`)
and called through its field
