Status: accepted
Where: 12, 13

`vun doc` writes only into a directory that is absent, empty or marked by a `.vun-doc` file an
earlier run wrote; any other directory is refused whole with `doc.foreign_output`, so documentation
never overwrites a site's own `index.html` or `style.css`. `vun debug compare` reports a row per
backend (exit, bytes per stream, code size, build and median run time) and the first line of stdout
or stderr where a backend parts from the first, and compares stderr as well as exit code and stdout
