# 335. `lang.meta.embed(path)` reads a file the package includes, from the directory

Status: accepted
Where: 03

`lang.meta.embed(path)` reads a file the package includes, from the directory of the file calling
(`FileRef::beside`), as a `&static [u8]`: a query input (`FileBytes`) the driver sets from the files
the package's `include` takes, so the read is a recorded dependency; a path leading out of the
package or naming no file traps (`Reason::Unembedded`); `std.meta` re-exports it
