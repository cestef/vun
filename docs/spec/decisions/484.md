# 484. `std.collections` gains `HashSet(T)`

Status: accepted
Where: 05

`std.collections` gains `HashSet(T)` (a `HashMap(T, ())`), `Deque(T)` (a ring over one buffer:
`push_front`, `push_back`, `pop_front`, `pop_back`, `get`, `iter`) and `BinaryHeap(T)` (a max-heap
by `<` over a `Vec`, sifting with the slice method `sift_down` the sort uses), each linear and given
its allocator per call as `Vec` is; `std.int.math` adds `div_ceil`, `align_up`, `align_down`,
`is_power_of_two`, `next_power_of_two`, `ilog2`, `isqrt`, `gcd` and `checked_pow` to every integer
type, narrowing their result as `.to` does. `ArrayVec` is left until storage that is not initialized
has a primitive
