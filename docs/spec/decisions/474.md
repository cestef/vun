# 474. `lang.arch.wasm32` is an instruction set of a stack machine

Status: accepted
Where: 07

`lang.arch.wasm32` is an instruction set of a stack machine: its forms declare the values they pop
and push, its registers are the function's locals (class: the value type), and a block is the text
format's body with bindings at `local_get`, `local_set` and `local_tee`; sema checks the stack
(`asm.stack`) and the wasm backend encodes the forms. `Blocks` (the table and `fit`) is separate
from `Registered` (registers, operands as the assembler takes them), which the native and C backends
read; the wasm target declares the features its backend uses
