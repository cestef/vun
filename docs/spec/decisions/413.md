# 413. `vun debug disasm` reads PE files beside ELF ones

Status: accepted
Where: 12, 13

`vun debug disasm` reads PE files beside ELF ones (`vun-pe`, a reader over `vun_bytes::In`, beside
`Out`): the sections that hold code at their virtual addresses, the names a program exports, its
entry and the slots it imports through, `__imp_<name>`, which code calls and jumps through. A format
is read into `vun_disasm::Code` once and the listing reads only that; x86 in 32-bit mode is an
instruction set beside x86-64 and arm64 (`Isa::X86`, an ELF machine 3 or a PE machine 0x14c). A
`Decoded` names the place an instruction refers to by its position, a direct branch's target or an
operand relative to the instruction pointer (`rip + disp`), so an import or a string is named where
code reads it
