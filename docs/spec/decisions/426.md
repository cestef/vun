# 426. A view has a scope

Status: accepted
Where: 13

A view has a scope (`vun_driver::view::Scope`): the file, or the unit holding a byte, which each
view names (`View::unit`: the function for types and MIR, the member declaration for values). The
code actions over a range starting in such a unit offer those views a second time, written beside
the document as `<view>.<unit>`; `vun debug dump types|values|mir --at line:column` shows the same,
`line:column` being `vun_span::Place` (`Values::Place` in `vun-command`), one-based, the column in
characters
