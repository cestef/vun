# 351. Lints see locals

Status: accepted
Where: 10

Lints see locals: `lang.lint.Local` (a local binding or a function literal's parameter, whether it
is a parameter, whether a name reads it), a function type's parameters and the binders of an
or-pattern's alternatives after the first excluded; `lang.lint.Decl` tells whether a declaration is
public and documented. Every lint report notes its level and proposes, as a placeholder, the
`#[lang.lint.allow(lint, reason)]` on the declaration around; `vun explain` shows lint pages as it
shows error pages. New lints: `std.lints.style.unused` (warn: a local no name reads, fixed by
binding `_` on request; parameters are not reported, as callers name them and interfaces fix them)
and `std.lints.layout.pub_doc` (allow: a public declaration without a doc comment). The levels a
package's build records (`b.lints(...)`) reach each lint of its files: `vun_sema::plan::Planned`
runs in `vun-sema` (`vun-sema-plan` reads its steps), the package input names its manifest, and a
pair naming the lint wins over one naming its group, the last written of each winning, `forbid`
lowered by neither a pair nor `#[lint.allow]`
