# 203. At a call, the native backend stores home only what is used after it

Status: accepted
Where: 13

At a call, the native backend stores home only what is used after it; values whose every remaining
use is a register argument of the call stay in their registers, and the arguments passed in general
registers are written as one parallel move (`Cx::spill_for_call`, `Cx::pass_in_regs`: a register is
written once no pending argument is in it, a cycle broken by storing one value home)
