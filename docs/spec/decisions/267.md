# 267. A failing file is reduced by `vun-reduce`

Status: accepted
Where: 13

A failing file is reduced by `vun-reduce` (`vun debug reduce`): edits follow the CST as in
hierarchical delta debugging (runs of siblings by halves, a node replaced by a child, single
lexemes), a candidate parsing worse than its source is never compiled and no text twice, and the
failure kept is typed (a crash at a compiler source place, or an error id, `--keep`); candidates
compile in process over the same queries (the user's plan)
