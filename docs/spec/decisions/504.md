# 504. `lang.arch.wasm32` declares structured control

Status: accepted

`lang.arch.wasm32` declares structured control (`block`, `loop`, `if_`, `else_`, `end`, `br`,
`br_if`, `br_table`) through `Form.control`, of blocks that give nothing or the one value a `Yields`
choice names (`block(yield_i32)`; a branch to a block carries it, to a loop nothing); there is no
`return`, since inlining would return from the caller; sema keeps a frame per open block
(`asm.stack` reports a block ended or branched to that the asm block did not open, one left open,
values at an `end`), the module verifier reads the same field, and `br` makes the rest of its block
unreached while its flow stays `next`, so a block holding a branch still returns. A read position
takes `in` or `inout` and a write one `out` or `inout`, and the backend makes a place a block names
twice one local.
