# 511. The Cranelift backend places C records by value where the classifier's

Status: accepted
Where: 13

The Cranelift backend places C records by value where the classifier's placement differs from
Cranelift's counting, by parameters carrying nothing (`Skip::{Int, Float, Stack}`) that take the
registers a convention closes (AAPCS64) or the words skipped to align a record past 8; a register
part of 3, 5, 6 or 7 bytes is loaded and stored in pieces of 4, 2 and 1 bytes; a struct argument of
any size is passed as whole words from a copy of its own; and on arm64, which has no struct
arguments, a record on the stack is passed as integer words. `memcpy` is a support function
Cranelift may call (x86-64 struct arguments). Extends 503
