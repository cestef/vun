# 505. A float constant of a wasm32 block is its bits

Status: accepted

A float constant of a wasm32 block is its bits (`Imm.bits(n)`: `f32_const(0x3f800000)`,
`f64_const(0x3ff8000000000000)`), written as the format stores them, little endian and not LEB128; a
float literal is an operand too (`f32_const(0.5)`), given to sema as the bits of each format
(`Given::Float`, only for an instruction set whose `Shape.floats` says so) and taken by the position
that names the bits.
