# 515. `DiagId` is typed

Status: accepted
Where: 10 Ids are equal, hashed and ordered by path text, so `DiagId::new` and `DiagId::parse` of one path are one id.

`DiagId` is typed (`vun-diag`): `Lang` for an id `lang.errors` declares, a variant of the enum
`cargo gen` writes from the files of `lib/lang/lang/errors/` beside the constants (`errors::ids`,
`Lang::path`, `Lang::ALL`), `Tool` for the `&'static str` a tool of the repository declares
(`DiagId::new`, const), and `Package` for the interned names of a lint a package defines
(`DiagId::package`). Text enters at the edges only (`DiagId::parse`, `DiagId::compiler`, which give
the `Lang` id when the path is declared there, so one id is one value), and leaves through `path`
and `Display`; `within` compares names, ordering is by binding path as before, so output, JSON,
SARIF and explanation pages are unchanged. `DiagSource::Lint` holds its group as a `Symbol`. Pass
ids were never text (`PassId` is a number)
