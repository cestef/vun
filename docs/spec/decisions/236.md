# 236. `targets.gnu` takes the flags selecting a target's machine

Status: accepted
Where: 13
Note: a review finding

`targets.gnu` takes the flags selecting a target's machine (`-mcpu`, `-mthumb`, `-mfloat-abi`,
`-march`/`-mabi`, `--target`), given to every compile and every link so the driver picks the
libraries built for it: `bare.cortex_m4f` builds Thumb-2 hard-float code, `bare.rv32imc`
RV32IMC/ilp32, `wasi.wasm32` wasm
