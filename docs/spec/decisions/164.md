# 164. The declarations of one link symbol that a program sees

Status: accepted
Where: 07
Note: the user's choice

The declarations of one link symbol that a program sees (its package and dependencies,
`Env::links_seen`) are one import, bound by the largest `stack.max` they state
(`Env::linked_stack`); a program declares the stack of the trap handler it imports itself.
`LinkDecl.symbol` is a `Symbol`
