# 678. A package's `.system` lists the libraries of the system its programs are linked

Status: accepted
Where: 07, 12

A package's `.system` lists the libraries of the system its programs are linked against beyond those
their imports name (`#[link.library]`, decision 673), each by the name its linker is given; a
program links those of its package and of every package it depends on, each once, after the objects
(`Session::system_libraries`, merged into `LinkPlan::libraries`)
