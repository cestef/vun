# 265. Floats are one constructor, `lang.Float($bits)`

Status: accepted
Where: 02, 04

Floats are one constructor, `lang.Float($bits)` (`f16 := Float(16)`, `f32`, `f64`), as integers are
`Int`: each operator interface has one impl over it, where there were 24 (one per type and
interface), and the compiler reads a float's format from its argument (`Format::of_bits`); a width
with no IEEE binary format traps (`Reason::Argument`)
