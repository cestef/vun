# 277. `vun-object` writes ELF of the class the machine's address width fixes

Status: accepted
Where: 13

`vun-object` writes ELF of the class the machine's address width fixes (`Machine::pointer_bits`),
never a flag: ELF32 for `Machine::Arm(Float)`, with `EF_ARM_EABI_VER5` and the convention's float
ABI in `e_flags`. Thumb relocations are kinds of their own (`ThumbCall`, `ThumbJump24`,
`ThumbJump19`, `ThumbLow16`, `ThumbHigh16`; data words `Abs32` and `Pc32`), written as `SHT_RELA`
like the other machines, which `ld.lld` resolves (a branch's addend is -4, as its program counter
reads 4 bytes on); a Thumb function's value has bit 0 set, as assemblers write it; `$t`/`$d` mapping
symbols are typed (`SymbolKind::Mapping`, `Object::map`). The width of a data word holding an
address, and DWARF's address size, come from the machine (`Machine::address`, `address_bytes`)
