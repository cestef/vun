# 320. Structured data is one model apart from any format

Status: accepted
Where: 13

Structured data is one model apart from any format: `vun-data` (renamed from `vun-json`) holds
values of the JSON data model, `ToData`/`FromData` (`#[derive(ToData, FromData)]`, attributes
`#[data(...)]`) and the formats as modules: `json` (read and written, `Json(&value)` writes), `toml`
(`Toml(&object)` writes a document, `Inline(&value)` a value) and `lua` (`Lua(&value)` writes a
table constructor); a value has no `Display` of its own. A configuration is one typed value written
in whichever format a tool reads
