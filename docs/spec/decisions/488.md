# 488. `std.math`

Status: accepted
Where: 08

`std.math`: the float functions that are not operators (`abs`, `signum`, `copysign`, `min`, `max`,
`clamp`, `trunc`, `floor`, `ceil`, `round`, `round_even`, `fract`, `sqrt`, `powi`, `pow`, `exp`,
`exp2`, `ln`, `log2`, `log10`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, the
hyperbolics, `hypot`, `to_radians`, `to_degrees`) as methods of every float type and the constants
`pi`, `tau`, `e`, `ln_2`, `ln_10`, `sqrt_2`, all written in Vun on the encoding and on integers
rather than as `lang.float` primitives, so every backend gives the same bits and no backend gains a
lowering; `sqrt` is correctly rounded (integer square root of the significand with a sticky bit),
the others are within a few ulp, a narrower float computes in `f64` and rounds once. The same batch
adds iterator adapters (`skip`, `take_while`, `skip_while`, `step_by`, `inspect`) and consumers
(`for_each`, `any`, `all`, `find`, `position`, `last`, `nth`, `reduce`, `min`, `max`, `collect`) and
the constructors `repeat` and `once`; option and result combinators; `std.text.num` (integer parsing
in any radix, magnitude below 2^120), `strip_prefix`, `strip_suffix`, `split_whitespace`,
`make_upper`, `make_lower`; slice `fill`, `copy_from`, `rotate_left`, `rotate_right`, `chunks`,
`windows`, `partition_point`, `dedup` and a stable merge sort over room the caller gives;
`Vec.retain`, `dedup`, `resize`, `extend_iter`; `std.collections.BitSet` and `SortedMap`; `Duration`
arithmetic and a `Format` impl
