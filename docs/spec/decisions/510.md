# 510. A Vun vector of 16 bytes binds to a block of `lang.arch.wasm32` as a value

Status: accepted
Where: 07, 13

A Vun vector of 16 bytes binds to a block of `lang.arch.wasm32` as a value (`in(v)`, `out(v)`,
`inout(v)`), amending 507. Sema holds a value as `Held::{Int, Float, Vector}` by its type, so a
128-bit integer is not a vector, and reports a value held in no register (`asm.unknown_operand`).
LIR gains `Scalar::V128`, which only the place of a block's output has (no value is of it); lowering
binds a vector input as an `inout` place of a copy in a slot of the block's own (`Rebind::input`),
so the write-back never reaches the vector. The wasm backend loads and stores it with `v128.load`
and `v128.store`; native and C refuse it (`Missing::Vector`)
