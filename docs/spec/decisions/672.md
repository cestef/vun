# 672. `vun new` renames what a template names after its package

Status: accepted
Where: 12

`vun new` renames what a template names after its package: every path component of the copied files
equal to the template's name (`hello.vun`, `hello/`, with any extension) and every such entry of
`include` (`Manifest::identify` takes a `Rename`). A template can then hold the package namespace
`<name>.vun` and its children, so `vun test` has a namespace to run; the `hello` template gains
`hello.vun` and `hello/tests.vun`, its program root staying `main.vun`
