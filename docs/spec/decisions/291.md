Status: accepted
Where: 13
Note: the user asked to keep optimizing, and for finer timings

Reusing memos, faster: before a memo's reads are verified in order, those that hold are verified
ahead over threads and marked current, computing none (`Settle`; under `Reuse::Check` only recorded
and checked by verifying in order); only a memo of a persisted query marks the database changed, so
a build that computes the same memos saves nothing; the architectures' assembly tables persist
(`ArchTable`), since a memo reading a query not persisted is never saved (a driver test builds an
unchanged program twice and requires nothing saved to be computed); a program's reach makes each
wave of bodies over threads (`get_all`), finding functions in the same order; the engine's own work
and the driver's build steps are timed
