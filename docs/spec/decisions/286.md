Variadic C functions are C imports with a pack, declared with the pack of the arguments their
callers pass (`open: unsafe (path: *u8, flags: u32, ..mode: .{ u32 }) -> i32 = _`): under `#[abi.c]`
the pack's items are C's `...`, the LIR signature marking where they start (`Signature::variadic`);
`vun-abi`'s `Variadic` passes them as fixed ones (AAPCS64), counting floating-point registers
(System V), each on the stack in the words it takes (Apple's arm64, `Free::spill`), or the whole
call as the base standard (AAPCS-VFP, `Rules::calling`); the C backend declares `...`, the wasm
backend refuses them (`Missing::Variadic`); a C function with a pack has no body and no `f32` or
`f16` item (`abi.variadic`)
