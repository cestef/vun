# 147. A member a namespace does not declare is `names.unresolved`

Status: accepted
Where: 10
Note: the user's choice

A member a namespace does not declare is `names.unresolved` (with a suggestion), unless the
namespace computes names; programs written ahead of their libraries live in `corpus/planned`, which
must parse and may report only unresolved names, listed as what each waits for; one that checks
clean fails until moved to `corpus/accept`
