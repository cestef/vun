# 407. A call of a function every parameter of which is a `$` one, or of a primitive

Status: accepted
Where: 04

A call of a function every parameter of which is a `$` one, or of a primitive taking none, is known
when compiling (`Callable::folds`, which was a primitive's alone), so an integer it gives has the
type of its value alone: `std.int.width(r)` is `Int(8..=8)` for `u8` in a body instantiated for it,
and `(bits - n) % bits` is `Int(0..8)` with `n: Int(0..8)`, as it is for a literal. A function with
no parameters, or with a run-time one, is typed by its signature. The integers' byte and bit methods
(`to_le`, `to_be`, `from_be`, `swap_bytes`, `rotate_left`, `rotate_right`, `count_ones`,
`leading_zeros`, `trailing_zeros`) are written for every `Int(r)` by its unsigned word
(`std.int.Word`, `std.int.width`), so a signed value is its two's complement
