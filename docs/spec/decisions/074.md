# 74. Typing uses the expected type where the context gives one

Status: accepted
Where: 01, 04
Note: on the agent's recommendation

Typing uses the expected type where the context gives one: annotations, parameters, the result
(tails and `return`), fields, assignments, a binary operator's right operand (the left's type),
branches; `.name` is a variant, a variant constructor or a declaration of the expected type; tuples
and arrays widen item by item; `match` and `if` take the join of their branches
