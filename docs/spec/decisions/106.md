# 106. Function types stay plain function values

Status: accepted
Where: 02, appendix B
Note: the user chose generic callbacks over closures in function types

new table `calls`), which function values and closures implement (`Env::implemented`); a `$`
parameter annotated with an interface has type `type`; inference reads a bound parameter's
