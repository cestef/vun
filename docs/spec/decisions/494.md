# 494. `vun test` runs tests in parallel as nextest does

Status: accepted
Where: 11, 13

`vun test` runs tests in parallel as nextest does: the tests' program takes `--list`
(`std.testing.Listed`, one line per chosen test) and the driver runs each test in a process of its
own, `--jobs` (`-j`, `VUN_TEST_JOBS`) at a time, the machine's cores if not given; results are
reported as processes end, totals summed, a process that reports nothing is a failure; `--jobs 1`,
benchmarks and fuzzing keep the one process in order. `cargo xtask runtimes` uses it. The register
allocator's check of native code found each fused comparison by scanning every block of the function
for every instruction (`Cx::is_fused`), quadratic in a function's size, minutes on a runner with
hundreds of tests; it is found for every value once
