# 647. A loan in a compile-time call's result is rebased on the caller's at any depth

Status: accepted
Where: 03, 13

A loan in a compile-time call's result is rebased on the caller's at any depth (a variant payload, a
tuple or array item, a struct field), as a returned loan into a parameter was; the cases still
rejected are one `Unevaluated::NestedLoan(Nested)` each (`OfLoan`, `InClosure`, `InParameter`,
`Own`, `InFrame`, `ToPrimitive`), reported by `comptime.unsupported` with what they are. Memory per
level of nested evaluation: a memo's reads are one `Arc<[Dep]>` per distinct list (`Db::list`), a
table holds each key once as an `Arc`, and `Cx::computed` keeps what follows the computation out of
its frame (960 bytes of stack for `MeteredCall` before, 496 after)
