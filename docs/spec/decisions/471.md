# 471. An operator whose left operand never finishes

Status: accepted

An operator whose left operand never finishes (`1 / 0` over constants has no value: its type is
`never`) is itself `never` and asks for no impl, so a trap at compile time is reported once, by its
own diagnostic (`comptime.trap`), and not again as `types.no_impl` of `lang.ops.Eq` for `never`; the
other operands are typed all the same
