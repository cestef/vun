# 324. The language server answers references, rename, code actions, signature help

Status: accepted
Where: 13

The language server answers references, rename, code actions, signature help, inlay hints and
completion (spec 13, section 11), each from the driver's session and its queries: references and
rename by what names resolve to (declaration and name together), rename spelling the name as the
source writes it and refused with a typed reason (`Unrenamed`), code actions from diagnostic fixes,
signature help from the callee's declaration as written, inlay hints from typing, completion from
namespace and type members or the names in scope, classed as semantic tokens are. Edits across
documents are `documentChanges` naming each open document's version
