# 473. `lang.check.Kind.stack`, a check of each function's frame against the stack

Status: accepted

`lang.check.Kind.stack`, a check of each function's frame against the stack: lowering gives the
function a `StackCheck` (`lang.check.stack(frame, site)` and its site), which a backend with
`Feature::StackChecks` calls with the frame's lowest address before the stack pointer moves to it,
so that a frame whose address wraps is caught and reported on the stack as it was; the runtime fails
with `Violation.stack_overflow` for a frame below `lang.check.stack_reserve` bytes above the stack's
bottom or at or past its top. WASI's runtime exports it (`std.check.stack_exports`); the other
backends and runtimes refuse it (`backend.lacks`, `check.unsupported`). Opt-in: without it a WASI
overflow is still the engine's out-of-bounds trap. The set of functions the checks do not apply in
follows a call of a link symbol into the function the program exports under it
