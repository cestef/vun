# 77. A function value is its literal and the compile-time call it was evaluated in

Status: accepted
Where: 03, 04
Note: on the agent's recommendation

A function value is its literal and the compile-time call it was evaluated in, whose parameters its
body sees (MIR reads them, and literals built from them, as `Rvalue::Comptime`); a declaration of a
struct type is evaluated where the type was built (`MemberValue`); a signature naming `$` parameters
is typed per call with them bound; the integer narrowings are `std.int.Narrow`, an impl for
`lang.Int` over the primitives `lang.int.{to, wrap, sat, fits}`; primitives read the environment, so
`fits` gives a `lang.bool`
