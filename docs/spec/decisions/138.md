# 138. Targets and lint groups are data

Status: accepted
Where: 10, 13
Note: backends and the linker per 182

Targets and lint groups are data: `lang.target.Spec` is a struct (architecture, object format,
backends and linkers as `lang.meta.Name`, `Endian` an enum); a lint group is a namespace of
`std.lints` declaring its default `level`; a namespace is a value of type `lang.meta.Namespace`;
`vun_items` has handles for the members of `struct` and `enum` literals, in a module per type as
nested namespaces have (`std::build_Build::new`)
