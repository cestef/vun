# 258. Inline assembly is a block of an architecture's instructions

Status: accepted
Where: 07, 13

Inline assembly is a block of an architecture's instructions, `lang.arch.<arch>.asm { ... }`, read
at compile time against the architecture's table in `lang.arch.<arch>` (registers, forms, what each
reads and writes), from which the native assemblers' tables are generated; operands bind Vun values
(`{in e}`, `{out p}`, `{inout p}`, `{in(rdi) e}`, `{name}` for an address), clobbers are derived
from the forms, an immediate must be a value the operation's width holds (never cut to the bits the
operation reads), each line takes the first form of its mnemonic that fits as the assembler chooses,
and a string template is no longer accepted (the user's choice)
