`.requires` in a manifest names the oldest toolchain that reads and builds the package. It is read
before every other field: a toolchain older than that reports only `manifest.toolchain_too_old`
(help: `vun toolchain update`), not the fields it does not know as `manifest.unknown_field`.
Toolchains that predate the field cannot say it; every library package written after it declares it.
