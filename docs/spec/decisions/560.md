# 560. `std.collections.BTreeMap(K, V)`

Status: accepted
Where: 05

`std.collections.BTreeMap(K, V)`: values by key in key order, in a B-tree of minimum degree 6 (at
most 11 keys and 12 children a node) whose nodes lie in one `Vec` and name each other by position,
so it holds no allocator and no pointer. Insert splits full nodes and remove grows thin ones on the
way down, one pass from the root, so no node is revisited and remove needs no allocator; unused
nodes form a list inside the pool. A node is an inline `ArrayVec` of keys, of values and of child
positions, so `ArrayVec` gains `insert`, `remove`, `split_off` and `append`, and `Vec` gains
`push_within_capacity` (a push that cannot fail, since one that can holds the item and a linear one
may not be held). API as `SortedMap`'s (`empty`, `len`, `get`, `get_mut`, `contains`, `insert`,
`remove`, `first`, `last`, `entries`, `clear`, `deinit`) plus `pop_first`, `pop_last` and `verify`.
Not built: range queries, entries to change, a by-value iterator
