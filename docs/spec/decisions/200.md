# 200. Lowering promotes slots to values

Status: accepted
Where: 13

Lowering promotes slots to values: a slot only plain, whole loads and stores of one scalar reach
through its address becomes SSA values with block parameters (`Function::promote`, Braun et al.'s
construction over known predecessors, trivial parameters removed, `Function::compact` renumbering),
a read before any store reading zero; legalization rewrites reachable blocks in reverse postorder.
The native backend's code for the backend test programs shrinks by 11 (`half`, mostly soft float
calls) to 37 percent of its instructions
