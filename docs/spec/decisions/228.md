# 228. Simplification scalarizes aggregate slots reached only by constant-offset

Status: accepted
Where: 13

Simplification scalarizes aggregate slots reached only by constant-offset scalars and copies into
tiles promotion takes, reuses pure computations a dominating equal one made (on a dominator tree,
`analysis::Dominators`, which the verifier now uses too), folds a branch or switch whose targets are
one, sweeps parameters only passed back to themselves, and runs its passes in rounds until one
changes nothing; functions of any shape up to 96 instructions besides constants are inlined. A `for`
over a range inlines its iterator and holds its state in registers: the 50-million-step LCG loop
runs natively in 109 ms instead of 380 (the C backend at `-O2`: 116 ms), and `half.vun` compiles to
13,773 instructions instead of 22,917
