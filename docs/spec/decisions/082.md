# 82. Compile-time evaluation reads types

Status: accepted
Where: 02, 03, 13
Note: on the agent's recommendation

Compile-time evaluation reads types: a declaration's value is typed first (`TypedDecl`, per instance
for members of built types) and evaluated with those types, so `.{ }`, `.name` and `.variant(x)`
have values; expected types also flow down while evaluating (`Env::eval_as`: fields, items,
payloads, field defaults); strings are byte arrays and a shared borrow of a compile-time value is
the value; a borrow of `[N]T` is accepted where a borrow of `[T]` is expected (spec 02); MIR builds
aggregates and reads fields and items (`Rvalue::{Aggregate, Field, Index}`)
