# 293. Native Thumb-2

Status: accepted
Where: 07, 13

Native Thumb-2 (`vun-native-thumb`, arch `arm`): homes off `r7`, `r12` and `lr` the framework's own,
`r11` building far offsets and saved by every prologue; a condition becomes a byte through `it`
blocks (`lang.arch.thumb.{it, itt, ite}`, whose moves snippets mark as conditional so the encoder
never drops them); floats are single precision in the floating-point extension where the convention
passes them there (`f64`, and every float under soft `aapcs`, are `backend.lacks` until soft
floats); 32-bit Arm objects carry `$t` mapping symbols, the Thumb bit on every address a function is
reached by (`Machine::reached`, local relocations included) and `.ARM.attributes` (Armv7, Thumb-2,
the float ABI). `targets.linux.arm` (Armv7-A in Thumb state, hard float) runs on
`std.os.linux.kernel` under `qemu-arm`; the framework asks each instruction what the backend lacks
before planning (`Isel::lacks`)
