# 263. `std.os.start` is the `start` of the runtime of the target being built for

Status: accepted
Where: 08

`std.os.start` is the `start` of the runtime of the target being built for: each system's namespace
declares a row `std.os.Runtime { os, abi, start }` and `std.os.runtime` takes the one matching
`lang.target.current`; `std.os` writes streams through a typed link symbol each runtime exports
(`std.os.symbols.write`), so nothing outside a runtime calls a C library. WASI preview 1 is the
first runtime without one (`std.os.wasi`); exit statuses are `Exit.status`, a trap's
`std.os.trapped` (the user's plan)
