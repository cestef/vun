# 674. `c"text"` is a string for C

Status: accepted
Where: 01, 07

`c"text"` is a string for C: an escaped string whose value ends with a zero byte, lexed as the
`String` token with a leading `c` (no new token kind), with the type of any string, `&static [N]u8`;
a zero byte inside is `syntax.interior_nul`. `std.ffi.cstr` holds `CStr` (bytes checked to end with
the only zero byte, borrowed; `ptr`, `text`, `at` for what C gives) and `CString` (a copy of text,
refused with `interior_nul(at)` when it holds a zero byte). Nothing in `lang` knows C strings, as
nothing in it knows `std.String`
