# 238. Executors only look at an `Event`'s mark

Status: accepted
Where: 06

Executors only look at an `Event`'s mark; the task waiting takes it through `Event.wait` (`for
!self.take() { yield .on(self); }`), so a task resumed early yields again, as spec 06 states. `Wait`
is `enum { on(&Event), either(&Wait, &Wait) }`: `select` yields `.either(&first, &second)`, where it
used to drop the first wait's chain (a nested `select` could hang) and resume a task whose event had
not fired
