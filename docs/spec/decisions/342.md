# 342. `--format styled`

Status: accepted
Where: 12
Note: the user's choice over mapping JSON records in TypeScript

`--format styled`: what people read, each line a JSON object of its pieces with the style each names
(`vun_term::Style`, written through `ToData`), on the stream it goes to; diagnostics rendered for
people without colors; for tools that draw vun's output themselves (the terminal scenes of
`assets/motion`, recorded by `pnpm record`) instead of parsing text or escape codes
