# 645. Coverage counts

Status: accepted
Where: 11

Coverage counts (spec 11, section 6): `lang.cover.map` is `[65536]u32` and lowering, not MIR, adds 1
to a block's count as the block starts, holding at the greatest `u32`; `vun cover` reports a line as
hit as often as its most-run block and a function as called as often as its first block ran, names a
function in lcov by the path of its declaration, and says how many blocks share a count with
another. The hash modulo the map's size still numbers the blocks, since numbering them densely needs
