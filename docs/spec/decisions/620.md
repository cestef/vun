# 620. The `vun-sema` query cycle is split by interfaces sema owns and the driver

Status: accepted
Where: 13

The `vun-sema` query cycle is split by interfaces sema owns and the driver installs (`Installed<T>`,
as `Evaluator` and `Framer` were): typing (`Typist`, implemented by `vun-sema-typeck`) and blocks of
instructions (`Assembler`, `vun-sema-asm`) leave it, with checking a file (`vun-sema-check`), lints
(`vun-sema-lint`) and the plan query (`vun-sema-plan`), which only read what it computes. What
typing finds (`vun_sema::typed`) and the inference of omitted `$` arguments (`omitted`) stay below,
since evaluation reads them. What remains is `env`, `member`, `callable`, `eval`, `decl`, `layout`,
`target`, `witness` and `apply`, which call each other through `Env`
