# 92. Coroutines

Status: accepted
Where: 02, 06, appendix B
Note: the user chose impls over interface constructors and iterators in `lang`

Coroutines: a function whose body yields returns `TyKind::Frame` (its literal, call, `$` arguments
and declared interface), and its body yields what the interface's `resume` carries in `yielded` and
ends with what it carries in `done` (the table `iteration` names both); `yield ..e` has what `e`
returns. An impl's target may be an interface constructor, covering every type implementing an
interface it makes, its value taking that type first (`coroutine_iterate`); the iterators of bounds,
slices and arrays are coroutine functions in `lang.ops` over `lang.bounds.{empty, first, ends}`, not
holes. A primitive whose declared types name its `$` parameters is typed per call. MIR:
`TerminatorKind::Yield`, `Rvalue::Resume`; at compile time a call of a coroutine function gives its
frame (`Value::Frame`) and resuming runs it to its next `yield`
