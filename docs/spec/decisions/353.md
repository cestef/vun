# 353. Namespaces are reflected

Status: accepted
Where: 03
Note: continues 352, toward the test runner the owner chose

Namespaces are reflected: `lang.meta.decls(ns)` gives a `lang.meta.Decl` (name, attribute values,
the namespace it is when a file or directory below) for each member the calling namespace sees,
values left to `ns.$(name)`; `std.meta.collect(package, attr)` (decision 42) walks the nested
namespaces and returns the members carrying `attr` with their namespace (`std.meta.Collected`),
reading attributes only; as `std` code it sees another package's public members
