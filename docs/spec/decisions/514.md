# 514. A link symbol is a callable like a function and a primitive

Status: accepted
Where: 07, 13
Amended by: 686

A link symbol is a callable like a function and a primitive (`Callable::Linked`, a `Value::Linked`
whose declaration names a symbol; a requirement an impl provides, also `Value::Linked`, is not one),
so a C import may have `$` parameters, among them a pack inferred per call (`printf: unsafe ($P:
type, format: *u8, ..args: P) -> i32 = _`), completing 285 for imports. The signature of a
declaration whose value is `_` is read from its annotation with the `$` arguments bound, for a
primitive and a link symbol alike (`Env::declared_signature`, the queries `DeclComptime` and
`DeclSignature`, which was `PrimitiveSignature`), the declaration's attribute markers (`#[abi.c]`)
put on it. A call types its pack per call, and reports an `f32` or `f16` item as `abi.variadic` at
the call where the declaration could not. Lowering drops the `$` arguments and calls the symbol
through its address with the call's own signature (`Callee::Indirect`), since an import has one
signature and each call's variadic items differ; a link symbol without `$` parameters is called as
before
