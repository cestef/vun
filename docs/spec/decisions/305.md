# 305. Workers join calls in flight

Status: accepted
Where: 13
Note: nested calls ran alone while workers idled; a cycle through `get_all` recursed without end

Workers join calls in flight: a `par_map` call stays open to the pool until its caller's share ends,
any worker free joining the newest open call, nested calls included; the pool names each thread's
helpers, which claim waits follow; `get_all` computes keys under the caller's path of queries, a
cycle through it provisional as on one thread
