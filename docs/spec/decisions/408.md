# 408. `vun debug disasm <file> [symbol]` lists the executable sections of an ELF file

Status: accepted
Where: 12, 13

`vun debug disasm <file> [symbol]` lists the executable sections of an ELF file as instructions
(`vun-disasm`): an address, the bytes and the text of each, a label for each symbol, and for a
direct branch the address it goes to with the symbol that holds it. An instruction set is a row of a
table (`Isa::ALL`: x86-64 and arm64), read by yaxpeax, which becomes a shipped dependency of the
`vun` binary where it was a test oracle alone; an instruction never crosses a label, so padding does
not swallow the next function; bytes that start no instruction are listed one at a time as data.
Reading an object, a program or a library alike is why a relocatable file's targets are not named
(its addresses are offsets). The alternative is a decoder written in this repository from the
instruction tables, which holds only the forms the compiler emits
