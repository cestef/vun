# 406. A call checks the bound of each `$` parameter annotated with an interface

Status: accepted
Where: 2

A call checks the bound of each `$` parameter annotated with an interface against the type bound to
it (`Typer::check_bounds`, `Env::satisfies`): the type has an impl of the interface, or of the one
its constructor makes with the same arguments; for `lang.ops.Call(P, R)`, a function or closure that
can be passed `P` (a list written `(T)` is the one parameter `T`; each of its parameters accepts the
one passed) and gives a type `R` accepts. `R` is not checked where the call inferred other `$`
parameters, which came from what it is expected to give and report as a mismatch of the result. A
type known only by an interface in a generic body is left to its instantiations. The report is
`types.no_impl`, at the argument that fixed the type
