# 163. An attribute's type says where it applies

Status: accepted
Where: 02
Note: the user's choice

An attribute's type says where it applies: `lang.Attribute := ($on: &[Place]) -> type { struct {} }`
(no longer a primitive), `lang.Place` an enum of `decls`, `functions`, `types`, `fields`, `params`;
every `lang` attribute declares its places, a library attribute may; one check over the HIR's
declarations, fields, parameters and attributed expressions reports `attr.misplaced`; any other
attribute is plain data. The compiler reads attributes through one view (`Attributes` of a `Func`,
`Nominal` or `DeclRef`), markers only as markers (`abi`, `stack.max` included)
