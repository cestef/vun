# 496. Language features are `lang.gate.Feature` variants

Status: accepted
Where: 03, 12, 13

Language features are `lang.gate.Feature` variants; a declaration marked `#[gate.behind(feature)]`
is usable from its own package and from packages that list the feature in `.features` of their
manifest (a list of `.name`s, read against the toolchain's table, `vun_target::Feature`), and any
other use of its name, written as a path wherever it appears, is `gate.disabled` at that path; a
file outside any package enables none. `deferred` (495) is the first. The toolchain's own components
are Cargo features of `vun-cli` (`backends`, `linkers`, each backend and linker, `native-x86_64`,
`native-arm64`, `native-thumb`, `ffi`, `lsp`, `mimalloc`), forwarded to `vun-driver` and
`vun-backend-native`
