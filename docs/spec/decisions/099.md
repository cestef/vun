# 99. A `$` parameter named in a later parameter's type may be omitted from a call

Status: accepted
Where: 02, 07
Note: the user chose inference when fixed and constructor functions

A `$` parameter named in a later parameter's type may be omitted from a call, all such parameters or
none; it is inferred by matching argument types against the declared annotations (names, borrows,
type prefixes, constructor calls, array, slice, tuple and function types), types found twice
joining; an undetermined one is `types.cannot_infer` (a form typed by its context gives no type),
and any other argument count is `types.arity`; the typed body records the inferred values
(`TypedBody::inferred`) and MIR passes them as constants. A variant with a payload named as a value
is its constructor (`Value::Constructor`), of type `(payload) -> E`, lowered to the variant
aggregate when called. `std.result.Fallible` gives `Result` its `map_err`
