# 512. The `asm` checks apply to blocks of `lang.arch.wasm32`

Status: accepted
Where: 07, 13

The `asm` checks apply to blocks of `lang.arch.wasm32`. The table says what each form writes
(`Form::writes`: `none`, a byte count, or `counted` for `memory_copy` and `memory_fill`), and the
wasm backend keeps the operands of a writing instruction in locals, calls `asm_write(address, bytes,
site)` and puts them back; a block that sets the global stack pointer and returns is compared at its
end (`asm_stack`). The WASI runtime exports the operations of `lang.check` over a shadow in linear
memory grown on first use (`memory_grow`, never given back), which also lets the pointer and
allocation checks run on WASI; only a runtime with no exports (a board's) is refused
(`check.unsupported`)
