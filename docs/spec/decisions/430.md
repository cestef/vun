# 430. `b.flash(program, .uf2(.{ .family = n }))` is carried out

Status: accepted
Where: 12

`b.flash(program, .uf2(.{ .family = n }))` is carried out: the driver writes `<program>.uf2` beside
the program, the bytes of each loadable segment of its ELF file cut into 256-byte blocks at the
address the segment is loaded from (`vun_uf2::Uf2`, `vun_elf::File::loads`), `n` being the family of
chip the format's registry numbers (`std.build.Uf2`, read as `vun_sema_plan::Method`);
`plan.unflashed` says why it could not. Probe and DFU steps stay `plan.unsupported`
