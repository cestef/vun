# 221. Compile-time calls run on stack the evaluator adds in 16 MiB segments whenever

Status: accepted
Where: 03, 13

Compile-time calls run on stack the evaluator adds in 16 MiB segments whenever less than 1 MiB is
left (`stacker::maybe_grow` around each `MeteredCall`), so calls nest as deep as their budget allows
instead of overflowing the thread (`$count(100000)` checks in 3.4 s); the query engine finds a memo
already on its stack through an index, not a scan, so deep nesting stays linear
