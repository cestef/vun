# 392. A compile-time report is a `lang.diag.Report`

Status: accepted
Where: 10
Note: the user's approval

A compile-time report is a `lang.diag.Report` (`lang.diag.error(report)`): `.at`, `.msg`, `.help`
and `.fixes`, each fix replacing what `.at` points at; `lang.lint.Fix` is `lang.diag.Fix`. A report
placed in the caller's code is shown there alone, without the label and the calls of the library
code that made it. `std.fmt.print` takes its format string as `Code(&[u8])`, so its reports point
inside the string, and it reports a missing `Format` impl at the argument's `{}`
(`lang.meta.Unborrowed` finds the type a method is looked up in). Code that is a literal is
evaluated without waiting for the typing of the function holding it
