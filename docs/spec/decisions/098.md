# 98. `#[kind.free]` makes a type free

Status: accepted
Where: 05, appendix A
Note: the user chose `#[kind.free]`, `o.*.field` and `kind.owns`

`#[kind.free]` makes a type free: its parts and type arguments may not be scoped (the kind records
it as misplaced), and a statement building such a value from operands that are not is
`borrow.in_free_value`; kind attributes apply on the type's literal (decision 104). `Own(T)` is a
library struct `#[kind.linear] #[kind.free]` whose pointer field is `#[kind.owns]`, and `.*` on a
struct reads through its `owns` field (`o.*.field`), so there is still no auto-dereference; matching
`.some(n) = cur` on a borrow binds by borrow, and fields of an owned value through it are
`n.*.*.field`
