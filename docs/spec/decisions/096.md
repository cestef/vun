# 96. `defer s;` is lowered again at every exit of its block

Status: accepted
Where: 05, 13

`defer s;` is lowered again at every exit of its block (end, `break`, `continue`, `return`, `?`),
the latest first, behind a MIR `Defer` terminator naming the linear locals `s` reads whole; the
place states decide it statically: it runs where all of them are `init`, is skipped where one is
`uninit` (a statement consuming several runs only where all are held; the others are then leaks),
and a local `init` on some paths to the exit is `place.ambiguous_join`. An exit inside `s` runs only
the statements deferred before it. A borrow whose mode needs and leaves the same state changes no
state
