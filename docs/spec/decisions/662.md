# 662. The diagnostics are declared one file per group

Status: accepted
Where: 10, 13

The diagnostics are declared one file per group, `lib/lang/lang/errors/<group>.vun`, the file's
`//!` lines the group's doc and each declaration a diagnostic, so `errors.vun` no longer grows past
the line limit; the path of an id and of its page are unchanged (`lang/errors/<group>/<name>.md`
beside the file). The literal reader gives a file's module doc (`Cst::module_doc`), which also
documents the handle of its namespace in `vun-items`
