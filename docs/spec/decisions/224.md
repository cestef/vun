# 224. What every compile-time call reads of its function is memoized

Status: accepted
Where: 13

What every compile-time call reads of its function is memoized: its signature (`Signed`, by
instantiation) and which parameters are `$` ones with its step budget (`Callee`, by function); the
query engine deduplicates a computation's reads by comparing them when few and remembers each
query's table per thread and database. A loop of 30,000 compile-time calls evaluates in 721 ms
instead of 1176
