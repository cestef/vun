# 134. `vun tool bind` reads a header through libclang with the build's flags

Status: accepted
Where: 07, 12

`vun tool bind` reads a header through libclang with the build's flags (`--cflags`) and binds, fully
qualified: integers by size as `lang.int.signed(N)`/`unsigned(N)`, pointers as `?*T` (C may pass
null), function pointers as `?#[lang.abi.c] (...)`, structs as `#[lang.layout.c]`, a union or a
struct with a bit field or an unsayable field as private bytes of its size and alignment (never
passed by value), an incomplete struct as `struct {}`, enums as an alias of their integer type with
typed constants, `extern` variables as `mut` link symbols unless `const`, integer `#define`s as
constants; variadic functions and C-only types are left out with `tool.bind_skipped`; only the
header's directory is bound; a tag an ordinary name spells is `struct_x`, a name the file sees
already takes `_`
