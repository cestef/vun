# 380. What a program reaches in other packages is checked as its own code

Status: accepted
Where: 04, 11

What a program reaches in other packages is checked as its own code: a check parses every file whose
functions the program built reaches and reports its syntax errors (a library's syntax error was
reported as an unlowered form), and reaches from the roots the program is built from
(`Roots::checked`: a type's members for the tests' program, every function of the root file
otherwise). A property's failing arguments are lines of the runner's protocol,
`{"argument":{"name":...,"value":...}}` (`std.testing.Argued`,
`vun_driver::testing::Line::Argument`), which `vun test` shows under the test and the language
server names in the trap it shows (`the test `t` was falsified by x = 200: ...`).
`lang.int.count(r)` is how many integers a range holds; an integer's generated choice is bounded by
it, so shrinking stays within the range. `R` of `$F: lang.ops.Call((), R)` is inferred from a type's
impl of the interface too (`Env::implemented`, `Contract::made`)
