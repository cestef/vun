# 276. The C backend writes a naked function under GNU attributes

Status: accepted
Where: 07, 13

The C backend writes a naked function under GNU attributes: `__attribute__((naked))` on a function
taking and giving nothing, its body its blocks as plain `__asm__` alone (the only statement GCC and
Clang allow there), their labels unique to each instruction of the unit since `%=` needs operands;
any other statement is refused (`backend.lacks`). A block's symbol is written by its name in the
object where the object format names it as C does (ELF), an import through `@GOTPCREL` or `:got:`,
and what a block names is `__attribute__((used))`; elsewhere a symbol is refused
