# 284. Files through the runtimes' link symbols

Status: accepted
Where: 08, 13

Files through the runtimes' link symbols (`std.os.symbols.{open, read, close}`): `System.open(path,
Mode)` gives a `std.os.file.File` read and written through its `Stream`, `System.stdin`;
`std.os.Error` names reasons (`missing`, `denied`, `exists`, `directory`, `not_directory`, `path`,
`interrupted`, `closed`) beside `number(n)`, each system mapping its numbers; WASI opens from the
preopened directory a path is inside. A build reports the diagnostics of every body its program
compiles, a library's included (`Typed` of each reached function outside the root file); the kernel
runtime exits through `exit(Int(0..=125))`
