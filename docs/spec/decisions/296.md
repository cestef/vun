# 296. Conversions between integers and floats and between float widths are explicit

Status: accepted
Where: 04, 13

Conversions between integers and floats and between float widths are explicit, total primitives of
`lang.float`, each `#[lower.soft]`: `from_int(r, x, T)` (the float nearest, ties to even),
`convert(T, x, U)` (the float of another width nearest, a NaN the canonical one) and `to_int(T, x,
U)` (toward zero, clamped to `U`'s bounds, a NaN 0 clamped likewise: saturating as Arm's `vcvt` and
WebAssembly's `trunc_sat`, never trapping); std spells them `n.nearest(f64)`, `x.nearest(f32)` and
`x.truncate(i32)`. `lower.soft` now fires when any constant argument names a type the target does
not compute with: a float it does not list or an integer wider than an address (`Target::computes`),
so wide-integer conversions run as `lang.float.soft.convert` on every target
