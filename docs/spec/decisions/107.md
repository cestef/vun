# 107. Raw pointer primitives in `lang.mem`

Status: accepted
Where: 03, 05, 07, appendix A

Raw pointer primitives in `lang.mem`: `pointer_to` and `address` (safe), `offset`, `cast`, `read`,
`write`, `copy`, `fill` (`unsafe`); `lang.meta.align`; `lang.meta.span` gives a code value's
`Origin` (`Value::Origin`); `lang.panic.fail($reason: Reason)` with `Reason := enum {
message(&[u8]), assertion(&[u8], Origin) }`. `std` builds on them: `std.ptr` (methods of `*T`), a
real `std.mem.Own` (private `_ptr`, `from_raw`, `into_raw`), `std.mem.alloc.Fixed` (`init`, `alloc`,
`create`, `destroy`), `std.panic.fail`, `expect` on options and results, `Quoted.span`
