# 116. Structural records

Status: accepted
Where: 02
Note: the user chose structural records

Structural records: an anonymous `.{ .a = x }` where no type is expected has the type
`TyKind::Record` of its fields sorted by name, a positional `.{ x, y }` a tuple, and a bare `.name`
there is a `lang.meta.Name` (`Value::Name`); records join and are accepted field-wise; two borrows
of arrays of one item type in one mode join as a borrow of a slice (`lang`'s precedence table lists
its tokens by `&[...]`, which the literal reader reads as the list); `.name(args)` without a context
stays untyped; a local annotated with a type not known has no type rather than its value's
