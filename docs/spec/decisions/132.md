# 132. The generator is its own binary, `vun-generate`

Status: accepted
Where: 13
Note: the user's request

The generator is its own binary, `vun-generate` (`cargo gen`), depending only on what reading `.vun`
data needs; the desugaring tables live in `vun-desugar`, apart from `vun-grammar`, which the parser
is built from; so no generated change can keep the generator from building
