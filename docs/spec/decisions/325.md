# 325. The native backend's DWARF unit holds an entry per function

Status: accepted
Where: 10, 13

The native backend's DWARF unit holds an entry per function (`DW_TAG_subprogram`, abbreviations
declared as a table): the name its symbol has, `DW_AT_decl_file` and `DW_AT_decl_line` from the
function's origin (an abbreviation without them where no source declares it), and its code as
`DW_AT_low_pc`, relocated against its symbol, with its size as `DW_AT_high_pc`; debuggers,
`addr2line -f` and profilers name functions from it
