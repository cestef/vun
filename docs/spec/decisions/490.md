# 490. `std.fmt.float` writes a float as the shortest decimal that reads back as it

Status: accepted
Where: 03, 11

`std.fmt.float` writes a float as the shortest decimal that reads back as it (Burger and Dybvig
free-format on the fixed-size bignum `std.math.big`), `fixed` writes it rounded exactly to a number
of decimals, and `std.float.parse` reads one rounded once to nearest even (800 digits kept, the rest
deciding a tie), for `f16`, `f32` and `f64` alike; `{}` and `{?}` are the shortest form, `{?}`
adding `.0` to a whole number. `std.json` reads JSON with a pull `Reader` that allocates nothing
(`Token` of a slice of the document, 64 levels of nesting), `std.json.text` decodes a string and
reads a number
