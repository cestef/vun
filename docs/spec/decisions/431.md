# 431. A `uf2` flash method lists the ways to give its file to a device

Status: accepted
Where: 12
Amended by: 451

A `uf2` flash method lists the ways to give its file to a device (`std.build.Uf2.deliver`:
`std.build.Delivery`, `.drive(.{ .mark })` a mounted drive holding that file, `.run(.{ .command,
.args })` a program given the file as `Argument.file`), tried in order by `vun flash` until one
reaches a device (`plan.undelivered` with a note per way). The default is the drive of every UF2
device, `INFO_UF2.TXT`, which the format defines; a board declares the rest as a value
(`rp2350.flash.uf2` runs `picotool load -x`, then the drive), so the driver names no programmer and
no mount directory (`vun_fs::Mounts` reads the system's mount table). `vun run` refuses a program
