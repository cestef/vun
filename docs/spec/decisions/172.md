# 172. Reflection gives every nominal type one shape

Status: accepted
Where: 03
Note: the user's choice

Reflection gives every nominal type one shape: variants and the parts each holds, a struct one
variant named by nothing (its fields its parts), an enum variant's payload items parts named by
position; `lang.meta.Variant { name, index, parts }`, `lang.meta.Field { name, index, type }`,
`variant(T, v)` is 0 for a struct, `part(T, v, $variant, $index) -> ?&Part(T, variant, index)`.
`std.cmp.derive_eq` is one path over that shape, enums with payloads included (before, a struct
path, an enum path by variant index alone, and a library error for payloads). Compile-time operators
take their operands' types from typing, or else widen the left operand's type to hold the others
