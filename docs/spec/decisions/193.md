# 193. The size budget of `cargo xtask size` is 12 MiB

Status: accepted
Where: 13
Note: the user's choice

The size budget of `cargo xtask size` is 12 MiB (12,582,912 bytes), raised from 10 MiB (decision
139) once the native backend in TPDE's layers took the `dist` build to 11,172,560 bytes, after the
query engine's code was shared across queries; the largest parts are `std`, rustls and ring for
`vun-http`, and per-query code
