# 384. Benchmarks run

Status: accepted
Where: 11

Benchmarks run (spec 11, section 5): a test whose one parameter is `&mut std.testing.Bench`
(`std.testing.bench.benchmark`, decided at compile time) is a benchmark. Run as a test, its loop
runs the body once; measured, the runner's `--bench` runs the benchmarks alone, each loop running
the body in batches that double what ran before, the clock read between batches only, until it has
run `std.testing.bench.least` (500 ms), and reports the outcome `measured(.{ .iterations, .nanos
})`, counted in the totals' `measured`. `b.keep(&x)` is a volatile read of a byte of `x` (none for a
zero-sized `T`), which keeps what makes it without copying what it owns. `vun bench [path] [names]`
builds the tests' program as `vun test` does and shows each benchmark's time per iteration
(`vun_term::Nanos`); `std.testing.Options` moves to `std.testing.options`
