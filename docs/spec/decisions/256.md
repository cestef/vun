# 256. Calling conventions are data in one crate, `vun-abi`

Status: accepted
Where: 13

Calling conventions are data in one crate, `vun-abi`: the `Rules` of each convention (System V,
AAPCS64, Apple's arm64, later LP64D and wasm32's C; the registers it names are each instruction
set's, `compiler/asm/*/src/conventions.rs`) and one classifier, `Passing::of`, giving each LIR value
of a signature a typed placement (register by class and position, stack, parts, copy, address of a
copy) that the backends read; each target names its convention in its description
(`lang.target.Spec.convention`, an enum, no default from arch and ABI)
