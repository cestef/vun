# 209. `lang.target.CCompiler` gains

Status: accepted
Where: 13
Note: the user's approval

`lang.target.CCompiler` gains `attributes: lang.target.Attributes` (`.none`, or `.gnu` for GCC and
Clang, which `targets.gnu` sets): the C backend places a data object aligned past every C type, or
in a link section (`#[link.section]`), with `__attribute__((aligned(n), section("name")))`, a
section name written as a string literal with nothing to escape; without it both stay refused
(`backend.lacks`), as C99 lacks them
