# 328. A constant shifted by an amount known only at run time has no width

Status: accepted
Where: 04

A constant shifted by an amount known only at run time has no width (`int.width_cap`, rule 5):
`lang.int.shifted_left` finds its range depends on a run-time value (`Unevaluated::Runtime`), which
typing reports where the call runs at run time; at compile time the value is computed exactly.
Before, typing gave it no type and MIR stopped with no report
