# 449. A stop on a board with no console is passed on in the reboot into BOOTSEL

Status: accepted
Where: 12

A stop on a board with no console is passed on in the reboot into BOOTSEL: its two parameters carry
the kind, program counter and fault address, status or trap site (`rp2350.record`), which `picotool
info -a` prints as "reboot param", instead of the watchdog scratch registers no stock tool reads
