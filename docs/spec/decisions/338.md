# 338. Lints run

Status: accepted
Where: 10

Lints run: a `lang.lint.Lint` states a check per kind of node (`.decl`, `.call`, defaulting to
`lang.lint.unchecked`, which is not run); the compiler walks each file once (`Linted`, absorbed by
`Checked`) and runs each check of the lints its package, its dependencies and `std` define
(`#[lint.define]`, `DefinedLints`) as a pure compile-time call, `lang.lint.reports`, `Cx` gathering
the reports; a report's id is the lint's path and its level the lint's default or its group's
`level`; `#[lint.allow(lint, reason)]` (reason positional: there are no named arguments) silences a
lint inside a declaration; `call.calls(f)` compares a call's callee with `f`
