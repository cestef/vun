# 508. What keeps a function whole under `Outline` is a register that is the caller's

Status: accepted
Where: 13

What keeps a function whole under `Outline` is a register that is the caller's state, not any named
register. Each instruction set's table declares them as `Kept` (x86-64 `rsp`, `rbp`; arm64 `x29`,
`x30`, `sp`; Thumb `r7`, `r11`, `sp`, `lr`, `pc`), the generator gives `Reg::kept`, and
`Registered::keeps` reads the registers a block names and those its forms use unnamed (`push` uses
the stack pointer). The runtime's blocks name scratch registers (`mov(rdi, ...)`), so they now move
into functions of their own. Replaces `Block::names_registers`. A function whose blocks name one
register in two of them keeps all its blocks, since the registers may carry state between them.
Measured on a program of 179 functions built through Cranelift: 16 blocks move (decision 502
measured one in 5,400 functions)
