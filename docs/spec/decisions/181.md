# 181. Output and command line redesigned after cargo and jj

Status: accepted
Where: 12, 13
Note: the user's choices of the tree, implicit fetch and the framework features

Output and command line redesigned after cargo and jj: terminal text names its style
(`vun_term::Style`, one palette), results go to standard output and status lines (`Checking`,
`Finished` in time, `Failed` with errors, `Downloaded`) to standard error after each step's
diagnostics; `--color` (`VUN_COLOR`, `NO_COLOR`, `CLICOLOR[_FORCE]`, `TERM=dumb`) and `-q` are the
global options; compile options (`--target`, `--diagnostics`, renamed from `--format`, `--timings`)
form a set on the compiling commands; planned commands leave the tree (and `cli.unavailable_command`
goes); fetching is implicit before compiling (`vun pkg fetch` goes); `vun-command` declares
parameters with arity, values (text, path, choice), variables, aliases, option sets and examples,
from which it validates, renders short (`-h`) and paged long (`--help`) help, and generates bash,
zsh, fish and nushell completions (`vun util completion`)
