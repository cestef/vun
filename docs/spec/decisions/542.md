# 542. `Vec.split_off(A, a, at)` moves the items from `at` on into a new vector

Status: accepted
Where: 05, 06

`Vec.split_off(A, a, at)` moves the items from `at` on into a new vector (an allocation, so a
`Result`); `Vec.drain(range)` is a coroutine yielding the items of the range and closing the gap in
a `defer`, so ending it early closes it too. `Vec.with_capacity` frees its empty vector when the
reserve fails, as a linear value must be consumed
