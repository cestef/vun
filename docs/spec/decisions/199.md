# 199. `#[impl(I(T))]` checks each provided requirement's type

Status: accepted
Where: 02

`#[impl(I(T))]` checks each provided requirement's type: the requirement's type in `I(T)` must
accept the witness member's type, and where `type` is required a value that is a type is accepted (a
tuple of types included, decision 89); a requirement type that names another requirement (such as
`Error`) does not evaluate and is not compared; a mismatch is `impl.requirement_type`, labeling the
requirement
