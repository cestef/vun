# 311. Division without a division instruction

Status: accepted
Where: 13

Division without a division instruction: legalization's restoring division helper, made per count of
limbs, also divides integers no wider than the widest where the backend says it has no instruction
for them on the target (`Legalize.division: Division::{Computed, Restoring}`, from
`Backend::division(target)`, `Computed` by default since the C compiler and the other backends
choose their own). The native backend answers per architecture from the table and the target's
processor (`Native::divides`: whether the processor has a form of each division instruction at the
register's width, `Op::available`), so Thumb without `divide` (Armv7-A before the virtualization
extensions) divides through the helper of one limb, operands sign- or zero-extended to the widest
and the result truncated back, instead of being refused; checked on `linux.arm` with `divide`
removed, under qemu, against the host. No language surface changes. `Buffer::rewrite` replaces
emitted instructions by those written into a buffer for the same processor, keeping what it lacks
