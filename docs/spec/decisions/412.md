# 412. `windows.x86_64.msvc` is a target

Status: accepted
Where: 08, 12, 13

`windows.x86_64.msvc` is a target: PE (`object_format = .coff`, programs named `.exe`, libraries
`.dll` and `.lib`), built through the C backend with clang for `x86_64-pc-windows-msvc`, linked by
the COFF flavor of lld (`lld-link`: `/out:`, `/entry:`, `/subsystem:console`, `/nodefaultlib`,
`/machine:`, `/libpath:` the target's sysroot, its libraries as `.lib` after the objects), `threads
= .one`, LLP64 (`targets.llp64`), `targets.c_only` for its backends. Its runtime, `std.os.windows`,
calls `kernel32` itself with no C runtime: file numbers are handles (low 32 bits, sign extended; 0
to 2 are the standard streams), paths and the command line are UTF-16 (`std.text.utf16`,
`std.os.windows.command_line` splitting as the C runtime does), the clocks are the performance
counter and the precise system time, a console is set to UTF-8, `__chkstk` probes a large frame page
by page (`std.os.windows.stack`, the same instructions as compiler-rt's), and the string functions a
freestanding C compiler calls moved from `std.os.linux.kernel.memory` to `std.os.memory` for both
runtimes. Programs built through it run under Wine with the machine's tools file naming it as the
`.runner` and the directory of `kernel32.lib` as the `.sysroot`
