# 125. Library diagnostics

Status: accepted
Where: 03, 10

Library diagnostics: `lang.diag.error($message, $at: ?Origin)` stops compile-time evaluation with
`comptime.reported`; `std.diag.error(Report)` with `Report { at, msg, fixes }`; a report without a
place moves, at each call absorbing an instantiation's reports, to that call; the typer runs `$e`
where it surely runs and reports traps of `$if`, `$for`, `$e` and instantiated signatures;
compile-time calls evaluate arguments as their parameters' types, and methods through borrows;
`lang.meta.items($T)` gives a tuple's item types; `std.fmt.print` reports a format whose `{}` do not
match its arguments
