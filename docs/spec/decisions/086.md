# 86. Code values are `lang.meta.Code(T)` values holding the expression and what it

Status: accepted
Where: 03

Code values are `lang.meta.Code(T)` values holding the expression and what it was written under (the
call and every bound binder), so splicing evaluates it where it was written; a quote `#{ e }` has
type `Code(T)` for `e: T`; `$c` for `c: Code(T)` has type `T`; an argument for a `Code(T)` parameter
is typed against `T` and passed as code (MIR `Rvalue::Quote`); `Code(T)` accepts `Code(U)` when `T`
accepts `U`; a code value is passed on by borrow, and `std.meta.Quoted` (an impl for
`lang.meta.Code`) gives `c.source()` and `c.span()`, replacing `std.meta.source(c)`/`span(c)`;
splicing code that reads run-time locals of another function waits for expansion at the call site
