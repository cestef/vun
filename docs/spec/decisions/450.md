# 450. The RP2350 board serves a polled USB serial console on the chip's own USB

Status: accepted
Where: 12

The RP2350 board serves a polled USB serial console on the chip's own USB (clock at 150 MHz from
PLL_SYS, 48 MHz from PLL_USB), with the chip id as serial number and the vendor reset interface, so
the first program can show life and `vun flash` replaces a running program
