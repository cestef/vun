# 146. A `yield` is an exit

Status: accepted
Where: 06, 13

A `yield` is an exit: MIR gives it a cancel path running what is pending there (terminator `Ended`),
which `end` of a frame suspended there takes; a linear local held across a `yield` must be consumed
by a deferred statement or it leaks; `for p in e` ends its iterator on every exit and `yield ..e`
ends `e` when it returns and when cancelled
