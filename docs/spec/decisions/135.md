# 135. Compile-time `&mut`

Status: accepted
Where: 03

Compile-time `&mut` (decision 88's missing memory model): an exclusive borrow is a loan
(`Value::Loan`, a local of the running call and the parts under it), followed by `.*`; calls copy
what a loan reaches in and give back what exclusive parameters hold (`Metered::written`), stored
through the loan, so calls stay pure and memoized; a returned loan into a parameter is rebased on
the caller's loan; loans nested in aggregate arguments, and frames holding what they were lent, are
unsupported
