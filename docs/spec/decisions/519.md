# 519. Reflection of requirements and function types

Status: accepted
Where: 03, 02

Reflection of requirements and function types: `lang.meta.members(T)` (a `lang.meta.Member` per
declaration of a struct type: name, type where known, whether its value is `_`),
`lang.meta.signature(F)` (`?Signature`: the parameter tuple `Params` and the `Returns` of a function
type) and `lang.meta.Tuple(items)` (the tuple type of types), all in `std.meta`; a call of an
interface value (`I(Self)`) is typed as the call of the function it wraps, so a body can name `I(T)`
for a `$I: lang.Interface`
