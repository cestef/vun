# 516. A loan nested in an aggregate argument of a compile-time call

Status: accepted
Where: 03
Amended by: 647

A loan nested in an aggregate argument of a compile-time call (a struct field, a tuple or array
item, a variant payload, at any depth) is lent as 135 lends a top-level one, through storage that
follows the arguments: the call's `Instance` carries, after its arguments, the value each nested
loan reaches, and the aggregate holds a loan of that slot (`Frame::lend`), so the callee follows it
with the loan paths it has (`.*`, passing on, returning it, whole reads); the frame gives each slot
a local past the body's (`Frame::new`, `Loans::relocate`), and `Metered::written` gives back each
such slot after the parameters, stored through the loan it came from. A loan returned out of the
callee into such a slot is rebased on the caller's loan as one into a parameter is. Still
unsupported, and never silently wrong: a loan nested in a result, in a value a parameter is left
holding, or in a closure nested in an aggregate; a loan whose target holds a loan; a frame holding
what it was lent
