# 225. A query table stores each key with its hash, computed once

Status: accepted
Where: 13

A query table stores each key with its hash, computed once (`Hashed`, looked up through a `Probe`):
a key asked for the first time is hashed once for the lookup and the insertion, and keys of other
hashes are never compared. Saving memos is timed (`save memos`), and its layout and the codec's
pools hash with foldhash rather than SipHash (168 to 141 ms for 90,000 memos)
