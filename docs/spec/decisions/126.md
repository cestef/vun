# 126. Executors in `std.task`

Status: accepted
Where: 06

Executors in `std.task`: `Event` with an atomic mark (`fire`, `take`), `Wait { event, also: ?&Wait
}` chained for alternatives, `select` (`Either`), `run` over a tuple of tasks with the runtime
symbol `std.task.sleep`, `block_on`; a frame's `resume()` and `end()` are its interface's
requirements (typed through `Typer::required_member`, lowered to MIR `Resume` and the new `End`, the
table `iteration` naming `end`); frames record the call their interface is written as, so `$F:
Async(A)` infers `A`; a call of an empty type ends its MIR block
