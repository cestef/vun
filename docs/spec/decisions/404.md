# 404. A function literal that is a member of the witness an impl declares and leaves

Status: accepted
Where: 2

A function literal that is a member of the witness an impl declares and leaves a run-time
parameter's type or its result out has them from the requirement of its interface with the member's
name, with the `Self` the impl is for (or what the target constructor makes of the parameters the
witness's function binds) and the requirement's `$` parameters bound to those the member binds at
their positions: `format := ($W: Writer, value, w) { ... }`. Where the member leaves parameter types
out, the requirement is where its parameters are written (`Func::written`), so a call infers its `$`
parameters from the arguments, and passes them as the requirement's borrow modes say, as for a
function written in full. What the requirement names that no instantiation binds yet is read per
instantiation (the generic body is checked in each, spec 02, section 3), and a result that names a
`$` parameter's member, `W.Error`, is known there only. A member of the struct a `#[lang.derive(f)]`
function `f` builds has the requirement of the interface deriving it, with the type `f` is given as
`Self`. A member with another number of parameters than its requirement is given none of its types,
and the report names both counts
