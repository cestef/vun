# 207. The native backend's instruction compilers take the target's variant of its C

Status: accepted
Where: 13

The native backend's instruction compilers take the target's variant of its C calling convention
(`Isel::Convention`, chosen by `Native::convention` from the target's `abi`): arm64 follows AAPCS64,
or Apple's variant for `darwin`, which gives a C call's scalars on the stack their own size at their
own alignment (`Loc::Stack { offset, bytes }`, stored at that width), as clang lays them out
