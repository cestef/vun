# 675. The binder binds what a request names

Status: accepted
Where: 07

The binder binds what a request names (`vun_binder::Request`): `scope` directories beside the
header's own (paths compared as the file system has them, `..` resolved), `only` globs (`*` for any
run) that keep the declarations they name and, by a closure over the types each is written with,
what they need, and `libraries`, each with the directory of the headers it declares, the deepest
naming a declaration's header giving its `link.library`. A variadic C function binds as a pack
import (spec 07), a typedef of an incomplete struct as an alias, plain `char` as `u8`, macros of
integers, floats and strings as constants (`macros::Names`), and a nullary function type as `() ->
()` since `()` is the unit type. `Reason::Variadic` is gone
