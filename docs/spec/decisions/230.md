# 230. A block jumping to itself heads a loop of its own

Status: accepted
Where: 13

A block jumping to itself heads a loop of its own (`analysis::Loops`), and a loop head's parameters
are held in callee-saved registers like the values spanning a loop: the one-block LCG loop keeps its
state in registers and runs natively in 56 ms instead of 103 (the C backend at `-O2`, reading the
same simplified LIR: 51 ms)
