# 427. A package may name the target it is written for with `.target` in its

Status: accepted
Where: 12, 13

A package may name the target it is written for with `.target` in its `package`, a path of the
package `targets` as `--target` takes it (`vun_build::manifest::Manifest::target`,
`PackageData::target`). Checking or building a file of it chooses that target when no `--target` or
`VUN_TARGET` names one, instead of the running machine's, so a board's address arithmetic is checked
at the chip's width; a plan's programs still name their own. A board names the target of its
processor there, and no longer in a `target` declaration (365 named `stm32f4.target`, which nothing
read)
