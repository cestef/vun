# 60. `vun pkg update` reads versions from an index speaking a Go-proxy-style protocol

Status: accepted
Where: 12
Note: its format superseded by 118

`vun pkg update` reads versions from an index speaking a Go-proxy-style protocol
(`<index>/<id>/<major>/list`, `.../<version>.ovpkg`); an index is a mirror, never an authority: what
it serves is verified by hash
