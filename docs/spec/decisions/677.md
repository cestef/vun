# 677. `vun new` refuses a directory whose name is no name in code

Status: accepted
Where: 12, 10

`vun new` refuses a directory whose name is no name in code (`vun_syntax::lexer::is_ident`: letters,
digits and `_`, not starting with a digit) with `new.bad_name`, which suggests the name with each
other character an `_`; a package is reached by its name (`gtk_todo.model`), so one a program cannot
write is no package. A template's doc comments name no template. `closest` never suggests a name to
itself, and a report of a generic body checked per instance (`places`) names the instance (`in keep
for File`)
