# 89. Patterns lower to tests in MIR

Status: accepted
Where: 01, 13

Patterns lower to tests in MIR: a test branches to a failure block, binds on success (a copy, or
through a borrow a borrow in its mode), and reaches parts through `Position` (tuple items) and
`Payload` (a tested variant's payload) projections; `Rvalue::IsVariant` is a condition; `match`
tests arms in order and ends in `Unreachable`; `if p = e`, `for p = e` and declarations with a
pattern use the same tests; or-patterns bind into the first alternative's locals (decision 194). An
annotation that cannot be evaluated as written is typed first and evaluated with those types, and
where `type` is expected a tuple of types (`()` included) is a type
