# 640. `#[test.traps()]`

Status: accepted
Where: 11

`#[test.traps()]` (`std.testing.test.traps`, a `std.testing.Traps` attribute) expects the test to
trap: a trap passes it, and ending without one reports a trap with no site and the text "the test
did not trap" (`Outcome.expecting_trap`, so `Outcome` and the driver's schema are unchanged). Which
trap ended it is not checked, since the program's table holds a site's text, not a typed kind
