# 272. A diagnostic's explanation page is found by its binding path, as a namespace's

Status: accepted
Where: 10

A diagnostic's explanation page is found by its binding path, as a namespace's source is (spec 01,
section 8), with the extension `md`: `lang.errors.int.does_not_fit` has
`lang/errors/int/does_not_fit.md` in its package, and a package's lint (`mydrivers.lints.raw_mmio`)
is found the same way in its own. `lang.diag.Diag` is `struct {}`, so an entry is `does_not_fit :=
diag.Diag{};`; `cargo gen` derives `EXPLANATIONS` through `vun_build::layout::Location::at`.
