# 279. Linux targets are static by default

Status: accepted
Where: 08

Linux targets are static by default: `targets.linux.<cpu>` (ABI `kernel`) runs on
`std.os.linux.kernel`, a runtime making system calls itself (naked `_start`, `string.h` exports in
assembly, the checks' shadow through `mmap`), linked `-static -nostartfiles -nolibc`; programs on
the GNU C library use `targets.linux.gnu.<cpu>` (ABI `gnu`, runtime row `std.os.linux.gnu`)
