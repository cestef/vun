# 401. `impl I for T { members }`, `impl T { members }` and `impl I for T = value;`

Status: accepted
Where: 2

`impl I for T { members }`, `impl T { members }` and `impl I for T = value;` declare a witness, the
methods of a type, and a witness that is a value (`NodeKind` `implementation`, `extension`,
`delegation`; `impl` is a word only before a name, `grammar.Context.declaration`). A target binds
the parameters of its constructor as a function does, `Int($r)`, every argument or none. HIR
lowering makes of each the declaration `_ := ...` carrying `lang.impl(I(C))` over a function of the
binders returning `struct { members }` (or the struct, or the value), with every origin the head's,
so witnesses, conformance and reports are those of the attribute form, which stays. `Json` is
derived by default as `Eq`, `Hash` and `Debug` are, so no impl restates a derivation. 65 impls of
`lang` and `std` are written so; the item tables drop their names
