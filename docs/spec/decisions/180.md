# 180. Timings

Status: accepted
Where: 13
Note: the user's requests

Timings: every query computation and every driver stage is an activity timed where it runs, summing
runs, own time and total time over threads; `VUN_TIMINGS=1` or `--timings` prints the table at exit.
Logging is off unless `VUN_LOG` asks, with one meaning per level across crates (`info` a step of a
run, `debug` a unit of work, `trace` an element)
