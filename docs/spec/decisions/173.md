# 173. NaN is defined

Status: accepted
Where: 04, 13
Note: the user's request

NaN is defined: every operation whose result is a NaN gives the canonical NaN of its format (sign
clear, exponent all ones, only the top fraction bit set), whatever NaN its operands held; `neg`,
`bits`, `from_bits`, moves and copies keep every bit. A float result is one encoding on every target
and at compile time; lowering selects the canonical NaN after each float operation whose result is
unequal to itself
