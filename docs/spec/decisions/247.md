# 247. A file's persisted key is typed

Status: accepted
Where: 10, 13

A file's persisted key is typed, `FileRef { package: PackageId, path }`, not `name@version/path`
text: a stored package, which never changes, is named by its content hash, so a fork of one release
keeps keys of its own; a package on disk, edited in place, by its declared name, identity and
version, which edits keep (decision 59); loose files by their path. `PackageId` is also the key of
the queries' package inputs
