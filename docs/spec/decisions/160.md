# 160. Calls read their arguments one way

Status: accepted
Where: 03, 07, 13

Calls read their arguments one way (`Env::passing`, shared by compile-time evaluation and MIR):
receiver, inferred `$` arguments, code, compile-time values (MIR `Comptime` with the parameter's
type, evaluated by the call running the body, never folded while building) and run-time values;
parameter types and quoting come from where parameters are written (`Written::{types, quotes}`), for
functions and primitives alike; the interpreter runs a call in its environment with the
instantiation's types (`Instantiation::running`). Calls passing code expand at the call site,
splices of caller code (MIR `Splice`) built there; run-time `lang.panic.fail` is a trap site whose
