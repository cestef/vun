# 111. Every spec 07 section 4 property is a marker of the function type

Status: accepted
Where: 07, appendix B
Note: the user chose to fold all properties into markers

Every spec 07 section 4 property is a marker of the function type (`Marker { item, args }`, in
`lang.Fn`'s third argument): attributes on function literals, function types and declarations, and
the prefixes of `markers`; the table `fn_markers` gives each a relation (`duty`, `guarantee`,
`bound`, `identity`) and acceptance compares them generically. `#[panic.never]` is checked on MIR
(`PanicChecks`): calls of functions without the promise, divisions by a value whose range holds 0,
`Narrowing::To` of a value that may not fit, and indices not proven within an array; the
non-trapping primitives of `lang.int` and `lang.mem` and the matching `std` functions carry the
promise
