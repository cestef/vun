# 298. Atomic accesses of integers wider than an address are `#[lower.soft]` to

Status: accepted
Where: 05, 13

Atomic accesses of integers wider than an address are `#[lower.soft]` to `lang.mem.soft.{load,
store, swap, compare_swap, add, sub}`: on Thumb (`isa == .thumb`, 8 bytes) loops of
`ldrexd`/`strexd` between `dmb sy` in inline assembly, as the word's isel makes them; elsewhere
`lang.diag.error` while compiling. The Thumb table gains `ldrexd`, `strexd` and the memory mode
`exclusive_pair`, and each word form a typed `Profile` (`every`, `application`), which the llvm-mc
test assembles on a core of its profile. Native inline assembly clobbers every register a block
names, inputs included (a value read in `r0` was kept there past a block writing `r0`), and a
register or bound value no longer fits a position taking none (the checker panicked on `cmp r4,
{in(r2) x}`, whose first form takes an immediate), on Thumb and arm64
