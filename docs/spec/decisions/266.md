Exit statuses are `std.os.Status := Int(1..=125)`, the range every supported system passes on
(shells reserve 126, 127 and 128 plus a signal; WASI `proc_exit` refuses 126 and above): `Exit :=
enum { ok, code(Status) }`, `Exit.status() -> Int(0..=125)` and its inverse `Exit.of`, `trapped:
Status = 101`; an out-of-range `.code` is a type error, so no runtime validates it. Rejected: a
