# 292. Legalization splits every integer wider than the backend's widest into limbs of

Status: accepted
Where: 13

Legalization splits every integer wider than the backend's widest into limbs of the widest
(`AbiType::Wide { limb, limbs, ext }`), so a 32-bit target computes `i64` as two limbs and `i128` as
four; the native backend's widest is the target's address width (`Widest::Register`), the others' a
fixed width; division calls a helper per count of limbs; C has no integer of more than two limbs
(`Unpassable::Integer`, `backend.lacks` as a width)
