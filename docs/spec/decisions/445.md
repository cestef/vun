# 445. `vun build` and `vun test` of a package, a workspace or a directory check every

Status: accepted
Where: 12

`vun build` and `vun test` of a package, a workspace or a directory check every file they cover as
`vun check` does before building, so a lint a file denies is reported though no program reaches the
file, as when a call of it is folded at compile time
