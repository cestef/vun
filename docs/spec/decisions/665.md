# 665. BLAKE3 is built with its SIMD code

Status: accepted

BLAKE3 is built with its SIMD code (NEON, AVX2 and AVX-512 chosen at run time), not `pure`; this
replaces the BLAKE3 clause of decision 67. `vun debug profile` put the portable compression at 19%
of the instructions of a warm check, which hashes the library files it reads, and `ring` already
needs a C compiler.
