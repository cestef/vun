# 650. Guaranteed tail calls

Status: accepted
Amended by: 653

Guaranteed tail calls (spec 09, section 3). `lang.flow.tail(f, args)` is typed from `f`'s signature
and is the value of a `return` (`flow.tail_position` otherwise); MIR builds it as the last statement
before `Return`, after the pending defers, and the borrow checker treats its arguments as escaping
(`borrow.escape`). LIR has `CallKind::Tail` on `Call`, verified to end its block by returning its
value; passes keep functions holding one out of inlining. Native (x86-64, arm64) and C (`musttail`)
implement it for register-only signatures; the others report `backend.lacks`. A member asked of a
type that has none, where only a `$` argument gave the type, is the `comptime.trap` reason
`NoMember` instead of a silent give-up
