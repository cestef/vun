# 333. `lang.simd.Vector(n, T)` is laid out as `[n]T`, aligned to its size when a

Status: accepted
Where: 03, 04

`lang.simd.Vector(n, T)` is laid out as `[n]T`, aligned to its size when a power of two (capped as
the widest scalar); `lang.simd.lanes`, `of` and `Lane` move between a vector and its lanes,
`chunks(n, w)` gives run starts for a `$for`; `std.simd` implements `splat`, `load`, `store`,
`shuffle`, `reduce_add(.pairwise(w))` and the `lang.ops` operators lane-wise in Vun, a lane's result
typed by `lang.meta.witness(I, T)`, the struct `T`'s impl of `I` gives. No backend emits vector
instructions yet: vectors run as their lanes
