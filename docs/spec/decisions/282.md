# 282. A borrow serves where another is expected when it performs the same transition

Status: accepted
Where: 05
Note: the user's choice

A borrow serves where another is expected when it performs the same transition and leaves others no
more access (`Borrow::serves`, read from the table `borrows`): `&mut T` is accepted where `&T` is
and branches of both join as `&T`; `&out` and `&take` never serve as `&T`; lowering copies a borrow
into one of another mode of the same pointee
