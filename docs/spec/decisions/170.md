# 170. Lowering covers every run-time form

Status: accepted
Where: 05, 13

Lowering covers every run-time form: a callee is a function, a closure (its function, the captures
first, constant or held in a place) or a function value (an indirect call of its type's signature);
a call of a primitive whose parameters are all `$` ones, with constant arguments, and of a variant's
constructor are folded when the body is made concrete; `lang.int.fits`, `abs`, `lang.meta.variant`,
`lang.mem.{address, offset, cast}` lower to instructions; a deferred statement consuming linear
values runs or is skipped at each exit as the place states decide (`Placed`). A borrow of a
top-level binding reaches its one storage, never a copy, and an immutable binding holding a cell
(`Kind.interior`) is stored writable. A closure's type holds its function (`Func`, `$for` bindings
included). A `$for` step's binders are typed per step
