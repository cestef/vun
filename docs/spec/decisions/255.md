# 255. Positions are shown through a compilation's view of the files it reads

Status: accepted
Where: 10

Positions are shown through a compilation's view of the files it reads (`vun_origin::Resolve`): an
origin recorded in an earlier text of a file it now reads in another, as a reused saved query holds,
is found relative to its declaration as the current text declares it; the process's tables keep
every text, and the view says which is current
