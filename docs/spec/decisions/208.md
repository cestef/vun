# 208. The mold and wild adapters link ELF through the target's C compiler, sharing

Status: accepted
Where: 12, 13

The mold and wild adapters link ELF through the target's C compiler, sharing GNU ld's driving
(`vun_link_gnu::Ld`: the compiler's own `ld`, `-fuse-ld=mold`, or wild linked as `ld` into a
directory given with `-B`); `--linker` (`VUN_LINKER`) names a build's linker instead of the
target's, refused with the new `link.unsupported` for a format or regions it does not link.
`Edit::link_to` makes a symbolic link as `put` writes a file
