Status: accepted

`vun util ffi bind --split --out <file>`, the file inside a package, binds the declarations of each
directory of headers in a file of its own beside the output, in the directory of its name
(`app/gtk/sys.vun` spreads `app/gtk/sys/glib.vun`, `gtk.vun`, ...); a request carries the namespace
the output is (`Request::module`, from `Session::module_of`), and a type of another file is written
by its whole path (`app.gtk.sys.glib.GObject`), which needs no import and lets files name each other
both ways. A file outside any package is `tool.split_place`. The result carries the `Part`s beside
the root file
