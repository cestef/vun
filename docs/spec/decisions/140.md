# 140. `std` additions

Status: accepted
Where: 05, 06, 08

`std` additions: `zip`, `chain`, `fold` on every frame; `std.os.System.args()` gives `Args` over C's
`argc`/`argv`, with `len`, `get` and `for` (`lang.ops.Iterate`), each argument read through the new
`unsafe lang.mem.items_at(T, p, n)`, the inverse of `items_pointer`; `Fixed` implements `Allocator`,
its own method renamed `take` since a type's member and an impl method of one name collide; `&e` is
a borrow type wherever `e` denotes a type (`&[u8]` as an argument)
