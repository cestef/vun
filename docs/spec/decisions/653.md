Status: accepted
Where: 09, 13

Tail calls reach Cranelift, and results that the callee writes through the caller's address are
allowed everywhere the backend can pass them. Cranelift jumps only between functions of its `tail`
convention, which nothing else can call, so each function that tail calls or is tail called is
compiled as a body in that convention behind an entry of the target's convention calling it, in one
code (entry first, body at an aligned offset, relocations to the body carrying its offset as
addend); tail calls jump to bodies, everything else to the entry. A group of functions joined by
tail calls is compiled whole or not at all (one another backend compiles would jump into an entry
and grow the stack), found by lowering until the group is stable (`Tails`). Wide integer results are
written through the address received (`Parts::Written` in legalization, replacing
`Unlegalized::TailResult`), and the lowering no longer refuses a C function's result in memory.
Rather than the conventions Cranelift lacks (`return_call` accepts only `tail`) or compiling the
whole unit in `tail` (Wasmtime's choice, whose boundary is a host with trampolines: here backends
assist one another across the unit, calling each other in the target's convention)
