# 196. Exhaustive `match`

Status: accepted
Where: 01

Exhaustive `match` (decision 29) is checked by the typer as the usefulness of a wildcard against the
arms (Maranget 2007): enums split by variant, tuples and structs by their parts, integers by the
ranges the arms name, other types only by `_`; value patterns count by their compile-time value
(`true`, `Color.red`, `3`); an arm with a guard covers nothing; what is not known (a type not
evaluated, an enum whose variants are generated) counts as covered; `binding.missing_case` names one
value no arm matches, written as a pattern
