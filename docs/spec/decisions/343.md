# 343. Inline assembly is ordinary Vun, replacing 258's block syntax

Status: accepted
Where: 01, 02, 07, 13

Inline assembly is ordinary Vun, replacing 258's block syntax (the owner's choices: a block of calls
passed as code, names the architecture declares brought by a spread, an impl covering every argument
tuple through `_`, a mnemonic's parts as leading operands): a block is `unsafe lang.arch.asm({ ...
})`, `lang.arch.asm` taking the block as code (`$code: Code(())`), each statement calling an
instruction `lang.arch.<arch>` declares (a family's members too) or declaring a label; an
instruction is callable with any operands through `#[impl(lang.ops.Call(_, ())(Instruction))]`, an
argument `_` of an impl's interface meaning any, the witness taking one value per `_`; an enum's
variants are members of its namespace, so `..Cond;` brings them, and each architecture's `names`
namespace spreads the operand forms, the enums naming its registers at each width, its conditions,
the words its positions take and its instructions (`..lang.arch.x86_64.names;`), a `Mnemonic` naming
the instructions one name spells; an enum of registers says what it names as its attribute
(`#[Registers{ ... }]`), an enum of choices its kind (`#[Choice.barrier]`), attributes being plain
data found by type; a spread written as a block's statement brings names into the block, found after
every scope around a name and exporting nothing; operands are values: registers, integers known at
compile time as immediates, a declaration's address, `in(e)`, `out(p)`, `inout(p)`, `.at(r)` naming
the register (`in(e).at(rdi)`), `mem(base, ...)` with `scaled(index, n)`, `pre`/`post` for
write-back, labels made by `here()` or `label()` and marked by `place(l)`; conditions, encoding
widths (`w`, `n`) and types are leading operands, a width of a form listing the types that select it
(`Sized.types`: `ldr(u8, ...)` is `ldrb`, `vcvt(i32, f32, ...)` is `vcvt.s32.f32`) and one listing
none selected by no type or the one type of its width, the assemblers' spelling derived from the
types; the grammar loses the `asm`, `line`, `suffix`, `bound` and `memory` kinds,
`operand_contexts`, `line_ends`, the contextual `asm` and the flow words
