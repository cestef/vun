# 190. Machine-readable output

Status: accepted
Where: 10, 12

Machine-readable output: the global `--format human\|json` (`VUN_FORMAT`) decides how everything a
command shows is shown; commands report typed records (`vun_term::Record`: a `type`, text for
people, fields for programs; `Status` for progress, `Row` for tables, `Document` for named texts
such as dumps and pages), never text they format themselves; in `json` every line of standard output
is one object naming its `type` (`started`, `finished`, `downloaded`, `component`, `stored`, `dump`,
`timings`, ...) and diagnostics are `"type": "diagnostic"` lines of a versioned schema
(`vun-render-json`, `SCHEMA` 1: ids, severity, messages as text and typed parts, locations resolved
to file, line, column and bytes, children, fixes with edits, trace); global options are read before
the command line is parsed, so usage errors follow them; a run program's own output is its own
