# 668. Saved memos hold wherever the toolchain and the libraries are

Status: accepted

Saved memos hold wherever the toolchain and the libraries are. The compiler is named by the BLAKE3
hash of its executable (`Build::identity`, remembered by path, size and time in the store's
`builds`), not by its path and time; a package's input holds no directory (`Locations` gives a
file's path on this machine, and a file in a saved stream is its key and text); the span of a
manifest is of the package's file. A file of shared memos is mapped, not read (`vun_fs::Mapped`, the
exception to `unsafe` denied: a file is written whole beside its name and renamed into place, never
changed or truncated, as rustc's metadata files are), and a query's keys are found without reading
the others (format 14: a key's hash first, where each starts, and a probe table), so that loading
costs what a run asks for.
