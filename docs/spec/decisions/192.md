# 192. The native backend generates arm64

Status: accepted
Where: 12, 13
Note: the user's choice of the machine file

The native backend generates arm64 (AAPCS64, ELF) through the same framework as x86-64:
`vun-backend-native` holds a table of architectures (name, object machine, compiler) from which
`INFO.arches` derives; the arm64 table gains `uxt` and `sxt`, extensions by source width; the
snippet encoder gives a result the register of an operand its first step reads for the last time
(three-address steps), and places the result after the step's operands; `vun_codegen::pieces` covers
byte counts by accesses for both architectures; atomics are exclusive-access loops (Armv8.0).
Building and running for another machine reads the machine's toolchain file (`vun/toolchain.vun` in
the user's configuration, or `VUN_TOOLCHAIN`), literal data naming per target a C compiler, flags
for each of its runs and a runner (an emulator); `vun run`, `vun debug compare` and the backend
tests run through it, and the backend tests run every program on linux.arm64 as well when the
machine runs its programs
