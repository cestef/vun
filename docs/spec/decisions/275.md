# 275. Each branch of a staged `$if` among statements is a scope of its own, as a

Status: accepted
Where: 03

Each branch of a staged `$if` among statements is a scope of its own, as a `$for` step is: its
declarations are not in scope after the `$if`, and both branches may declare the same names; a value
chosen at compile time is the `$if`'s value (`x := $if c { a } else { b }`)
