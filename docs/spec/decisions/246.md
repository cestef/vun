# 246. An integer wider than a register is a typed wide `AbiType` in LIR, not split by

Status: accepted
Where: 13

An integer wider than a register is a typed wide `AbiType` in LIR, not split by legalization into
`I64` halves; each backend's call classifier places it by its convention (an even register pair
under AAPCS64, two registers or memory under SysV)
