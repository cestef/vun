# 113. Rule 8 as typing

Status: accepted
Where: 04

Rule 8 as typing: at run time, `&`, `|`, `^`, `<<`, `>>` exist on `uN` types (`Int(0..=2^N - 1)`)
only and keep the type, the type of the run-time operand when the other is a constant; any other
integer type is `types.no_impl`. Compile-time integers are exact and keep computing without a width
