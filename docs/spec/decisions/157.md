# 157. The baseline backend

Status: accepted
Where: 13
Note: named `native` and layered by 183

The baseline backend (spec 13, section 8.3) is built for x86-64 and ELF: its own encoder and object
writer, one pass per function over `Order`, `Liveness` and `Moves`; homes in the frame, recomputed
constants and addresses, stores home at block ends and calls; Vun's convention on the C argument
registers; System V records; floats and 128-bit integers refused for now. `Lack` and `Missing` move
to `vun-backend`, shared by every backend. Lowering gains run-time division and remainder (in the
storage holding operands and result, the divisor checked where its range holds 0) and atomic swap,
add and sub
