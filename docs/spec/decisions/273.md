# 273. An integer in a literal or range pattern is an operand of the comparison the

Status: accepted
Where: 01, 02

An integer in a literal or range pattern is an operand of the comparison the pattern stands for, as
in an expression, so it need not fit the matched type: `0..=300` over a `u8`, and `0..=9` over a
`$n: u8` an instantiation types as its value alone (`Int(3..=3)`), are accepted; exhaustiveness
counts only the type's values. Other values in patterns are values of the matched type
