# 390. Indexing takes an integer or bounds

Status: accepted
Where: 02

Indexing takes an integer or bounds; any other index is `types.bad_index`, instead of typing giving
up silently and the build reporting a compiler bug. `xs[..n]` is the common case (a prefix `..` is a
pack, so the index is a type), whose fix writes the start, `0..n`
