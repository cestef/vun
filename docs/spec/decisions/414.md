# 414. `std.re` holds what a program reading binaries builds on

Status: accepted
Where: 12

`std.re` holds what a program reading binaries builds on: `Pattern(n)`, up to `n` bytes each a byte
to match or any, written as reverse engineers do (`48 8B ?? 05`, `?` and `??` wildcards), with
`parse`, `matches` and `find` over any `&[u8]`, and `hexdump`, a line of 16 bytes at a time with its
address, the bytes in hexadecimal and their ASCII, written to any `std.fmt.Writer`. Both are library
code over slices; a source that is not in memory, a file or a process, reads into a slice first
