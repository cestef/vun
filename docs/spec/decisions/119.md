# 119. `&temp T` and `&temp mut T` are rows of the table `borrows`

Status: accepted
Where: 05, appendix B

`&temp T` and `&temp mut T` are rows of the table `borrows` (`lang.mem.RefTemp`, `RefTempMut`) with
the extent `temp`: borrows of one transition and access accept each other, a call's scoped result is
not tied to its `&temp` arguments, and in the callee a `&temp` parameter is a loan that conflicts
with nothing and escapes when it reaches the result (`borrow.escape`)
