# 448. A `$` argument that reads a local its body computes when it runs is passed as

Status: accepted
Where: 03, 13

A `$` argument that reads a local its body computes when it runs is passed as that local's value
(`passed`, `reads_run_time_local`): the interpreter runs the call with it, so a function run at
compile time, as `$if has(d, A)` runs `has`, may loop and pass what it finds to a `$` parameter
(`same(type, t, A)`); in generated code it stays `comptime.runtime`, reported where the call is
(`Body::compile_time_arguments`), even for a local holding a constant
