# 344. `lang.diag.error` reached at run time refuses the program

Status: accepted
Where: 07, 10

`lang.diag.error` reached at run time refuses the program: a report outside any `$` form is no error
where it is written, only where a program built reaches it, shown at the call that led to it from
outside the reporting code (from each generic instantiation to the call that reached it, as a
compile-time report moves), with the calls between as frames; a library's report is shown before any
other failure to lower. An instruction's call impl reports so, so calling one outside a block is
refused at the call (`comptime.reported`), and `lang.arch.outside` is gone; any other failure to
lower in a generic instantiation stays where it arises, with the same frames
