# 197. Saved queries are loaded as they are used

Status: accepted
Where: 13

Saved queries are loaded as they are used: the body names each query and holds it encoded on its
own, each key with the stable hash of its value (`vun_hash::Stable`) and its memo; a query's keys
are read when one is first looked for, a key's memo when the key is first given a slot, a memo's
reads (positions in the file) when it is first verified, its value when first needed. A save
extending the loaded stream keeps every key at its position and copies what was never asked for; a
key keeps the fingerprint it was first saved with, and a memo or read records its own only when it
differs, so a memo copied unread keeps meaning what it read. A whole write restores every saved memo
