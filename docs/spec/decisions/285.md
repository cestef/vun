# 285. Packs

Status: accepted
Where: 01, 02, appendix B
Note: the user chose parameter packs over a C-only marker

Packs: a function's last parameter may be the rest pattern `..args: P` of its parameter tuple,
gathering the arguments after the others into a tuple of type `P`, written or a `$` parameter
inferred as the tuple of their types (one instantiation per call shape); in a function type it is
`..P`, `lang.Pack(P)` through the table `type_prefixes`; the typer plans each argument's parameter
(`Plan`, every argument past the others to the pack's) and records where each call's pack starts
(`TypedBody::packs`), which `Env::passing` reads for MIR and compile-time calls (`Passed::Pack`); a
written `P` takes as many arguments as it has items (`types.arity`), and a pack elsewhere than last
is `types.pack_position`; lowering passes a pack as its tuple under Vun's convention, and tuples
convert item by item
