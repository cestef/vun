Status: accepted
Where: 13
Note: in the framework by 183

The baseline backend fuses a compare into the branch that is its one use, keeps registers into the
block emitted next when only the block before reaches it (storing nothing at a plain jump into it),
and reports frame sizes (frame, return address, saved frame pointer) while emitting; backends report
frames into their `ArtifactSink` (`Emitted`), others through their tools' report
(`Backend::frame_sizes`)
