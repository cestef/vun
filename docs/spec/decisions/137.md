# 137. A shared borrow of what lives as long as the program is `&static`

Status: accepted
Where: 03, 05

A shared borrow of what lives as long as the program is `&static`: a literal, a tuple, array or
record of literals, or an immutable top-level binding (the row of the same transition and access
whose extent is `static`); a `mut` top-level binding has no compile-time value (its MIR storage is
`Role::StaticMut`, which the interpreter does not read); a binding's local has its annotated type; a
method whose type depends on its `$` parameters takes its receiver in the mode its first parameter
writes (`Func::modes`)
