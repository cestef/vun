# 191. Saved queries stay bounded and whole

Status: accepted
Where: 12, 13

Saved queries stay bounded and whole: the file is a header (format, the body's size when last
written whole) and a body; a save extends the loaded stream until the loaded body has grown past
twice that size, then writes the body whole, decoding the values never read. `vun_fs::Edit::put`
writes a sibling file and renames it over the target, so a file is replaced whole or not at all.
Symbols, interned values and origins hash by `vun_hash::Stable` (fixed-seed foldhash, stable within
one toolchain build) rather than BLAKE3, which stays the content hash of files, packages and caches.
A saved key carries its memo's fingerprint and a saved read its own only when it differs; queries
are encoded one by one and decoded in parallel
