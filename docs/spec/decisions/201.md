# 201. Native code quality

Status: accepted
Where: 13

Native code quality: a branch falls into its `then` block when that is emitted next, jumping on the
inverted condition (`vun_codegen::Layout`, also deciding which target keeps the registers); the
snippet encoder omits a move of a register to itself at the architecture's full width
(`Emits::WHOLE`); `Builder::binary` gives the left operand for an integer identity on the right
(`BinOp::identity`: `x + 0`, `x * 1`, shifts by 0, ...); x86-64 gains `mov r/m8, imm8`; the
prologue's frame size is listed as written (`Buffer::relist`). With decision 200, 13 to 49 percent
fewer instructions over the backend test programs, most by 36 to 49
