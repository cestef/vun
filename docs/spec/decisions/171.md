# 171. A path naming a member its namespace lacks is reported wherever it is written

Status: accepted
Where: 01, 13

A path naming a member its namespace lacks is reported wherever it is written (a body, a signature,
a field type, typed or not), and a member missing from a type and its impls through the type
(`u32.from_le`) as through a value; members of type parameters and frames come from their
interfaces. Coverage (`vun debug coverage`) counts function literals by the run-time instantiations
every closed function of the file reaches (`Roots::Functions`), apart from those that run only at
compile time (a parameter or result whose values do not exist at run time, `Exists`)
