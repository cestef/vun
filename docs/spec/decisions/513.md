# 513. `--diagnostics=sarif` is the renderer component `sarif`

Status: accepted
Where: 10

`--diagnostics=sarif` is the renderer component `sarif` (`compiler/components/renderer-sarif`, over
`vun-render-sarif`), which writes one SARIF 2.1.0 log per run on standard output. SARIF is one
document, so a `Renderer` may keep what its sinks are shown and write it in `Renderer::finish`,
which the renderer protocol carries as `Call::Finish` and the program's context calls once, after
everything else is shown (`Diagnostics::finish_diagnostics`, from `Context::finish`); a renderer
that keeps nothing writes nothing. Each result has the rule of its id (`ruleId`, `ruleIndex`, rules
in the order they first appear), its level (hint and info are `note`), the primary label as its
location, the other labels, the children's labels and the trace as `relatedLocations`, the children
as the property `children`, and each fix as a `fix` with the replacements of its edits per artifact.
An artifact is its file URI when its path is absolute, else the path as a reference relative to
`%SRCROOT%`; a column counts characters and ends after the last one
