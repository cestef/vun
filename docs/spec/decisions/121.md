# 121. `std.sync` in Vun

Status: accepted
Where: 05, 07, 08

`std.sync` in Vun: `critical($F: Call((&temp Critical), R), f)` lends the section for the call, over
the runtime's typed link symbols `std.sync.enter`/`leave`; `Shared(T)`, `Atomic(T)`, `Mutex(T)` with
a linear `Guard`, over `lang.mem.Cell`, `cell`, `cell_pointer` and
`atomic_{load,store,swap,compare_swap,add,sub}` with `lang.mem.Ordering`; `std.os` has `System`
(claimed by a runtime), `Stream`, `Exit`, and `start` over the C library runtime
`std.os.libc.start`, using `lang.mem.items_pointer`
