# 287. The libraries' memos are shared between projects

Status: accepted
Where: 13
Note: the user chose shared store entries

The libraries' memos are shared between projects: inputs are set as the project's own or as shared
(`Db::share`, `Sharing`: every package but the project and loose files, the target, the checks, and
inputs never set); a memo whose every read leads to shared inputs alone is saved whole by
`Db::save_shared` into an entry of the store's `memos` directory, by toolchain, target and checks,
which a session without memos of its own loads and a session that computed some the entry lacked
rewrites when it ends; tests share one directory per build of their binary; entries of other
toolchains are removed
