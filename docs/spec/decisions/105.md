# 105. An `enum` literal holds declarations after its variants and a `;`, which are

Status: accepted
Where: 01, 02
Note: the user chose namespaces while keeping `lang` minimal

An `enum` literal holds declarations after its variants and a `;`, which are its namespace as a
struct body's are (`enum { circle(u32), square(u32); area := ...; }`); the CST keeps both in the
slot `members`, split by node kind in HIR (`ExprKind::Enum { variants, ns }`). `lang`'s `Option` and
`Result` stay variants only: their methods live in `std` through `#[impl(T)]`
