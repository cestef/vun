The shadow of the checks of unsafe code follows a program's memory wherever the system puts it: a
directory holds a word per span of 2^32 addresses, the shadow of a span reserved the first time
memory in it is described (0 in the directory reads as accessible), so no width of the address space
is assumed (a fixed 47-bit shadow faulted on arm64 Linux, whose stacks sit above 2^47)
