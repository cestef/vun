# 410. A function literal that is a member of a witness and writes no result, whose

Status: accepted
Where: 02, 06

A function literal that is a member of a witness and writes no result, whose body suspends, has the
frame of the interface its requirement names as the result: `iter := (self) { ... yield ... }` in an
`impl lang.ops.Iterate` takes `Iter`, as `iter := (self) -> Iter { ... }` does
(`Context::interface`, read by `literal_signature_in`), and its parameters are typed apart from its
result (`Env::params_in`), so an interface, which is no type, does not stop them. Before, such an
impl gave up in typing and a `for` over its type failed with a compiler bug, `std.os.Args` among
them
