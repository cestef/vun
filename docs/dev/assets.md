# Assets

```
assets/palette.toml         brand schemes (light, dark, rose, mono) the cards read
assets/logo/                hand-drawn SVGs: wordmark/, mark/, icon/, construction.svg, motion/
assets/logo/logo.typ        the logo's geometry for Typst, in the coordinates of wordmark/*.svg
assets/cards/<card>/        card.typ and its outputs, one per variant: code/, social/, icon/, moods/,
                            lockup/, emoji/, stickers/, release/, diagrams/; a card's mascot/ holds its
                            versions with the mascot
assets/cards/figures.typ    the figures emoji and stickers share: each mood, the v, the wordmark
assets/cards/formats.toml   the sizes of the places a card is shown (social, release)
assets/diagrams/            diagram.typ, a diagram vocabulary in the brand, and the diagrams
assets/sound/               the sound mark, written by `pnpm sound`
assets/stream/              OBS browser-source overlays; generated/ by `pnpm stream`, obs/ by `pnpm obs`
assets/mascot/              the mascot, generated by `pnpm mascot` in assets/motion: stills, adaptive
                            (<mood>.svg) and per scheme (<scheme>/<mood>.svg), CSS animations (motion/)
assets/motion/              Motion Canvas projects (videos) and the kits' scripts
```

`*/adaptive.svg` follow `prefers-color-scheme`; `mono.svg` strokes in `currentColor`; `motion/`
animates with CSS and stills under `prefers-reduced-motion`. The logo's geometry is written twice,
in the SVGs and in `logo.typ`: a change to one is made to the other.

`cargo xtask typeset` compiles the table `typeset::ALL` of `xtask` (the whitepaper and the
cards), in parallel. A card with variants declares them itself as `#metadata(..) <variants>`: an
array of `(path: (..), inputs: (..))`, each compiled with its `sys.inputs` to
`<dir>/<path>.<format>`, once per format the table lists (the diagrams as PNG and as SVG, which
the videos scale; the sticker sheet as PDF). Adding a scheme to `palette.toml` or a size to a card
adds its outputs; a variant removed leaves its old output to delete by hand. The cards draw at 72
pixels per inch, so a point is a pixel.

The code card renders `corpus/accept/programs/tour.vun` (so the corpus keeps it compiling) with
`editors/sublime/vun.sublime-syntax` (generated from the grammar), in the colors of
`assets/cards/code/colors.toml`, each highlighting scope in the role `roles.toml` gives it, and
JetBrains Mono. The videos highlight code the same way, from the same two tables and the VS Code
grammar. Regenerate after changing any of them.

`assets/motion` holds Motion Canvas projects, one per video (`src/<project>.ts`, listed in
`vite.config.ts`, its scenes in `src/scenes/`): `pnpm install`, then `pnpm start` opens the editor,
where a project renders (its `scheme` variable names a scheme of `palette.toml`). The scenes draw
from the repository's sources rather than copies: `src/brand/` reads `palette.toml`, the logo's
SVGs (`construction.svg` by the ids of its groups: `grid`, `guides`, `circles`, `strokes`,
`joints`, `centers`) and the code tables. `Wordmark` and `Mark` (the v alone: the echo behind a
card, a bullet) are the logo as components; `beats.ts` holds when the stings' moments happen, which
`pnpm sound` places the sound mark by. Not to be confused with `assets/logo/motion/`, the CSS
animations.

| project | what it shows |
|---|---|
| `sting` | the logo built on its construction grid: traced, swelled to weight, the word landing, the v wagging on its tip |
| `sting-mascot` | the sting, then the word making room and the mascot dropping in beside it (the variable `mascot`) |
| `sting-short` | the sting in two seconds, at weight, with the mascot: what opens a clip |
| `mascot` | the mascot dropping in, looking around, going through each mood, then its moods lined up |
| `clip`, `clip-square`, `clip-tall` | the mockup episode (`src/episodes/tour`) as a clip, 1920 by 1080, 1080 square, 1080 by 1920 |
| `talk` | the mockup talk: the same scenes as slides, for the editor's presentation mode |
| `lower-third` | a speaker's name and role over footage, on no background |
| `release` | a release of `cards/release/releases.toml`, named by the variable `version` |

The clip kit (`src/clip/`, scenes in `src/scenes/clip/`): an `Episode` is a list of typed
segments (`title`, `chapter`, `points`, `code`, `diff`, `terminal`, `split`, `callout`, `stats`,
`image`, `end`); `clip(episode)` and `talk(episode)` in `project.ts` make a project of it, each
segment played by the scene of its kind, copied under a name of its own. Every length is a share
of the frame's shorter side, so one episode renders at every size. In a clip each segment fades
into the next with the echo still, its caption and a progress bar under it; in a talk each held
moment (`beat`) is a slide. `pnpm record <episode>` captures what an episode shows from the
repository, as `record.toml` beside it asks: its session, each command run with
`vun --format styled` (`VUN` names the vun to run), and changes, a file before and after a change
of the history (`jj`). The terminal scenes draw those lines in the styles vun printed them in
(`brand/terminal.ts`).

The mascot is declared once, in `src/mascot/`: `shape.ts` its geometry (a box with arc corners,
outlined so its corners round; eyes and mouth as curves described by numbers,
so faces blend), `moods.ts` a face and a pose per mood, `Mascot.tsx` the component the scenes move
(`feel`, `blink`, `glance`, `hop`, `shake`, `breathe`). `pnpm mascot` writes `assets/mascot/`
from them (and `scripts/motions.mts`, its CSS animations), clearing it first; never edit it by
hand. The cards draw the mascot from those stills through `assets/cards/mascot.typ`, which reads
the moods from the `mascot.toml` written beside them: after changing the mascot, run
`pnpm mascot`, then `cargo xtask typeset`. A card's versions with the mascot are variants under
its `mascot/` directory, beside the ones without. `tools/body.html`, opened by `pnpm body` (it needs the
dev server, which compiles the modules it imports), designs the body and face placement over the grid with every mood
previewed, and prints the `DESIGN` constant of `shape.ts` to paste over it.
`pnpm sound` synthesizes the sound mark into `assets/sound`: `mark.wav` (the word landing),
`pop.wav` (the mascot landing and cheering), and a track per sting with each sound at its moment,
which the sting projects play and the ffmpeg exporter muxes.

Emoji and stickers: `assets/cards/figures.typ` draws the figures both kits share, tight to their
extent, and cut round at a border for stickers; the mascot's corner radii come from the `corners`
key `pnpm mascot` writes into `mascot.toml`. `cards/emoji` makes square transparent emoji of every
figure in every scheme, at 128 pixels for chat and a 512 master; `cards/stickers` one die-cut PNG
per figure and scheme, the border in the scheme's background, and `sheet.typ` an A4 sheet of them
as vector PDF for printing.

Diagrams: `assets/diagrams/diagram.typ` draws boxes, arrows, stages in a row, ranks of peers and
code spans, themed by a scheme; each diagram is a module there (`pipeline`, `layers`, `origins`),
compiled as cards per scheme by `cards/diagrams`. The whitepaper can import them from
`/assets/diagrams/`. `layers.toml` is written from `RANKS` of `xtask/src/layers.rs` by
`cargo xtask layers`, and a test checks it is current.

Releases: `assets/cards/release/releases.toml` lists the releases, newest first, three to five
highlights each; `cards/release` draws a card per release, scheme and format (the formats of
`cards/formats.toml`, shared with the social cards), and the `release` project animates one.

Stream: `assets/stream` holds OBS browser-source overlays, 1920 by 1080: `starting`, `brb` and
`ending` fill the frame, `lower`, `ticker` and `webcam` are transparent. Each takes `scheme` and
its texts as URL parameters, rendered as text only. `pnpm stream` writes `generated/` from
`palette.toml`, the mascot and `assets/logo/motion`; never edit it by hand. `pnpm obs [scheme]`
writes `obs/vun.json`, a scene collection to import in OBS (Scene Collection, Import): Starting,
Live (webcam frame, ticker, lower third; add the camera under the frame), Be right back and
Ending, each overlay a browser source by its absolute `file:` URL, so it is written per checkout
and ignored.
