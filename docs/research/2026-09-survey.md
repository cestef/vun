## 1. Compile-time execution and metaprogramming

| System | Mechanism | Lesson for Vun |
|--------|-----------|------------------|
| Zig 0.16 | Sema interprets ZIR; type-returning functions; `@Type` replaced by `@Struct`, `@Enum`, ... | one language works; reified types cannot have methods, so names cannot be computed; slow (see below) |
| Jai | `#run` on a bytecode VM with full I/O; `#insert` of `Code` or strings; `#expand`; build metaprogram intercepts compiler messages | maximal power; the canonical examples still build code with string builders; I/O defeats caching |
| Scala 3 | typed quotes `'{ }` and splices `${ }`, `Expr[T]` | typed, hygienic output with real spans; macros must be compiled before use |
| MetaOCaml, Terra | `.< >.` / `.~`; Terra stages a low-level language from Lua | typed staging works; a second meta-language is a cost |
| Rust | `macro_rules` (mixed hygiene); proc macros as untyped token functions in host dylibs | proc-macro output size dominated check time in Bevy (27k generated vs 16k written lines, 16% of `cargo check`); facet shows reflection data can replace per-format derives |
| C++26 | P2996 reflection `^^T`, splicers `[: :]`, `define_aggregate`; token injection (P3294) deferred | declarations as data; untyped token injection chosen over typed fragments because fragments are hard to check out of context |
| Nim | `NimNode` ASTs, `quote do`, VM, `staticExec` | hygiene pragmas proliferate; VM slow |
| Lean 4, Racket | syntax objects with scope sets | reference hygiene, but built for user-extensible syntax, a Vun non-goal |
| Julia, Mojo | `@generated`; Mojo parameters and `comptime` | parametric only; no declaration generation |

Cross-cutting:
- In a compile-time-first language, a function body with compile-time parameters is already a typed
  quote. What is missing is computed names and computed declaration sets.
- Declarations as `(name, value, attributes)` data is the common core (Zig, C++26, facet).
- Hygiene by construction (binders referenced by handle) avoids scope-set machinery.
- Every generated item should keep an origin chain (Zig's reference traces are the best practice).
- Observation cycles (a generator reflecting on what it generates) need a freeze rule.

Performance:
- Zig #4055 (open): a 100M-iteration compile-time loop took 189 s against 6 s in CPython, using
  14 GiB. Zig #20163: a loop over 333K elements took 56 minutes.
- Clang's bytecode constant interpreter vs its AST walker: 36.5 s to 14.8 s on a 9 MB checksum;
  27.8 s to 4.2 s on 10k allocations (Red Hat, 2025-10-15).
- Sandboxed, deterministic evaluation makes memoization and persistent caching sound; designs with
  I/O at compile time lose that.

## 2. Ecosystem and tooling

- **Cargo**: feature unification is the chronic pain (RFC 3692 still unstable); `build.rs` and proc
  macros run unsandboxed (sandboxing still at project-goal stage); cargo-semver-checks grew from 120
  to 242 lints in 2025, and integration into `cargo publish` is a 2026 goal; build-std unstable.
- **Zig**: `build.zig` plus `build.zig.zon` (literal Zig subset: name, version, fingerprint,
  dependencies as `{url, hash}` or path, lazy, paths); hash is identity; no lockfile, no resolution;
  0.16 moved packages into `zig-pkg/` and added `--fork`. Weaknesses: one URL per dependency;
  dependencies' build scripts run in one non-hermetic process; ZON needs its own parser.
- **Go**: `go.mod`, `go.sum` (sorted, merge-friendly); minimal version selection; major versions as
  new import paths; module proxy and checksum database; `toolchain` directive with automatic
  download; built-in fuzzing since 1.18; `go fix` rebuilt on the analysis framework in 1.26 with
  `//go:fix inline`.
- **uv**: fast through a global cache with linking, parallel fetches and PubGrub; universal lockfile.
- **Roc**: URL packages with content hashes; apps name their platform explicitly.
- **Elm**: API-computed semver, enforced at publish; behavior changes are not caught.
- **Odin**: no package manager by design ("Package Managers are Evil", 2025-09-08).
- **Hare** (local): directory is a module; file-name tags select platform code; HAREPATH; no manifest.
- **Bazel 9** (January 2026) removed WORKSPACE; content-addressed action caches.
- **KDL 2.0** finalized 2024-12-21.
- **Embedded**: probe-rs (flash, debug, RTT, defmt decoding) as a library and CLI; defmt interns
  strings in a non-loaded ELF section and sends only indices and packed arguments, with log levels
  as linker subsections; esp-hal 1.0 released 2025-10-30; Embassy uses chiptool-style register
  values; Zephyr integrates Rust as a west module built through CMake; ESP-IDF's component manager
  writes `dependencies.lock` and `managed_components/`; PlatformIO's lag on Arduino-ESP32 3.x led
  to the pioarduino fork.

## 3. Performance

Compile time:
- Zig data-oriented design: about 20% faster tokenize and AST, about 40% faster IR generation.
  Self-hosted x86_64 debug backend: hello world 918 ms to 275 ms, compiler build 75 s to 20 s.
  Parallel codegen (PR #24124) with a single linker thread. Serial Sema is now the bottleneck (Bun:
  19 s in Sema, issue #22236). Incremental rebuilds around 30 ms with the self-hosted ELF linker.
- rustc parallel front end: nightly since 2023, stabilization a 2026 goal.
- Cranelift for rustc: about 20% less codegen time, about 5% less total; code about 14% slower.
- TPDE (arXiv 2505.22610): 8x to 24x faster than LLVM -O0, runtime within about 9%; backend is only
  15% of clang -O0 time, so end-to-end gain is 17%.
- QBE (local `doc/llvm.txt`): "70% of the performance in 10% of the code"; no SIMD, no 32-bit.
- Carbon: postorder parse-tree arrays; [unverified] 10M lines/s lex and 1M lines/s check targets.
- Salsa port grew rust-analyzer's memory about 4x (issue #19402) until an LRU was added.
- wild vs mold (2026-09-18): wild 1.2x to 1.3x slower for debug links, about equal for release;
  wild's goal is incremental linking.
- Go shares generic code by GC shape; rustc removed polymorphization in 2024 (PR #133883).

Runtime:
- Rust's checks: 1.96x slower than C with all checks; bounds checks about 53% of the overhead
  (ASE 2022).
- Zig result location semantics: accepted as a "failed experiment" (codeberg #32009, April 2026):
  swap bug (#12064), leftovers on early exit, spec complexity. Parameter reference optimization
  caused observable aliasing (#5973).
- Rust async frames: parameters stored twice (#108906); nested forwarding doubles size per layer,
  16 MiB at depth 10 (#163195).
- Tail calls: Rust `become` on nightly; CPython's tail-call interpreter gain is about 2% to 5% once
  an LLVM 19 regression is accounted for (LWN 1033373).
- Hints: Zig replaced `@setCold` with `@branchHint`; Rust stabilized only `cold_path`.
- SIMD: Zig `@Vector` works; Rust `std::simd` still unstable (masks, swizzles).

## 4. Entry points, effects, keywords

- **Entry mechanisms** reduce to: a library-declared symbol the startup code calls, a user export
  defining it, and a linker entry symbol. Go (`//go:linkname main_main main.main`), Hare
  (`@symbol("main")` plus `export fn start_ha`, local source), cortex-m-rt (`#[entry]` renames to
  `main`; weak `PROVIDE` defaults) all fit. The magic elsewhere is a known name (Rust lang items,
  `#[panic_handler]`) or root inspection (Zig `start.zig` with `@hasDecl(root, ...)`; 0.16 "Juicy
  Main" passes `std.process.Init`). Roc and WASI avoid both: the host states a typed requirement
  (`requires { main! : ... }`; `export run: func() -> result`).
- **Rust EII** (externally implementable items, issue #125418) turns lang items into typed
  declared-upstream, defined-downstream items: the precedent for typed link symbols.
- **Effect handlers**: Effekt's capability passing (ICFP 2020) and lexically scoped handlers match
  scoped borrows structurally; Lexa (OOPSLA 2024, 2025) is zero-overhead when nothing is raised but
  uses stack switching; Koka's evidence passing makes tail-resumptive operations direct calls.
  Without a heap and with static frames, the implementable classes are capability values, `Result`,
  and one-shot coroutines, which Vun already has.
- **Keyword counts**: Lua 22, Go 25, V about 52 (local `vlib/v/token/token.v`), Hare about 61 with
  type names (local `lex.c`). Hylo's `let`/`inout`/`sink`/`set` correspond to `&`, `&mut`, by value
  and `&out`; Vun's `&take` has no Hylo equivalent.

## 5. Diagnostics and lints

- **Renderers**: annotate-snippets (rust-lang) became rustc's only emitter via PR #150032 (merged
  2025-12-17, MCP #947); its model has groups, annotations (primary, context, visible) and patches
  rendered as diffs. ariadne 0.6.0 (2025-10-28) moved to Codeberg, GitHub archived, 0.7 unreleased;
  no fix model. codespan-reporting 0.13 (Gleam, Typst). miette 7.6 (application errors).
- **rustc**: `Diag` with multi-spans, subdiagnostics, suggestions with `Applicability`
  (`MachineApplicable`, `MaybeIncorrect`, `HasPlaceholders`, `Unspecified`); `ErrorGuaranteed` to
  suppress cascades; JSON output; `--explain`; Fluent translation files removed by MCP #959
  (January 2026) for ergonomic reasons.
- **Others**: Elm and Roc (conversational messages); Zig (reference traces, `@compileError`, no
  warnings); TypeScript (stable codes, message chains); Swift (fix-its, diagnostic groups SE-0443,
  source-level control SE-0522); Clang (fix-its, SARIF); Go (`analysis.Analyzer` with facts and
  suggested fixes).
- **Lint frameworks**: Clippy groups and levels (`allow`, `warn`, `deny`, `forbid`, `expect`); dylint
  tied to nightly; Ruff fix safety (safe, unsafe, display-only) with per-rule reclassification;
  Biome GritQL plugins; Oxlint JS plugins (alpha 2026-03-11).
- **Machine interfaces**: LSP (`code`, `codeDescription`, `relatedInformation`, `tags`, `data`, quick
  fixes), SARIF 2.1.0, rustc UI tests with `--bless` and `run-rustfix`.

## 6. Testing, fuzzing, benchmarking

- Go: built-in coverage-guided fuzzing (corpus in `testdata/fuzz/`); `b.Loop` (1.24);
  `testing/synctest` generally available in 1.25 (isolated bubble, fake clock).
- Zig 0.16: fuzz input became a typed choice stream (`std.testing.Smith`); multiprocess fuzzing;
  `--test-timeout`. The fuzzer broke in two releases in a row.
- Rust: cargo-fuzz, afl.rs, `arbitrary`; proptest shrinks value trees; bolero runs one harness under
  several fuzzers and Kani; insta snapshots; cargo-mutants; source-based coverage.
- divan (local source) registers benchmarks through `.init_array` global constructors, the kind of
  hidden mechanism Vun excludes.
- gungraun (formerly iai-callgrind) and CodSpeed's simulation mode: instruction counts as
  deterministic CI gates.
- probe-rs embedded-test: flash once, reset between tests, semihosting exit, libtest protocol.
- Deterministic simulation: TigerBeetle VOPR ("A Tale of Four Fuzzers", 2025-11-28), FoundationDB,
  Antithesis.
