# Identity

Adopted so far (candidates live in `explore/`):

- **Color.** Pastel. Peach (the crab) is the brand color, seafoam (the shell) the second; warm
  stone carries surfaces and text. Rose marks errors, butter warnings, sea notes, sky help.
  Diagnostics renderers and syntax themes take their colors from a theme's `diag` and `code`
  roles.
- **Type.** Bricolage Grotesque for display, IBM Plex Sans for text, IBM Plex Mono for code.
- **Name.** Always lowercase `vun`. In the wordmark the `v` takes the accent; the `n` is the `u`
  turned over.
- **Logo.** `logo/mark` (the mascot, square), `logo/wordmark`, `logo/lockup` (both).
- **Voice.** Plain, exact, unhurried; nothing behind the scenes.

`sample.toml` is the code specimen used on identity pages.
