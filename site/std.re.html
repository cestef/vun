std.re

Tools for reading binaries, which a program of its own builds on: byte patterns with wildcards (Pattern), as a reverse engineer writes them, and a hex dump of bytes (hexdump).

Namespaces

  • std.re.dump

    The hex dump std.re.hexdump writes: the bytes of a run, a line of 16 at a time.

  • std.re.pattern

    Byte patterns as a reverse engineer writes them: hexadecimal bytes separated by spaces, with ? or ?? for a byte that may be any, as in 48 8B ?? 05.

  • std.re.tests

    Tests of std.re: patterns with wildcards found in bytes, and hex dumps.

function Pattern

Pattern: ($n: Int(1..)) -> type = std.re.pattern.Pattern

A pattern of up to n bytes, each a byte to match or any byte.

function hexdump

hexdump := ($W: std.fmt.Writer, w: &mut W, bytes: &[u8], base: u64) -> Result((), W.Error)

Writes bytes to w as a hex dump, a line of 16 of them at a time, each line with the address of its first byte, counted from base, the bytes in hexadecimal and their ASCII.
