std.collections.map

HashMap(K, V): values by key, in open addressing over one buffer an allocator gave: the states of the slots, then the keys, then the values. Keys are compared by Eq and hashed by std.hash.Hash, both derived for the types made of ones that have them. It is linear, as Vec is, and holds no allocator: the one passed to a call that grows it is the one deinit must be given. Keys and values are not dropped: ones owning memory are taken out first.

value vacant

vacant: u8 = 0

The state of a slot holding nothing yet: no key was ever put in it.

value live

live: u8 = 1

The state of a slot holding a key and its value.

value deleted

deleted: u8 = 2

The state of a slot whose key was removed: a search goes on past it.

value smallest

smallest: usize = 8

The fewest slots a map is made with.
