std.simd

Portable vector code (spec 04, section 3): the methods and operators of every lang.simd.Vector(n, T), lane by lane over the array of its lanes. An operator's lanes have the type the same operator gives their lanes (u8 lanes sum to Int(0..=510) lanes).

function lane_count

lane_count := ($T: type) -> usize

How many lanes of T the target's vector registers hold (lang.target.Spec.vector_bits), one where it has none or T is wider than they are.

function Scalable

Scalable := ($T: type) -> type

The vector of the target's width: code over it takes its lane count from the target, and covers a sequence of any length through cover, load_partial and store_partial.

The order a reduction combines lanes in: each run of width lanes as a balanced tree of pairs, then the runs' results in lane order. A width of 1 combines every lane in order.
