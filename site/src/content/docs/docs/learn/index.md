Each lesson is a short page and a program you can change and run in place. The program starts broken or incomplete, and the lesson says what to make it do. The compiler checks every run, so you see which of the lesson's conditions you have met and which you have not.

- A lesson is done when a run ends as the lesson asks: the output it names, a normal exit, or the compiler refusing with the right diagnostic.
- **Hint** on a lesson climbs a ladder, one step at a time: a hint, the lines that differ from a working solution, the change to make, and the solution itself.
- Your code and your progress stay in this browser.

The compiler runs in your browser as WebAssembly, so nothing is sent anywhere. Start with [hello](../learn/hello/).
