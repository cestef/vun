lang.arch.thumb.branch

Branches, calls, returns and traps (Armv7-M, branches and exception-generating instructions).

value b_always

b_always := _t.Instruction{ .forms = &[ .{ .base = 0xf0009000, .args = &[.{ .kind = .target(.jump), .access = .read }], .flow = .jump }, .{ .base = 0xe000, .args = &[.{ .kind = .target(.narrow), .access = .read }], .flow = .jump }, ] }

A branch; its 32-bit form first, as a label's distance is not known when it is chosen.

value bcond

bcond := _t.Instruction{ .forms = &[ .{ .base = 0xf0008000, .args = &[ .{ .kind = .cond, .at = 22, .access = .read }, .{ .kind = .target(.cond), .access = .read } ], .flags = .some(.read), }, .{ .base = 0xd000, .args = &[ .{ .kind = .cond, .at = 8, .access = .read }, .{ .kind = .target(.narrow_cond), .access = .read } ], .flags = .some(.read), }, ], }

A branch if the condition holds, its 32-bit form first.

value b

b := _t.Mnemonic{ .instructions = &[.b_always, .bcond] }

A branch, given a condition a conditional one.

value bl

bl := _t.Instruction{ .forms = &[ .{ .base = 0xf000d000, .args = &[.{ .kind = .target(.call), .access = .read }], .writes = _link }, ] }

A call: the return address, its lowest bit set for Thumb, into lr.

value blx

blx := _t.Instruction{ .forms = &[.{ .base = 0x4780, .args = &[_any], .writes = _link }] }

A call of the address in a register, whose lowest bit must be set.

value bx

bx := _t.Instruction{ .forms = &[.{ .base = 0x4700, .args = &[_any], .flow = .ends }] }

A jump to the address in a register: a return, from lr.

value cbz

cbz := _t.Instruction{ .forms = &[ .{ .base = 0xb100, .args = &[_lo, .{ .kind = .target(.compare), .access = .read }] }, ] }

A branch forward if a register is zero, or is not.

value cbnz

cbnz := _t.Instruction{ .forms = &[ .{ .base = 0xb900, .args = &[_lo, .{ .kind = .target(.compare), .access = .read }] }, ] }

value udf

udf := _t.Instruction{ .forms = &[.{ .base = 0xde00, .args = &[_u8], .flow = .ends }] }

A permanently undefined instruction: a trap.

value svc

svc := _t.Instruction{ .forms = &[.{ .base = 0xdf00, .args = &[_u8], .reads = &[.r7], .writes = &[.r0] }] }

A call of the system: Linux takes its number in r7 and returns its result in r0.

value bkpt

bkpt := _t.Instruction{ .forms = &[ .{ .base = 0xbe00, .args = &[], .flow = .ends }, .{ .base = 0xbe00, .args = &[_u8], .flow = .ends }, ] }

A trap into the debugger, or a fault without one.

value it

it := _t.Instruction{ .forms = &[ .{ .base = 0xbf00, .args = &[.{ .kind = .then(.none), .access = .read }], .flags = .some(.read) }, ] }

Makes the next instruction conditional (it), or the next two, the second on the same condition (itt) or on its opposite (ite): their encodings are the unconditional ones.

value itt

itt := _t.Instruction{ .forms = &[ .{ .base = 0xbf00, .args = &[.{ .kind = .then(.t), .access = .read }], .flags = .some(.read) }, ] }

value ite

ite := _t.Instruction{ .forms = &[ .{ .base = 0xbf00, .args = &[.{ .kind = .then(.e), .access = .read }], .flags = .some(.read) }, ] }
