std.testing.options

How a run of the tests' program is asked for: the options its arguments give (spec 11, section 3).

value seed_option

seed_option := "--seed"

The option drawing every property's cases from the seed that follows it.

value cases_option

cases_option := "--cases"

The option running as many cases of each property as the number that follows it.

value bench_option

bench_option := "--bench"

The option running the benchmarks alone, measured.

value fuzz_option

fuzz_option := "--fuzz"

The option fuzzing the properties alone, over as many cases as --cases asks.

struct Options

Options := struct { ... }

How a run is asked for, by the program's arguments: --seed n draws every property's cases from n rather than from its name, --cases n runs n cases of each, --bench runs the benchmarks alone, measured, --fuzz fuzzes the properties alone, and the other arguments name the tests to run, every one if none does.

of := (args: std.os.Args) -> ?Options

The options args ask for; .none when an option has no number after it.

function option

option := (arg: &[u8]) -> bool

Whether arg is an option, which the number after it goes with.

function runs

runs := (self: &Options, kind: std.testing.Kind) -> bool

Whether a test of kind runs: the benchmarks alone when measured, the properties alone when fuzzed, else every test.

function chosen

chosen := (self: &Options, name: &[u8]) -> bool

Whether the test name is run: every test when the arguments name none, else those they name.
