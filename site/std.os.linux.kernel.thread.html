std.os.linux.kernel.thread

Threads of a program calling the kernel itself. Each runs on a stack of its own, mapped for it with its lowest pages left inaccessible so that running past its end faults, and starts from clone, sharing the process's memory, files and signal handlers. The kernel clears the thread's id in its record when the thread ends and wakes whoever waits on that word (CLONE_CHILD_CLEARTID): joining waits for it, then unmaps the stack.

value stack_bytes

stack_bytes := 8 << 20

The bytes of a thread's stack, as many as a process's main thread has by default.

value guard_bytes

guard_bytes := 64 << 10

The bytes left inaccessible below a stack: whole pages whatever the page size.

value mapped_bytes

mapped_bytes := stack_bytes + guard_bytes

The bytes mapped for a thread.

value sharing

sharing: usize = 0x35_0f00

What clone shares with the new thread, and where it reports its id: CLONE_VM, CLONE_FS, CLONE_FILES, CLONE_SIGHAND, CLONE_THREAD, CLONE_SYSVSEM, CLONE_PARENT_SETTID and CLONE_CHILD_CLEARTID. The thread sets its own pointer, as the main thread does.

value wait

wait: usize = 0

op for futex: wait while the word holds a value (FUTEX_WAIT).

value inaccessible

inaccessible: usize = 0

protection for mprotect of memory neither read nor written.

value entered

entered: usize = if lang.target.current.arch == .x86_64 { lang.meta.size(usize) } else { 0 }

Where the words a new thread starts from are above its stack pointer: past a return address where the architecture's call pushes one. They are the address of the thread's record, then the function it begins at (Begin).

value frame

frame: usize = ((entered + 2 * lang.meta.size(usize) + std.os.thread.align - 1) / std.os.thread.align * std.os.thread.align).wrap(usize)

The bytes a new thread's stack holds from its pointer up when it starts, the pointer aligned.

function clone

clone := (request: Clone) -> isize

Makes the clone system call of request, returning what it returns to the calling thread. The new thread starts on request.stack, branching to the function the stack holds with the record's address it holds, through no register the system call does not read: a block the checks of assembly watch keeps two free. On arm64 the branch goes through x16, the register a branch may land on a function's entry through where branch targets are enforced (BTI), as a C compiler building with branch protection makes them. On Thumb the number goes in r7, the frame pointer, which the calling thread keeps on the stack meanwhile; the new thread starts on a stack of its own and never gives it back.

field spawn

#[link.export(std.os.symbols.spawn)]
spawn := unsafe (start: std.os.thread.Start, context: *u8, bytes: usize) -> Result(usize, std.os.Error) { mapped := std.os.linux.kernel.outcome(std.os.linux.kernel.mapping(mapped_bytes))?; placed := std.os.thread.Placed.of(Record, (mapped + mapped_bytes).wrap(usize), bytes); image := unsafe std.os.linux.kernel.tls.image; block := std.os.thread.down((placed.context - image.span()).wrap(usize)); pointer := image.place(block); stack := (block - frame).wrap(usize); unsafe { lang.mem.pointer_at(Record, placed.record).write(Record{ .tid = 0, .mapped = mapped, .start = start, .context = placed.context, .ended = placed.ended, .pointer = pointer, }); placed.begin(); lang.mem.copy(u8, lang.mem.pointer_at(u8, placed.context), context, bytes); lang.mem.fill(u8, lang.mem.pointer_at(u8, stack), 0, frame); lang.mem.pointer_at(usize, (stack + entered).wrap(usize)).write(placed.record); lang.mem.pointer_at(Begin, (stack + entered + lang.meta.size(usize)).wrap(usize)).write(begin); } request := Clone{ .number = std.os.linux.kernel.numbers.clone, .flags = sharing, .stack = stack, .parent = placed.record, .child = placed.record, }; guarded := std.os.linux.kernel.request( std.os.linux.kernel.numbers.mprotect, [mapped, guard_bytes, inaccessible, 0, 0, 0] ); started := if guarded < 0 { guarded } else { clone(request) }; match std.os.linux.kernel.outcome(started) { .ok(_) => .ok(placed.record), .err(e) => { std.os.linux.kernel.unmap(mapped, mapped_bytes); .err(e) }, } }

field join

#[link.export(std.os.symbols.join)]
join := unsafe (thread: usize, context: *u8, bytes: usize) -> std.os.thread.Ended { tid := unsafe lang.mem.pointer_at(u32, thread); mut running := unsafe lang.mem.atomic_load(u32, tid, .acquire); for running != 0 { std.os.linux.kernel.request( std.os.linux.kernel.numbers.futex, [thread, wait, running.to(usize), 0, 0, 0] ); running = unsafe lang.mem.atomic_load(u32, tid, .acquire); } held := unsafe lang.mem.pointer_at(Record, thread).read(); unsafe lang.mem.copy(u8, context, lang.mem.pointer_at(u8, held.context), bytes); ended := unsafe lang.mem.pointer_at(std.os.thread.Ended, held.ended).read(); std.os.linux.kernel.unmap(held.mapped, mapped_bytes); ended }
