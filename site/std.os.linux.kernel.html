std.os.linux.kernel

A runtime calling the kernel itself, for static programs without a C library (spec 08, section 2). _start finds the arguments where the kernel puts them, on the stack it starts the process with, and every request is a system call. The C compiler may call the four functions of C's string.h a freestanding program must provide, so the runtime exports them.

Namespaces

  • std.os.linux.kernel.calls

    The numbers of the system calls the kernel runtime makes, which each architecture assigns its own.

  • std.os.linux.kernel.division

    The hooks the Arm EABI's division functions call for a divisor of zero (__aeabi_idiv0, __aeabi_ldiv0), which the platform may supply. A C compiler for 32-bit Arm divides through functions of its own library, and GCC's Linux one answers a zero divisor through the C library's raise; a program without one supplies the hooks itself. Vun checks its divisors, so reaching a hook is a trap.

  • std.os.linux.kernel.pages

    std.os.pages's exports for the kernel runtime: mprotect by raw system call, and a query of /proc/self/maps, which std.os.linux.pages reads needing no system call of its own.

  • std.os.linux.kernel.thread

    Threads of a program calling the kernel itself. Each runs on a stack of its own, mapped for it with its lowest pages left inaccessible so that running past its end faults, and starts from clone, sharing the process's memory, files and signal handlers. The kernel clears the thread's id in its record when the thread ends and wakes whoever waits on that word (CLONE_CHILD_CLEARTID): joining waits for it, then unmaps the stack.

  • std.os.linux.kernel.tls

    Storage per thread of a program calling the kernel itself (spec 07, section 2). The program's TLS segment, which the auxiliary vector the kernel starts it with leads to, is the image each thread's block starts as; a block is laid out as the architecture's ABI says, and the thread pointer, which code reaches the block from, is set to it for each thread.

struct Call

#[layout.c]
Call := struct { ... }

A system call: its number and six arguments, which the architecture's instruction takes in registers. A block loads them from here, binding the one register the address comes in and the result goes out in, rather than eight. On Thumb the number goes in r7, the frame pointer, which the block keeps on the stack meanwhile.
