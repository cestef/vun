std.trace

Backtraces (spec 07, section 3): where a trap was written and the calls that led to it, read from the program's table (lang.trace) and the chain of frames every function keeps, a record of its caller's frame and of where it returns to at its frame pointer. A runtime's handler of traps writes one before ending the program.

The program's table, which the compiler defines.

depth := 64

The most frames a backtrace names: past them, the chain is taken to be broken.

function calls

calls := (frames: &mut [depth]usize) -> usize

Where each call on the chain returns to, from the one this function returns to on: at most depth of them, the count in frames. The chain starts at this function's own frame, read here so that it is live whether or not the function is inlined; none is read where frames are not memory a program reads (WebAssembly).

function report

report := ($H: type, handler: H, site: u32, why: Why)

Writes to the standard error why the program ends and what its table says of the trap at site: where it is written and what it says, then, where the table describes them, the calls that led to it, past the last call returning into handler, of type H, the function handling the trap, and so past this function's own frames wherever it is inlined. A program built without its table writes nothing.

Writes why the program ends, where the trap site site is written, and what it says.

function inlined

inlined := (w: &mut std.os.Stream, index: u32)

Writes each function the code at the origin of index index is inlined into, innermost first, up to the one it is not: that one's frame is on the chain.

called := (w: &mut std.os.Stream, handler: usize)

Writes the function of each call on the chain past the last returning into the function at handler, up to the first function foreign code calls; then, in a thread, those of the calls that spawned it.

type Spawn

What a thread keeps of the calls that spawned it, which its backtrace names past its own: their chain where the table describes calls, else nothing.
