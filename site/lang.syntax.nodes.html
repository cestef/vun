Kinds of syntax tree nodes (spec 13, section 2), each with its production: the tokens and children it spells, in source order.

A term of a production is a token spelled "text" (a punctuation or keyword token, or a name spelled so where the grammar makes it a word), .token(...) for a token of one of the kinds listed, each .kind or a path to a list of the token kind or a table of tokens, .word(path) for a name or keyword spelled as a variant of the kind, or the list of one, the path names, a child .field, .optional(...) and .many(...) for terms written once or not and any number of times, .separated(term, "sep") for any number of term with sep between them and after the last if written, .choice(a, ...) for one of the terms, .of(.field, table) for a child in field of a kind the table lists, .starting(.field, tokens) for one starting with a token a table of tokens lists, and .seq(...) for terms in sequence. Tables are named by paths, as grammar.infix. Where a table names kinds (.of, holds), a transparent node stands for the node it ends with, and its last child stands where it stands, taking what that position takes.

A node is anchored at the first token of its production; its other tokens are punct leaves, its children fill its fields. A field's count follows from where it stands: many in many or separated, else optional in optional or choice, else one. A field named after a kind holds a node of that kind, any other field any node. A leaf spells one token and holds nothing; punct holds the token its parent's production names, skipped a token no production reads, and neither stands in a field. An error stands for a child absent, or not one its position takes, which it holds, and fits any field; an error, a skipped token, and a node holding one or anchored at an absent token, are recovery's shapes: they fit their kind's fields, not its production.

fields := [.field]

value unterminated

unterminated := [ .module_doc, .block, .\if, .\for, .\match, .labeled, .staged, .implementation, .extension, ]

Kinds of entries of a list needing no ; after them: module docs, blocks and the forms ending with one.

value staged_forms

staged_forms := [.\for, .\if]

What a list's entry made at compile time is: a loop or a choice.

value labeled_bodies

labeled_bodies := [.\for, .block]

What a label names: a loop or a block.

value member_names

member_names := [.name, .int, .paren]

What names a member after .: a name, an index, or $ and the value naming it (.$(f.name)).
