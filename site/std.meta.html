std.meta

Reflection and code generation helpers over lang.meta (spec 03), including collect(package, attr), which gathers declarations carrying an attribute (decision 42).

struct Quoted

Quoted := interface(($Self: type) -> type { struct { ... } })

What a code value tells of itself (spec 03, section 4). A code value is passed by borrow: a parameter of type Code(T) itself would receive its argument as code.

function source

source: (c: &Self) -> &[u8] = _

The source text of the code, as written.

function span

span: (c: &Self) -> lang.meta.Origin = _

Where the code is written.

function within

within: (c: &Self, $bytes: lang.Range) -> lang.meta.Origin = _

Where the bytes bytes of the string literal the code writes are written, inside it.

function variant_name

variant_name := ($T: type, v: &T) -> &[u8]

The name of the variant of its type T that v is, as declared.

function attrs

attrs := ($D: type, $d: D) -> &[lang.meta.Any]

The values of the attributes written on d, a field or a variant as reflection gives it (lang.meta.Field, lang.meta.Variant): plain data, each with its type, known at compile time only.

function attr

attr := ($D: type, $d: D, $A: type) -> ?A

The first attribute written on d that is an A, as #[Rename{ .to = "key" }].

function has

has := ($D: type, $d: D, $A: type) -> bool

Whether an attribute written on d is A: the type itself, a marker such as #[test], or a value of it.

struct Collected

Collected := struct { ... }

A member collect finds: the namespace declaring it and its descriptor. Its value is c.ns.$(c.decl.name).

field ns

ns: lang.meta.Namespace

field decl

decl: lang.meta.Decl

function collect

collect := ($ns: lang.meta.Namespace, $A: type) -> &[Collected]

The members of ns and of the namespaces nested in it on which an attribute is A (has), in the order they are declared: what a test runner or a command table gathers (spec 03, section 6). Nothing is evaluated but their attributes, and only when it is called. It sees what std sees: the public members of another package.
