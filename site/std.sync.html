std.sync

Synchronized interior mutability; the only safe kind (spec 07, section 2). A critical section is global mutual exclusion: Shared(T) is reached only with the &Critical it lends, and Atomic(T) and Mutex(T) synchronize by themselves.

struct symbols

The runtime's critical section, typed link symbols it exports (spec 08, section 1): enter masks interrupts and, on multi-core targets, takes the global lock; leave undoes it.

struct Critical

Critical := struct { ... }

Holding the critical section. Only critical makes one, and it lends it for the call only, so nothing reached through it outlives the section.

function run

#[panic.never]
run := ($R: type, $F: lang.ops.Call((&temp Critical), R), f: F) -> R

Runs f in the critical section and returns its result, which cannot hold what f was lent.

value critical

critical := Critical.run

function Local

Local := ($T: type) -> type

A value each thread has its own of (spec 07, section 2): every top-level binding of a Local(T) has one storage per thread, which no other thread reaches, so no access needs a section. It is reached by value, as a Shared(T) is, through relaxed atomic accesses, which a handler of a signal or interrupt the thread runs between two of them cannot tear.

struct Mutex

Mutex := ($T: type) -> type { struct { ... } }

A value one holder at a time reaches, through the guard lock returns. Waiting spins on an atomic flag; the system capability is what a hosted runtime will park on.

function init

init := (value: T) -> Mutex(T)

function lock

lock := (self: &Mutex(T), sys: &mut std.os.System) -> Guard

Waits until no guard is held, then holds one.

field Guard

Guard := #[kind.linear] struct { _mutex: &Mutex(T), /// Waits until no guard is held, then holds one. acquire := (mutex: &Mutex(T)) -> Guard { for mutex._locked.compare_swap(false, true, .acquire) {} .{ ._mutex = mutex } }; get := (self: &mut Guard) -> &mut T { unsafe { &mut lang.mem.cell_pointer(T, &self._mutex._value).* } }; unlock := (self: Guard) { .{ ._mutex = mutex } := self; mutex._locked.store(false, .release); }; }

Holding the mutex: the value is reached through it until unlock, which must be called.
