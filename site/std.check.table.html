std.check.table

What allocators have handed out, for the checks of allocations (spec 13, section 8.7): the bytes handed out at each address, open-addressed by linear probing. A removal moves later entries of its run back rather than leaving a tombstone, so probes stay as short as the table is full.

value entries

entries := 1 << 22

The entries of the table, a power of two; one is always left empty, so every probe ends.

value words

words := 1 + 2 * entries

The words of the table: the entries in use, then two per entry, the address handed out (0 where the entry is empty) and its bytes.

function home

home := (address: usize) -> usize

Where the probe for address starts.

function next

next := (slot: usize) -> usize

The entry after slot, the first after the last.

function within

within := (hole: usize, slot: usize, end: usize) -> bool

Whether slot lies in the run from after hole to end, around the end of the table.
