std.os.memory

The functions of C's string.h a freestanding C program must provide, which a C compiler calls for copies and fills of its own: a runtime with no C library holds them. Copies and fills are written in assembly: a loop in Vun would be read back by the C compiler as a call of the function it is.

exports := struct { ... }

The exports, which a runtime holds: memory := std.os.memory.exports.

function move

#[link.export("memmove"), abi.c]

Copies from the last byte down where to overlaps the end of from, else up.

The sign of the first byte that differs, as unsigned bytes, 0 where none does.

function forward

forward := (to: usize, from: usize, bytes: usize)

Copies bytes from from to to, from the first byte up.

function backward

backward := (to: usize, from: usize, bytes: usize)

Copies bytes, at least one, from from to to, from the last byte down.
