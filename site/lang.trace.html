lang.trace

What the compiler tells a program of its own code, so that a trap reports where it was written and the calls that led to it (spec 07, section 3): the program's functions, its trap sites and the places in source they name. The compiler lays the table out as these declarations do and gives it the link symbol symbols.table, which a runtime declares to read it.

enum Detail

Detail := enum { ... }

How much of its code a program's table describes, and so what a trap reports.

variant off

off

No table: a trap reports nothing.

variant sites

sites

The trap sites: where a trap is written, and what it says.

variant calls

calls

The sites, and the functions of the calls that led to a trap.

value current

current: Detail = _

The detail the program is built with (std.build.Options.trace, --trace), known when compiling, as lang.check.current is.
