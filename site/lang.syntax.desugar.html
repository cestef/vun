lang.syntax.desugar

What syntax means (appendix B): the lang items operators, borrows and other forms desugar into, as data the compiler looks up, so no lang name is written in the compiler. Read with grammar.vun, whose token kinds these tables name. A table naming lang items by their paths is a tuple, since the items it names have types of their own.

enum Extent

Extent := enum { ... }

How long a borrow passed to a call is held (spec 05, section 4).

variant tied

tied

As long as the call's result: a scoped result is tied to it.

variant temp

temp

For the call only: the result is not tied to it, and the callee may not return it.

variant static

static

For the whole program: a borrow of a literal or of an immutable top-level binding, which is free, and is the only extent required where it is written (spec 05, section 4).

Borrow types by the words after & (appendix B): &T is lang.mem.Ref(T). Each mode is named by the transition it performs on the place it borrows (spec 05, section 2): the state it needs before, and the state the place has after; by the access it leaves others; and by how long a call holds it. A borrow serves where another of the same transition is expected when it leaves others no more access (&mut T where &T is), whatever its extent, but where &static is written.

enum Relation

Relation := enum { ... }

How a function carrying a marker is accepted where a function type is expected (spec 07, section 4).

variant duty

duty

A duty of the callers: accepted when the function has no duty the expected type lacks.

variant guarantee

guarantee

A promise to the callers: accepted when the function makes every promise expected.

variant bound

bound

A limit: accepted when the function's is at most the expected one, or none is expected.

variant identity

identity

A convention: accepted when both have the same ones.

value iteration

iteration := .{ .{ .function = lang.ops.Iterate.iter, .iterator = lang.ops.Iterate.Iter, .resume = lang.Coroutine.resume, .end = lang.Coroutine.end, .each = lang.Step.yielded, .done = lang.Step.done, }, }

What for p in e drives (appendix B): the witness of the interface of function for the type of e gives the iterator through it and names its coroutine interface iterator; each item is the payload of the variant each of what the interface's resume returns, and the variant done carries what the coroutine returns. A frame answers the interface's resume and end itself (spec 06, section 1).
