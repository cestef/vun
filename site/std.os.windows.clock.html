std.os.windows.clock

The system's clocks and sleep, in the units std.time keeps.

value unix_epoch

unix_epoch: u64 = 116_444_736_000_000_000

The 100-nanosecond intervals of the system's real clock between 1601-01-01, where it starts, and 1970-01-01, where std.time.Clock.real does.

value nanos_per_interval

nanos_per_interval := 100

value longest_sleep

longest_sleep: u64 = 0xFFFF_FFFE

Milliseconds in a sleep, at the most one less than INFINITE, which Sleep takes for ever.

function monotonic

monotonic := () -> Result(std.time.Instant, std.os.Error)

The monotonic clock: counts of the performance counter, in nanoseconds.

function unix_nanos

unix_nanos := (intervals: u64) -> u64

The nanoseconds since 1970 of the system time intervals, since 1601. A clock set before 1970 reads as the epoch, as one past what an Instant counts reads as its last.

function real

real := () -> Result(std.time.Instant, std.os.Error)

The real clock: the system's time of day, in nanoseconds since 1970.

function pause

pause := (span: std.time.Duration) -> Result((), std.os.Error)

Suspends the calling thread for at least span, in whole milliseconds.
