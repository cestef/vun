std.text.utf16

UTF-16, as Windows spells text: units of 16 bits, a code point past U+FFFF written as a pair of surrogates. Text in a program is UTF-8 (decision 43); these read and write the units a system call takes, and turn one into the other.

value high_first

high_first := 0xD800

The surrogates that start a pair (high) and end it (low), by their first and last units.

value high_last

high_last := 0xDBFF

value low_first

low_first := 0xDC00

value low_last

low_last := 0xDFFF

value pair_first

pair_first := 0x10000

The first code point written as a pair, and how many values each surrogate holds of it.

value pair_span

pair_span := 0x400

function decode

decode := (text: &[u16]) -> Option((u32, usize))

The code point text starts with and how many units it takes; none for an empty text, and for a surrogate with no partner: a low one first, or a high one not followed by a low one.

function from_utf8

from_utf8 := (text: &[u8], into: &mut [u16]) -> Option(usize)

The UTF-16 of the UTF-8 text, written to the front of into, and how many units that is; none where text is not UTF-8 or into is too short for it.
