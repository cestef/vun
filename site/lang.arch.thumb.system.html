lang.arch.thumb.system

The special registers, interrupt masks, waits and barriers (Armv7-M, system instructions).

value mrs

mrs := _t.Instruction{ .forms = &[ .{ .base = 0xf3ef8000, .args = &[_r_w, .{ .kind = .special(.is(.apsr)), .access = .read }] }, .{ .base = 0xf3ef8000, .args = &[_r_w, .{ .kind = .special(.any), .access = .read }], .requires = _microcontroller }, ] }

A special register read into a general one: the flags on every profile, the others on the microcontroller one's.

value mrc

mrc := _t.Instruction{ .forms = &[ .{ .base = 0xee100010, .args = &[ .{ .kind = .coprocessor, .at = 8, .access = .read }, .{ .kind = .imm(.unsigned(3)), .at = 21, .access = .read }, .{ .kind = .gpr(.general), .at = 12, .access = .write }, .{ .kind = .cr, .at = 16, .access = .read }, .{ .kind = .cr, .access = .read }, .{ .kind = .imm(.unsigned(3)), .at = 5, .access = .read }, ], }, ] }

A coprocessor's register read into a general one: mrc p15, 0, r0, c13, c0, 3 reads the thread pointer (A profile, where the system control coprocessor holds it).

value msr

msr := _t.Instruction{ .forms = &[ .{ .base = 0xf3808800, .args = &[.{ .kind = .special(.is(.apsr)), .access = .write }, _r] }, .{ .base = 0xf3808800, .args = &[.{ .kind = .special(.any), .access = .write }, _r], .requires = _microcontroller }, ] }

A general register written into a special one, as mrs reads them.

value cpsid

cpsid := _t.Instruction{ .forms = &[.{ .base = 0xb670, .args = &[_mask] }] }

Masks interrupts: cpsid i sets primask, cpsid f sets faultmask; cpsie clears them.

value cpsie

cpsie := _t.Instruction{ .forms = &[.{ .base = 0xb660, .args = &[_mask] }] }

Waits for an interrupt, or for an event.

value barriers

barriers := _t.Family{ .forms = &[.{ .base = .\or(0xf3bf8f00), .args = &[.{ .kind = .barrier, .access = .read }] }], }

Barriers: every access before completes before any after (dsb), in order of memory (dmb), and the instructions after are fetched again (isb).

value dsb

dsb := _t.Member{ .family = barriers, .bits = 0x40 }

value dmb

dmb := _t.Member{ .family = barriers, .bits = 0x50 }

value isb

isb := _t.Member{ .family = barriers, .bits = 0x60 }
