lang.float.soft.arith

IEEE 754 arithmetic written with integers, for a processor computing no float of the type (lang.lower.soft): each operand taken apart through lang.float.bits, the result exact in integers twice as wide as the float, then rounded once to nearest, ties to even; a NaN result is the canonical NaN, as the instructions' are made (spec 04, section 2).

function add

add := ($T: type, a: T, b: T) -> T

a + b.

function sub

sub := ($T: type, a: T, b: T) -> T

a - b: a plus b negated.

function mul

mul := ($T: type, a: T, b: T) -> T

a · b.

function div

div := ($T: type, a: T, b: T) -> T

a / b: the dividend's significand shifted up past the divisor's, both with their leading one at bit M, so the integer quotient holds M + 3 bits at least, a remainder kept sticky.
