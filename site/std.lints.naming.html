The level of the group's lints unless a build or an attribute sets another (spec 10, section 4).

lowercase_types := &[ "unsigned", "signed", "usize", "isize", "f16", "f32", "f64", "bool", "never", "type", "interface" ]

The type names that keep their conventional lowercase, with the integer widths (width_prefixes): the exemptions of case.

value width_prefixes

value case

#[lint.define]
case := lang.lint.Lint{ .group = .naming, .doc = std.meta.embed("naming/case.md"), .decl = (cx: &mut lang.lint.Cx, d: lang.lint.Decl) { name := Spelling{ .text = d.name }; if .some(want) = Case.of(d.binds, name) { if !want.holds(name) { // Renaming a declaration leaves its uses to rename: shown, never applied. renamed := want.written(name); msg := "rename it `" ++ renamed ++ "`, and its uses"; fix: lang.lint.Fix = .{ .msg = msg, .safety = .display_only, .text = renamed }; cx.report(d.origin, want.said(d.binds, name), &[fix]); } } }, }
