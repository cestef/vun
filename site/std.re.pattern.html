std.re.pattern

Byte patterns as a reverse engineer writes them: hexadecimal bytes separated by spaces, with ? or ?? for a byte that may be any, as in 48 8B ?? 05.

struct Pattern

Pattern := ($n: Int(1..)) -> type { struct { ... } }

A pattern of up to n bytes.

function parse

parse := (text: &[u8]) -> ?Pattern(n)

The pattern text writes; none for an empty text, for a token that is neither a byte nor a wildcard, and for more than n bytes.

function len

len := (self: &Pattern(n)) -> usize

How many bytes it matches.

function matches

matches := (self: &Pattern(n), bytes: &[u8]) -> bool

Whether bytes start with what it matches: not where they are fewer.

function find

find := (self: &Pattern(n), bytes: &[u8]) -> ?usize

Where it first matches in bytes: none where it never does.
