std.os.library

Libraries a hosted program loads as it runs (spec 08, section 2): shared objects the system finds by path or name, whose functions the program calls once it has their addresses. The system names a library by a number, as it does a file.

Loads the library at path, or the one the system finds by that name, returning the number it knows it by.

struct Library

Library := struct { ... }

A library loaded for as long as the value lives, until close.

field of

of := unsafe (handle: usize) -> Library { .{ ._handle = handle } }

The library the system knows as handle, which it must have loaded and nothing else unloads.

field function

function := unsafe (self: &Library, $F: type, name: &[u8]) -> Result(F, std.os.Error) { address := symbol(self._handle, name)?; .ok(unsafe lang.mem.function_at(F, address)) }

What it exports as name, a function of type F: the code there must be written to F's signature and calling convention (#[abi.c] for C's), and the function must not be called after close.
