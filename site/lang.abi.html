lang.abi

Calling conventions (spec 07, section 4).

value native

native: Attribute(&[Place.functions]) = _

value c

c: Attribute(&[Place.functions]) = _

value interrupt

interrupt: Attribute(&[Place.functions]) = _

value naked

naked: Attribute(&[Place.functions]) = _

value sysv

sysv: Attribute(&[Place.functions]) = _

The System V AMD64 convention, a function of x86-64 called as C's are under it.

value win64

win64: Attribute(&[Place.functions]) = _

The Microsoft x64 convention.

value cdecl

cdecl: Attribute(&[Place.functions]) = _

The C convention of 32-bit x86: arguments on the stack, popped by the caller.

value stdcall

stdcall: Attribute(&[Place.functions]) = _

32-bit x86's __stdcall: the arguments on the stack, popped by the callee.

value fastcall

fastcall: Attribute(&[Place.functions]) = _

32-bit x86's __fastcall: two arguments in ecx and edx, the rest as stdcall.

value thiscall

thiscall: Attribute(&[Place.functions]) = _

32-bit x86's __thiscall: the first argument in ecx, the rest as stdcall.
