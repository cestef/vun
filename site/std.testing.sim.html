std.testing.sim

Deterministic simulation (spec 11, section 4): a test whose one parameter is &mut Sim runs tasks, std.task.Async frames, on a virtual clock, one at a time, each next one chosen among those ready by the case's choices. They are the choices a property's arguments are read from, so a simulation runs over the cases a property does, a failing one is shrunk on its choices, and --seed replays it exactly. Time passes only when no task is ready: the clock jumps to the earliest time a task sleeps until.

function run

Runs tasks, borrows of std.task.Async frames, on clock until each finished, none can go on, or the clock has moved limit past where it read: one ready task at a time, the next chosen by the case's choices, the clock moved to the earliest time a task sleeps until whenever none is ready.

function attempt

attempt := ($F: type, $f: F, sys: &mut std.os.System, c: &mut std.testing.Choices, quiet: bool) -> ?lang.panic.Trap

Runs the simulation f with the choices c, on a thread of its own, reporting a trap unless quiet: the trap that ended it, if one did. The choices it took stay in c, a trap included. Where the system runs one thread, on the calling one, and a trap ends the run.
