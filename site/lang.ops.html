struct derive_eq

derive_eq := ($T: type) -> type { struct { ... } }

An Eq witness for T by reflection (spec 03, section 6): two values are equal when they are the same variant and each part of it is equal, by its own Eq. A struct is one variant, its fields its parts.

function eq

eq := (a, b)

struct Eq

#[lang.derive(derive_eq)]
Eq := interface(($Self: type) -> type { struct { ... } })

a == b and a != b. A struct or an enum whose parts have it is equal by its parts without an impl: derive_eq.

a < b, a <= b, a > b and a >= b: a partial order, in which two values may be unordered, every comparison of them false (a float NaN is unordered with every value).

struct Ord

Ord := interface(($Self: type) -> type { struct { ... } })

A total order: any two values compare, as cmp says. A totally ordered type's operators are its PartialOrd, which by_cmp derives from cmp.
