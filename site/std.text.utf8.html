std.text.utf8

UTF-8 (decision 43): text is bytes, and these read and write the code points in them. A code point is a u32.

value replacement

replacement: u32 = 0xFFFD

The code point read where the bytes are not UTF-8: U+FFFD.

value max

max: u32 = 0x10FFFF

The largest code point.

value surrogate_first

surrogate_first: u32 = 0xD800

The first and last surrogates, which are no code points of text.

value surrogate_last

surrogate_last: u32 = 0xDFFF

value continuation_mask

continuation_mask: u8 = 0xC0

The bits that tell a byte in the middle of a sequence, and those it holds of the code point.

value continuation_tag

continuation_tag: u8 = 0x80

value continuation_bits

continuation_bits: u8 = 0x3F

value bits_per_byte

bits_per_byte := 6

The bits each byte of a sequence holds of the code point.

function low_bits

low_bits := (byte: u8, mask: u8) -> u32

The bits of byte that mask keeps, as a code point's first bits.

function byte_of

byte_of := (cp: u32, shift: u32, tag: u32) -> u8

The byte holding the bits of cp from shift up under the bits tag, a sequence's first.

function tail_of

tail_of := (cp: u32, shift: u32) -> u8

The byte holding six bits of cp from shift, as a sequence continues.

function continues

continues := (byte: u8) -> bool

Whether byte is one in the middle of a sequence.

function is_scalar

is_scalar := (cp: u32) -> bool

Whether cp is written in UTF-8: a code point up to max, and no surrogate.

function decode

decode := (text: &[u8]) -> Option((u32, usize))

The code point text starts with and how many bytes it takes; none for an empty text, and for bytes that are not UTF-8: a sequence cut short, a byte that cannot start one or continue one, a code point written longer than it needs, a surrogate, or one past max.

function is_valid

is_valid := (text: &[u8]) -> bool

Whether every byte of text is part of UTF-8.

function chars

chars := (text: &[u8]) -> std.iter.Iter(u32)

The code points of text, replacement for each byte that is not part of UTF-8.

The bytes a code point is written as.

of := (cp: u32) -> Encoded

cp in UTF-8; replacement where it is a surrogate or past max.

function text

text := (self: &Encoded) -> &[u8]

The bytes.

write := ($W: std.fmt.Writer, w: &mut W, cp: u32) -> Result((), W.Error)
