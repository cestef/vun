function witness

#[
    lint.allow(
        std.lints.naming.case,
        "it gives an impl, a namespace, which a primitive's annotation cannot say"
    )
]
witness: ($I: lang.Interface, $T: type) -> type = _

The struct T's impl of the interface I gives, as the impls seen where it is asked see them: witness(lang.ops.Add, u8).Output(u8) is Int(0..=510).

function implements

implements: ($I: lang.Interface, $T: type) -> bool = _

Whether T has an impl of the interface I, as impls are seen where it is asked: whether witness(I, T) gives one.

function embed

embed: ($path: &[u8]) -> &static [u8] = _

The bytes of the file at path, from the directory of the file calling, in its package (spec 03, section 7): the one input compile-time code reads, recorded as a dependency.

function inside

inside: (inner: Namespace, outer: Namespace) -> bool = _

Whether the namespace inner is outer or nested in it.

function same

same: ($T: type, $a: T, $b: T) -> bool = _

Whether a and b are one compile-time value: two types made by the same constructor from the same arguments, one name.

type Any

Any: type = _

A compile-time value of any type, with its type: what a plan records of a record whose type each call infers (spec 03, section 7). It exists at compile time only.

value, of type T, as an Any.

The value a holds, when it is of type T.

The items of items followed by item, in compile-time memory (spec 03, section 7).

function concat

concat: ($T: type, a: &[T], b: &[T]) -> &static [T] = _

The items of a followed by those of b, in compile-time memory.

struct Field

Field := struct { ... }

A part of a value, as reflection gives it (spec 03, section 6): a field of a struct, an item of a variant's payload, named by its position (0, 1, ...), or a parameter of a function, a part of the tuple a call passes.

field name

name: &[u8]

field index

index: usize

Its position among the parts of its variant.

field type

type: type

field attrs

attrs: &[Any]

The values of the attributes written on it, plain data found by type (std.meta.attr); none for an item of a payload.

function fields

fields: ($T: type) -> &[Field] = _

The fields of the struct type T in declaration order, generated ones included.

struct Variant

Variant := struct { ... }

A variant of a type, as reflection gives it: every value of a struct or enum type is one of its type's variants and the parts that variant holds. A struct is one variant, named by nothing, whose parts are its fields.

field name

name: &[u8]

field index

index: usize

Its position among the variants of its type.

field parts

parts: &[Field]

field attrs

attrs: &[Any]

The values of the attributes written on it; none for the variant a struct is.

struct Decl

Decl := struct { ... }

A member of a namespace, as reflection gives it: its name, the values of the attributes written on it, and, for a file or directory below, that namespace. Its value, ns.$(name), is computed only where it is read.

field name

name: &[u8]

field attrs

attrs: &[Any]

field nested

nested: ?Namespace

function decls

decls: ($ns: Namespace) -> &[Decl] = _

The members of ns the namespace calling sees, in the order they are declared: every one within its package, the public ones from another.

function variants

variants: ($T: type) -> &[Variant] = _

The variants of T in declaration order: an enum's, the one a struct is, none for another type.

function variant

#[panic.never]
variant: ($T: type, v: &T) -> usize = _

The position among the variants of T of the variant v is: 0 for a struct.

function Parts

Parts: ($T: type, $variant: usize) -> type = _

The types of the parts of the variant variant of T, as a tuple.

function items

items: ($T: type) -> &[type] = _

The item types of the tuple type T, in order; none for another type.

function Unborrowed

Unborrowed: ($T: type) -> type = _

T without the borrows around it, U for &&U: the type a method called on a value of T is looked up in.

function name_of

name_of: ($T: type) -> &[u8] = _

The name of T as diagnostics show it: a struct or enum literal by the declaration it is written in, with its compile-time arguments.

function params

params: ($F: type, $f: F) -> &[Field] = _

The parameters of the function f, in order: each by its name, or its position when it binds no name, the type F gives it and the values of the attributes written on it.

function within

within: ($T: type, c: &Code(T), $bytes: lang.Range) -> Origin = _

Where the bytes bytes of the string literal the code c writes are written: a part of its origin, which a report points inside the literal with (spec 10, section 3); the code's own origin when it writes no literal.
