std.text

Text (decision 43): bytes held, written and cut. Slab(n) keeps up to n bytes inline, with no allocator; text is UTF-8 in &[u8], whose bytes ascii classifies and whose code points utf8 reads. Formatting is std.fmt, readers and writers are std.io, maps are std.collections.

Namespaces

  • std.text.ascii

    ASCII bytes (decision 43): which class a byte is of, its other case and the digit it writes. Bytes past 127 are in no class and stay as they are.

  • std.text.string

    String: bytes of text a program grows, in a buffer an allocator gave. Like Vec, which it holds, it is linear, and each call that grows it is passed the allocator, which deinit must be given back. Text is UTF-8 in &[u8]; a string keeps whatever bytes were put in it.

  • std.text.tests

    Tests of std.text: a slab written to as any writer, read back as bytes.

  • std.text.utf16

    UTF-16, as Windows spells text: units of 16 bits, a code point past U+FFFF written as a pair of surrogates. Text in a program is UTF-8 (decision 43); these read and write the units a system call takes, and turn one into the other.

  • std.text.utf8

    UTF-8 (decision 43): text is bytes, and these read and write the code points in them. A code point is a u32.
