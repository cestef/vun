lang.lint

Lints as values (spec 10, section 4). A lint states its group, its default level and a check for each kind of node it looks at; the compiler walks the typed code once per file and runs each check a lint states on each node of its kind, at compile time. A check sees the code through Cx and the nodes as plain data, a view versioned with lang, and reports by appending to Cx: running it is a pure compile-time call.
