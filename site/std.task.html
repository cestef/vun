std.task

Asynchronous tasks and executors (spec 06). A task yields Wait requests; the executor, not the task, owns wakeups. Executors are library code over frames: run for bare metal, block_on for one task on a hosted system, select inside a task.

struct Event

Event := struct { ... }

Something that happens, which an executor watches: an interrupt, a timer, a device. Firing it, from an interrupt handler too, marks it until a task waiting on it takes the mark; executors only look at it.

init := () -> Event

fired := (self: &Event) -> bool

Whether it fired since the mark was last taken, leaving the mark.

function take

#[panic.never]
take := (self: &Event) -> bool

Whether it fired since the mark was last taken, taking it.

function wait

wait := (self: &Event) -> Async(())

Waits until it fires, and takes the mark: resumed before then, it finds no mark and yields again, so a task may be resumed whenever an executor likes.

enum Wait

Wait := enum { ... }

A request yielded to the executor: resume the task once an event fires. Waiting on either of two tasks joins their waits, in the frames of the tasks waiting, and allocates nothing.

struct symbols

symbols := struct { ... }

Waits for the next event: sleeps the core until an interrupt, or parks a hosted thread. A typed link symbol the runtime exports (spec 08, section 1).

enum Either

Either := ($A: type, $B: type) -> type { enum { ... } }

Which of two tasks finished first, with its result.

variant first

first(A)

variant second

second(B)

function select

select := ($A: type, $B: type, $F: Async(A), $G: Async(B), tasks: (&mut F, &mut G)) -> Async(Either(A, B))

Runs two tasks until one finishes, and gives its result; both stay for the caller to end. It is resumed once either task's wait is ready and resumes both, the other finding no mark.

function run

run := ($T: type, tasks: T) -> never

Runs tasks, borrows of tasks that never finish, forever: each resumes when an event it waits on fires, and between rounds the core sleeps until an interrupt.

function block_on

block_on := ($R: type, $F: Async(R), task: &mut F) -> R

Runs one task to its end on a hosted system, sleeping while it waits.
