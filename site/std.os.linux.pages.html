std.os.linux.pages

Pages as Linux's mprotect takes them, and as /proc/self/maps describes them: a line per mapped range, its ends in hex and rwxp for what it allows, before whatever else it holds.

value read_bit

read_bit: u32 = 1

PROT_READ, PROT_WRITE and PROT_EXEC.

value write_bit

write_bit: u32 = 2

value execute_bit

execute_bit: u32 = 4

function of_access

of_access := (access: std.os.pages.Access) -> u32

access as mprotect's prot.

value prefix_max

prefix_max := 48

The most bytes of a line of /proc/self/maps this reads before it knows whether address is inside it: lo-hi rwxp, 16 hex digits for each of a 64-bit address at most.

value chunk_bytes

chunk_bytes := 256

The most bytes read from the file in one call.

function query

query := (address: usize) -> Result(std.os.pages.Region, std.os.Error)

The range of /proc/self/maps that holds address, read a chunk at a time so neither a line nor the file is ever held whole; .unmapped where no line does.

function scan

scan := (fd: i32, address: usize) -> Result(std.os.pages.Region, std.os.Error)

Reads fd a chunk at a time, matching address against the range of each line in turn.

function is_hex

is_hex := (b: u8) -> bool

Whether b is an ASCII hex digit, lowercase as the kernel writes them.

function hex_value

hex_value := (b: u8) -> usize

The value of the hex digit b; 0 where it is not one, which is_hex must have ruled out.

function hex

hex := (text: &[u8], start: usize) -> ?(usize, usize)

The hex digits of text from i on, as far as they go: the address they write, and where they end; .none past u64, as no address of this process is.

function line

line := (text: &[u8], address: usize) -> ?std.os.pages.Region

The range and access text, the start of a line of /proc/self/maps, holds: lo-hi rwxp; .none where it is not address's, or does not read this way.
