std.os.windows.kernel32

The functions of kernel32 the runtime calls, each by its link symbol (spec 08, section 3): the system's own, which a program of this runtime links by name and no C runtime stands between. They are stdcall, the system's convention on 32-bit x86, which x86-64 takes for its one. A handle is a usize, a BOOL an i32, a DWORD a u32.
