std.build

The build API used by build.vun files (spec 12, section 2). build runs at compile time, in the sandbox, with a &mut Build capability, and records a plan: steps that the driver carries out once it returns. What only the package knows, its dependencies' names and parameters, a program's options, is written as records, which the driver reads by reflection (decision 116).
