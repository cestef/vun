std.os.pages

The pages of the process's own address space (spec 08, section 2): what a range of them allows, and the range an address is mapped within. An address passed here must be one the system gave the process: through a library it loaded, its own code and data, or memory it mapped.

struct Access

Access := struct { ... }

What a range of pages allows: reading it, writing it, and running it as code. A system that takes the three separately may still deny some combinations of them: Windows gives writing no words of its own without reading too, so asking for it there reads as well.
