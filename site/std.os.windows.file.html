std.os.windows.file

Files as the system hands them out: handles, which a std.os file number stands for, the modes std.os.file.Mode asks for in the system's words, and paths in UTF-16.

value standard_handles

standard_handles: [3]u32 = [0xFFFF_FFF6, 0xFFFF_FFF5, 0xFFFF_FFF4]

GetStdHandle's arguments for the three standard streams, as DWORDs: -10, -11 and -12.

value invalid

invalid: usize = (0 - 1).wrap(usize)

What CreateFileW returns where it failed: -1 as a handle.

function handle

handle := (fd: i32) -> usize

The handle the file number fd stands for: the standard streams are 0, 1 and 2, which no handle is (handles are multiples of 4), and any other number is a handle, of which a 64-bit system uses the low 32 bits alone, sign extended.

function number

number := (opened: usize) -> i32

The file number for a handle CreateFileW returned.
