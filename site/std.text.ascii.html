std.text.ascii

ASCII bytes (decision 43): which class a byte is of, its other case and the digit it writes. Bytes past 127 are in no class and stay as they are.

The value of the digit b writes in radix, 2 to 36; none for any other byte. Each class is compared inline, which is what proves the arithmetic of its digit stays in a u8.
