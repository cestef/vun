std.os.windows.command_line

The command line of a Windows process: one string of UTF-16, which a program splits into its arguments itself. The rules are the C runtime's, as Microsoft documents them:

  • The program's name is up to the first space or tab, or, when it starts with a double quote, up to the next one; nothing in it is escaped.
  • The other arguments are separated by spaces and tabs, which a double quote protects: a quote starts a quoted stretch and the next one ends it, neither being part of the argument, and two quotes together inside a stretch are one quote of the argument.
  • Backslashes are themselves, except before a double quote: a run of them there stands for half as many, and if the run is odd the quote is one of the argument, else it starts or ends a stretch.

function split

Splits line into arguments written to bytes, each followed by a zero byte, with where each starts in starts; how many there are. A unit that stands for no character, a surrogate without its partner, which the name of a file on Windows may hold, is written as std.text.utf8.replacement. None where bytes or starts is too short.
