std.fmt.json

JSON (RFC 8259) written from typed values, each type writing itself through Json: an integer is a number, a float a string of its exact hexadecimal form, a bool true or false, bytes a string, another sequence an array and an option its value or null. derive(T) writes a struct or a record as an object of its fields, a tuple as an array of its items, and an enum's value as its variant's name, or, where the variant holds parts, as an object naming it; a type of these without a Json of its own is written as derive(T) writes it.

struct Json

#[lang.derive(derive)]
Json := interface(($Self: type) -> type { struct { ... } })

How a value is written as JSON. A struct, an enum, a tuple or a record whose parts have it has it without an impl, as derive(T) writes it.

struct derive

derive := ($T: type) -> type { struct { ... } }

A Json witness for T by reflection: a struct or a record is an object of its fields, each by its own Json, a tuple an array of its items; an enum's variant is its name, or, holding parts, an object whose one member is named by it and holds its part, or the array of its parts. #[impl(std.fmt.json.Json(Line))] line_json := std.fmt.json.derive(Line);
