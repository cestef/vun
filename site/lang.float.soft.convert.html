lang.float.soft.convert

Conversions written with integers, for a processor that does not convert between the types (lang.lower.soft): a float it lacks, or an integer wider than an address. Each takes the encoding apart through lang.float.bits and rounds once, to nearest, ties to even, as the primitives of lang.float say.

function from_int

from_int := ($r: lang.Range, x: Int(r), $T: type) -> T

The float of type T nearest the integer x.

function to_int

to_int := ($T: type, x: T, $U: type) -> U

x rounded toward zero and clamped to the bounds of the integer type U; a NaN gives 0, clamped likewise.

function convert

convert := ($T: type, x: T, $U: type) -> U

The float of type U nearest x, of type T; a NaN gives the canonical NaN.
