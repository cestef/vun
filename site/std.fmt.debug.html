std.fmt.debug

Debug output, {?} in a format string: a value written as the expression that builds it, for a reader of the program. An integer is its digits, a bool true or false, bytes a quoted string, other items [a, b], a tuple (a, b), a variant .name or .name(a, b) and a struct Name{ .field = a, .other = b }, as the compiler shows values. A struct or an enum whose parts have Debug has it without an impl, by derive_debug.

#[lang.derive(derive_debug)]

function quoted

quoted := ($W: std.fmt.Writer, w: &mut W, bytes: &[u8]) -> Result((), W.Error)

Writes bytes as a string literal: quoted, " and \ escaped by a backslash, the line feed, carriage return and tab as \n, \r and \t, other control characters by their code, \u{1b}. Bytes past 127 are the UTF-8 of the text, written as they are.

struct derive_debug

derive_debug := ($T: type) -> type { struct { ... } }

A Debug witness for T by reflection: a tuple is its items in parentheses, an enum's variant is .name, followed by its parts in parentheses where it has any, and a struct or a record is its type's name and its fields, each as .name = value. #[impl(std.fmt.Debug(Line))] line_debug := std.fmt.debug.derive_debug(Line);
