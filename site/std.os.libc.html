std.os.libc

A runtime on top of the C library: exports C main, the trap handler, the critical section and the executors' sleep, and reaches the system through the C library's functions (spec 08, section 2).

Namespaces

  • std.os.libc.library

    Loading libraries through the C library (dlopen, dlsym, dlclose): the exports a runtime on top of it holds, library := std.os.libc.library.exports. The loader reports a failure as text rather than an error number, so each is unresolved.

  • std.os.libc.pages

    std.os.pages's exports for a runtime on top of the C library: mprotect, and a query of /proc/self/maps where the system is Linux's, which gives a process no other way to its own.

field spawn

#[link.export(std.os.symbols.spawn)]
spawn := unsafe (thread: std.os.thread.Start, context: *u8, bytes: usize) -> Result(usize, std.os.Error) { total := (lang.meta.size(Thread) + bytes + 2 * std.os.thread.align).wrap(usize); mapped := outcome(reserve(total).wrap(isize))?; placed := std.os.thread.Placed.of(Thread, (mapped + total).wrap(usize), bytes); unsafe { lang.mem.pointer_at(Thread, placed.record).write(Thread{ .handle = 0, .begun = .{ .start = thread, .context = placed.context, .ended = placed.ended }, .mapped = mapped, .bytes = total, }); lang.mem.copy(u8, lang.mem.pointer_at(u8, placed.context), context, bytes); placed.begin(); } begun := (placed.record + lang.meta.size(usize)).wrap(usize); failed := unsafe pthread_create(lang.mem.pointer_at(usize, placed.record), 0, begin, begun); if failed != 0 { unmap(mapped, total); return .err(system.error(failed)); } .ok(placed.record) }

Starts a thread through the C library, its context copied into memory mapped for it.
