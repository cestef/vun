struct Fixed

Fixed := struct { ... }

An allocator handing out the bytes of one buffer in order, freeing nothing until it is dropped as a whole.

function init

init := (storage: &mut [u8]) -> Fixed

An allocator over storage, which it borrows for as long as it lives.

function take

take := (self: &mut Fixed, size: usize, align: usize) -> Result(*u8, Error)

The next size bytes aligned to align, a power of two: what its Allocator impl's alloc gives.

function create

create := (self: &mut Fixed, $T: type) -> Result(Own(T), Error)

A place for a T, uninit, owned by the caller.

function destroy

destroy := (self: &mut Fixed, $T: type, o: Own(T))

Gives o back; a fixed allocator reuses nothing, so this only ends the ownership.
