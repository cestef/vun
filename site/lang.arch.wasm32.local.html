Locals and the stack.

value local_get

local_get := _w.Instruction{ .forms = &[.{ .base = 0x20, .args = &[.{ .kind = .local, .access = .read }], .pushes = &[.local], }] }

Pushes the value of a bound local: local_get(in(a)).

value local_set

local_set := _w.Instruction{ .forms = &[.{ .base = 0x21, .args = &[.{ .kind = .local, .access = .write }], .pops = &[.local], }] }

Pops into a bound local: local_set(out(r)).

value local_tee

local_tee := _w.Instruction{ .forms = &[.{ .base = 0x22, .args = &[.{ .kind = .local, .access = .read_write }], .pops = &[.local], .pushes = &[.local], }] }

Writes the top of the stack into a bound local and leaves it: local_tee(inout(r)).
