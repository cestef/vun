value xpaclri

xpaclri := _a.Instruction{ .forms = &[ .{ .base = 0xd50320ff, .sizes = _any, .args = &[], .reads = &[.x30], .writes = &[.x30] }, ] }

Strips the pointer authentication code from the address in x30, as a return address is saved where code is built with return addresses signed; a hint, which does nothing on a processor without pointer authentication.
