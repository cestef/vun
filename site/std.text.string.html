std.text.string

String: bytes of text a program grows, in a buffer an allocator gave. Like Vec, which it holds, it is linear, and each call that grows it is passed the allocator, which deinit must be given back. Text is UTF-8 in &[u8]; a string keeps whatever bytes were put in it.
