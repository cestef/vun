lang.check

Checks of unsafe code at run time (spec 07, section 7; spec 13, section 8.7): what a program may be built to check, the operations its runtime provides for the checks, and how a failed one is reported.

Namespaces

  • lang.check.mem

    The operations of lang.mem on raw pointers, checked (#[check.by(.pointers, f)]): each checks the bytes it touches, then does what it checks.

function by

by: ($kind: Kind, $F: type, $f: F) -> Attribute(&[Place.decls]) = _

At run time, in a program built with kind checked, each call of the declaration this marks is a call of f: its arguments, then the call's origin as a $ lang.meta.Origin.

value granule

granule := 8

The bytes of memory one byte of the runtime's shadow describes, which a slot with a redzone starts at a multiple of.

value redzone

redzone := 16

The bytes poisoned past a stack slot whose address is taken, a multiple of granule.

value stack_reserve

stack_reserve := 16384

The bytes at the bottom of the stack kept for reporting a failed check: a frame that reaches into them is an overflow, so that the report has room to be written.

value quarantine

quarantine := 1 << 20

The bytes of memory given back that the quarantine holds poisoned before giving them to their allocator, past which each free gives back the oldest its allocator has there.
