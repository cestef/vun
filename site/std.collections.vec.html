std.collections.vec

Vec(T): items of one type in a buffer an allocator gave, grown as they are pushed. It is linear: it owns its buffer, which deinit gives back to the allocator it came from, the one each growing call is passed. No allocator is held, so one allocator serves any number of them.

function Vec

Vec := ($T: type) -> type

value grown_least

grown_least: usize = 4

The fewest items a buffer is made for, so that the first pushes do not each grow it.
