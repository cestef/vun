lang.arch

The instruction sets a block of instructions is written in, each a namespace declaring its table (spec 07, section 6): x86_64, arm64, thumb and wasm32; and what a block is written with, whatever its instruction set.

Namespaces

  • lang.arch.arm64

    64-bit ARM (spec 07, section 6): its registers, and each instruction with its forms as the toolchain's assembler encodes them (Arm A64 ISA), with what each form reads and writes. The instructions are declared in control, fp, int and memory, what their operand positions take in operand; vun-isa-arm64's tables are generated from these declarations. An alias is an instruction of its own, its fixed fields in its base word: mov is orr from the zero register, cmp is subs into it.

  • lang.arch.thumb

    Thumb, the instruction set of Arm's M profile and of Arm's A profile in its Thumb state (spec 07, section 6): its registers, and each instruction with its forms as the toolchain's assembler encodes them (Armv7-M, Thumb-2 with the floating-point extension), with what each form reads and writes. The instructions are declared in branch, data, fp, memory, multiply and system, what their operand positions take in operand; vun-isa-thumb's tables are generated from these declarations.

  • lang.arch.wasm32

    WebAssembly 32-bit, the instruction set of the wasm32 targets (spec 07, section 6): the instructions of its stack machine with what each pops and pushes, as the toolchain's backend encodes them. They are declared in arithmetic, compare, control, convert, local and memory; vun-isa-wasm32's tables are generated from these declarations.

  • lang.arch.x86_64

    x86-64 (spec 07, section 6): its registers, and each instruction with its forms as the toolchain's assembler encodes them (Intel SDM volume 2), with what each form reads and writes. The instructions are declared in arith, control, int and sse; vun-isa-x86_64's tables are generated from these declarations, so the language, the assembler and its listings share one table. names holds what a block of instructions is written with.

struct Registers

Registers := ($Class: type, $Size: type) -> type { struct { ... } }

What the variants of an enum of an instruction set name, written as the enum's attribute (#[Registers{ .class = .general, .size = .some(.b32) }]): registers of a class, at a width where their names give one, the nth variant naming register n * step of the class (d1 is the second double-precision register, the third of its class counted as single-precision ones).

function asm

asm: unsafe ($code: lang.meta.Code(())) -> () = _

A block of instructions (spec 07, section 6): each statement of code calls an instruction of one instruction set's table, or makes or marks a label. Sema reads the block against that table; the block is never where its last instruction does not return.

function in

in: ($T: type, value: T) -> Operand = _

The value of value, read by the instruction from a register the backend picks.

function out

out: ($T: type, place: T) -> Operand = _

A register the backend picks, written into the place place after the block.

function inout

inout: ($T: type, place: T) -> Operand = _

A register holding the value of the place place, written back into it after the block.

function at

at: (self: Operand, $R: type, register: R) -> Operand = _

self, a value bound by in, out or inout, in the register register names instead of one the backend picks (in(e).at(rdi)).

function mem

mem: ($P: type, ..parts: P) -> Operand = _

Memory at the address its parts give: a base, then an index and an offset, as the instruction set writes them (mem(x1, 8), mem(rax, scaled(rcx, 8), 16)).

function scaled

scaled: ($R: type, index: R, scale: u8) -> Operand = _

An index register times scale bytes, a part of memory where the instruction set scales one.

function pre

pre: (memory: Operand) -> Operand = _

memory, its address written back into its base before the access ([x1, 8]!).

function post

post: ($T: type, memory: Operand, offset: T) -> Operand = _

memory, its base moved by offset after the access ([x1], 8).

function here

here: () -> Label = _

A label marking the next instruction.

function label

label: () -> Label = _

A label a later place marks.

function place

place: (at: Label) -> () = _

Marks the next instruction with at.

struct called

called := ($I: type) -> ($Params: type) -> type { ($Params: type) -> type { struct { ... } } }

The witness making each instruction of type I callable with any operands (spec 02, section 3): an instruction set declares #[impl(lang.ops.Call(_, ())(Instruction))] on called(Instruction), so that a block's calls are typed as any call is. Outside a block an instruction cannot run: a program reaching such a call is refused, at the call.
