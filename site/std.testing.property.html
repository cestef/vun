std.testing.property

Property tests (spec 11, section 2): a test's arguments are generated from its parameters' types, each read from a stream of choices, so the case that fails is replayed and shrunk as its choices, whatever generated it. A parameter whose type borrows, such as &[u8], is lent what the case holds for it (lend).

Namespaces

  • std.testing.property.lend

    How a property's case passes an argument of a type that borrows what it reaches (spec 11, section 2): it holds a value generated as any other, and lends it.

  • std.testing.property.shrink

    Shrinking a failing case (spec 11, section 2): on the choices it took, whatever generated them, towards fewer and smaller ones.
