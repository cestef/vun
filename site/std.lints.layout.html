std.lints.layout

Organization of namespaces, files and directories (spec 10, section 5).

value level

level: lang.lint.Level = .warn

The level of the group's lints unless a build or an attribute sets another (spec 10, section 4).

value pub_doc

#[lint.define]
pub_doc := lang.lint.Lint{ .group = .layout, .default = .some(.allow), .doc = std.meta.embed("layout/pub_doc.md"), .decl = (cx: &mut lang.lint.Cx, d: lang.lint.Decl) { if d.public and !d.documented { cx.report( d.origin, "the public " ++ d.binds.noun() ++ " `" ++ d.name ++ "` has no doc comment", &[] ); } }, }

A declaration any package sees says what it is in a doc comment. Allowed unless a build asks for it, as libraries publishing an interface do.
