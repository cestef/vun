function Own

Own := ($T: type) -> type

An owning pointer (spec 05, section 5): linear, free, and read through with .* and .. Freeing it needs the allocator it came from.

function copy

copy := ($T: type, to: &mut [T], from: &[T])

Copies from over to, which must be as long: a difference is a bug, not a short copy.
