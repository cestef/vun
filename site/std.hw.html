std.hw

Hardware access: memory-mapped registers over volatile operations.

function Reg

Reg := ($T: type) -> type

A memory-mapped register holding a T: each read and write reaches the device, exactly as written, in the order written. It is laid out as the T it holds, so a #[layout.c] struct of registers is laid out as the device's.

value at

#[panic.never]
at := unsafe ($T: type, address: usize) -> &T { unsafe { &lang.mem.pointer_at(T, address).* } }

The registers of the device at address, a T laid out as the device lays them out.
