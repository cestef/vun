std.fmt

Formatting, with format strings read at compile time (spec 03, section 4): print(w, "{} args\n", n) writes the text of the format string with each {} replaced by the next argument, as its Format impl writes it. Another specifier between the braces writes it another way: {?} by Debug, {x} by Hex and {b} by Binary. After a : goes where it sits in a width: {:>8} pads on the left to 8 bytes, {x:0>4} with 0, {:^5} on both sides.

Namespaces

  • std.fmt.debug

    Debug output, {?} in a format string: a value written as the expression that builds it, for a reader of the program. An integer is its digits, a bool true or false, bytes a quoted string, other items [a, b], a tuple (a, b), a variant .name or .name(a, b) and a struct Name{ .field = a, .other = b }, as the compiler shows values. A struct or an enum whose parts have Debug has it without an impl, by derive_debug.

  • std.fmt.json

    JSON (RFC 8259) written from typed values, each type writing itself through Json: an integer is a number, a float a string of its exact hexadecimal form, a bool true or false, bytes a string, another sequence an array and an option its value or null. derive(T) writes a struct or a record as an object of its fields, a tuple as an array of its items, and an enum's value as its variant's name, or, where the variant holds parts, as an object naming it; a type of these without a Json of its own is written as derive(T) writes it.

  • std.fmt.layout

    The layout of an argument in a format string (spec 03, section 4): after a : in its place, an optional fill and alignment, <, > or ^, and a width, as in {x:0>8} or {:^5}. An argument shorter than the width is padded with the fill; a longer one is written whole.

  • std.fmt.places

    The places of arguments in a format string (spec 03, section 4): {}, {?}, {x} and {b}, each a row of specs, then optionally a : and a layout (fmt/layout.vun), read once at compile time into the text between them, or the first problem.

  • std.fmt.tests

    Tests of std.fmt: the places of arguments in a format string, and debug output.
