std.testing.property.shrink

Shrinking a failing case (spec 11, section 2): on the choices it took, whatever generated them, towards fewer and smaller ones.

function smallest

smallest := ($F: type, $f: F, sys: &mut std.os.System, failing: std.testing.property.Failing) -> std.testing.property.Failing

The smallest case found from failing that still traps, within tries cases: a shorter stream, then each choice at 0 or halved, until none of them traps.

function retried

retried := ( $F: type, $f: F, sys: &mut std.os.System, taken: &[std.testing.property.room]u64, len: usize, best: &std.testing.property.Failing ) -> ?std.testing.property.Failing

The case replaying the first len of taken, when it still traps and is smaller than best, as a failing case found by one more shrink than it.
