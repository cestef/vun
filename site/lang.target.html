enum BuildsFor

BuildsFor := enum { ... }

enum Convention

Convention := enum { ... }

The calling convention of a target's C functions (spec 13, section 8.5): where a call passes its arguments and gets its result.

variant sysv

sysv

System V AMD64.

variant aapcs64

aapcs64

The procedure call standard for 64-bit ARM (AAPCS64).

variant darwin_arm64

darwin_arm64

Apple's variant of AAPCS64: a C call's scalars on the stack at their own size.

variant win64

win64

The Microsoft x64 convention: four arguments in registers shared by both banks, a shadow space of four words above the return address, and a record of 1, 2, 4 or 8 bytes in a register, any other by reference.

variant lp64d

lp64d

The RISC-V convention for 64-bit integers and double-precision floats in registers.

variant aapcs_vfp

aapcs_vfp

The procedure call standard for 32-bit ARM, floats in VFP registers (hard-float EABI).

variant aapcs

aapcs

The procedure call standard for 32-bit ARM, floats in general registers (soft-float EABI).

variant ilp32

ilp32

The RISC-V convention for 32-bit integers, floats in general registers.

variant wasm32

wasm32

The C convention of wasm32, as clang follows it.

variant cdecl

cdecl

The C convention of 32-bit x86: arguments on the stack, last first, popped by the caller, a result in eax, or edx and eax, or st0 for a float.

variant stdcall

stdcall

32-bit x86's __stdcall: as cdecl, but the callee pops the arguments (Windows' API).

variant fastcall

fastcall

32-bit x86's __fastcall: the first two arguments of a word or less in ecx and edx, the rest as stdcall.

variant thiscall

thiscall

32-bit x86's __thiscall on Windows: the first argument in ecx, the rest as stdcall (a C++ method's this).

struct Spec

Spec := struct { ... }

A target, as data (spec 13, section 7): the package targets declares one per system, architecture and ABI (targets.linux.x86_64.kernel), so adding a target changes no code. Architectures, CPUs, systems, ABIs, object formats, backends and linkers are names, the sets of them open to what the toolchain registers.

field arch

arch: lang.meta.Name

The instruction set: x86_64, arm64, riscv64, riscv32, arm, wasm32.

field isa

isa: lang.meta.Name

The instruction set its code is written in, which a block of inline assembly names as lang.arch.<isa> (spec 07, section 6): thumb for Arm's M profile, the arch otherwise.

field features

features: &[lang.meta.Name] = &[]

What its processor has of the instruction set beyond what every processor of it has, as the set's table names it (lang.arch.thumb.Feature): a block of instructions compiled for the target uses no form needing one it lacks.

field cpu

cpu: lang.meta.Name

The processor the code is for, generic for any of the architecture.

field os

os: lang.meta.Name

The system programs run on; bare on bare metal.

field abi

abi: lang.meta.Name

The conventions of the system's binaries: gnu (the GNU C library), eabihf, ...

field convention

convention: Convention

field accepts

accepts: &[Convention] = &[]

The conventions of other architectures that its C compiler takes for its own, as Windows takes __stdcall on x86-64, where the one convention has no other: #[abi.stdcall] names the target's own there, so that code calling the system is written once.

field pointer_bits

pointer_bits: u8

The width of an address.

field register_bits

register_bits: u8

The width of a general register: the widest integer its processor computes with, wider ones being computed in parts, and accessed atomically by lang.mem.soft (lang.lower.soft).

field floats

floats: &[type]

The float types its processor computes; lang.float.soft computes the others (lang.lower.soft).

field vector_bits

vector_bits: u16 = 0

The width of the vector registers its code can count on, in bits, or 0 where it has none: std.simd.Scalable(T) holds as many lanes of T as they do (spec 04, section 3).

field threads

threads: Threads = .one

How many threads its programs run, which storage per thread follows (spec 07, section 2).

field endian

endian: Endian

field object_format

object_format: lang.meta.Name

field entry_symbol

entry_symbol: ?&[u8]

The symbol a program starts at, when the target has one.

field os_version

os_version: ?Version = .none

The oldest release of its system its programs run on, where its binaries record one (as Mach-O's do); none where they do not.

field backends

backends: Backends

field linker

linker: lang.meta.Name

c: C
